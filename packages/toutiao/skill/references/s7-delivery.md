# S7 交稿、声明与反馈回流（人工终审卡口）

> **AI 到此止步，终审权在人。** 交稿单九个模块齐全，明确告诉用户“是否采用、何时发布由你决定”。用户没明确确认，状态停在“已验收”，不得自称“已交稿”。
> 不替用户发布、不登录头条账号，除非用户明确要求。

---

## 一、状态机（汇报只用这五个词）

```
初稿待改 (S4) ──[S5]──> 待验收 ──[S6 脚本 + 九项速查通过]──> 已验收（呈交用户）
                           │                                    │
                    [S6 打回，最多两轮]                     [用户确认采用]
                           ▼                                    ▼
                        验收退回                              已交稿
```

- **验收退回有两种来路**：S6 两轮仍不过（附差值和原因，不带病交），或用户看完说不行（附用户意见，回到对应步骤）。写明是哪一种。
- **已交稿只由用户触发**：用户说“就用这版”“发了”才改，并同步改台账：`python3 scripts/ledger.py status --title "主标题" --to 已交稿`。

## 二、交稿单（写入 `outputs/toutiao/YYYY-MM-DD-slug/交稿单.md`）

模板 `templates/交稿单-图文.md`，复制后逐块填实。对话里直接给终稿正文和标题矩阵，交稿单作为文件交付，不要只报一个路径。九个模块：

1. 1 主 + 4 备标题矩阵（字数、标题力、母体）
2. 信息流 dek 摘要（25~40 字，一个具体的人或处境）
3. 终稿正文（长图文标出主稿字数、延伸字数、延伸接的问题）
4. 标签与话题
5. 配图 Prompt 与图注（故事线写神话场景，别画成真实历史照片的样子）
6. 发布时间窗（经验值）
7. S6 质检快照（脚本原样输出，含立项卡检查）
8. S5 三联改写留痕
9. 发布设置、声明与出处

## 三、第九模块怎么填

### 头条首发（单篇勾选，由用户决定）

发布页现在单篇勾的是“头条首发”，没有单独的“声明原创”。勾之前对照四条（头条创作者帮助中心《首发激励计划》，https://baike.toutiao.com/detail/242/566/0 ，2026-05-25 更新）：

1. **原创**：不是拼接要点、整合汇编，不大篇幅引用公共信息（含百科）。长图文的延伸接的是主稿的问题，不是另一篇文章接上去；故事线不是照着原典或百科把情节顺一遍。
2. **独家 72 小时**：头条先发，发布后 72 小时内不在其他平台发；账号的“内容同步授权”要关掉，否则会自动同步出去。
3. **不重发**：同一篇或实质相似的内容只首发一次，删了重发也算违规。换个人名、换个神、换个模板再发同一个骨架，也会被当成同质内容（头条 2026-09-15《关于升级治理AI低质内容的公告》对此从严处置）。
4. **后果**：判非原创或非首发，每篇扣 5 信用分并扣回首发补贴；频繁发低成本内容（空洞水化、事件重复描述、网络信息拼凑汇编、模板化标题）冻结首发 14 天，累计两次永久关闭。

平台规则随时会改，勾之前以发布页和帮助中心当天写的为准。

### 作者声明（发布前必做，以发布页实际选项为准）

- **“AI生成”**：本技能产出的稿子都要选。依据《人工智能生成合成内容标识办法》（2025-09-01 施行）。
- **“虚构演绎，故事经历”**：故事线（神话、传说、民间故事改编）都要选；资讯线用了合成人物或情节、或整篇是细节丰富的生活故事也要选。依据头条 2025-11-27《“故事内容”的规范标识公告》。
- **“信息来源”**：涉及时事、公共政策、社会事件的，按页面要求标注。
- **只能单选时**：选“AI生成”；资讯线把合成人物改成明示口吻（“说一个挺常见的情形”），故事线在开头或结尾写明是改编（“按《山海经》的记载重讲一遍”）。

## 六、反馈回流

用户审阅后改了任何东西（哪怕半句话），追加到 `outputs/toutiao/feedback.md`，下次开工在 S2 之前先读：

```markdown
## [YYYY-MM-DD] · [slug]
- 初稿原句：[交稿单里的句子]
- 用户改后：[用户改后的句子]
- 修改动机：[节奏嫌慢 / 数字口径 / 地方口癖 / 标题锐度 / 敏感规避 / 版本出处 …… 一句话提炼规律]
```

同一类动机累计三次，提醒用户要不要固化进对应的 references 或 corpus。

## 七、发稿台账（`outputs/toutiao/log.csv`）

用脚本记，不手改：

```bash
python3 scripts/ledger.py add --card 立项卡.json --status 已验收
python3 scripts/ledger.py status --title "主标题" --to 已交稿
python3 scripts/ledger.py show --last 10
```

字段以 `python3 scripts/qa_check.py --rules` 为准：4.0.0 起多了内容线、母题、故事、改编方式四列，故事线撞题靠它们查。3.x 的旧台账照常读，下次写入时自动补齐表头，旧行的新列留空，内容线按主驱动推断。台账只记立项字段，不存正文。记完台账再跑 `--card` 复检，脚本会跳过本篇自己那一行。
