# S4 资讯线写法：热点、政策、生活实用

> **先读** `s4-common.md`（长图文蓝图、开篇、标点、节奏、纪律、真实性），本文件只写资讯线自己的东西：主驱动、数字预算、四层、开头结尾的具体写法、四类题的打法。
> **语料**：先 `corpus/common.md`，再 S2 锁定的那一份垂类文件，只借质感不借句子。

---

## 一、先定主驱动，再定数字预算（治账单味的总开关）

**账单味**是资讯线最容易写出来的毛病：开头报金额、中段拆成本、第三节算对比账、结尾还在问“你们那儿到手多少”，人物只剩一个按计算器的动作。病根是把“切身”等同于“算钱”。读者要的是“这事跟我有关”，钱只是其中一种有关。

| 主驱动 | 文章的主角 | 读者带走什么 | 适合的题 | 数字怎么用 |
|---|---|---|---|---|
| **账本型** | 一笔钱怎么来、怎么没的 | 一个看清了的数 | 外卖、网约车、小店拆账，利率，补贴到账 | 一笔主账，可单设一节拆它，其余各节回到人 |
| **处境型** | 一个人卡在一件事里 | “这说的就是我” | 退休办手续、独生子女陪护、35 岁求职 | 三五个关键数字，不设算账节 |
| **冲突型** | 两方各有各的理 | 一个能吵起来的判断 | 婚假与岗位、业主与物业、婆媳带娃 | 数字只立双方底线 |
| **信息型** | 规则变了怎么办 | 一张能照着做的清单 | 新规实施、年审、补贴申领、防骗 | 只放办事必需的日期、门槛、电话 |
| **情感型** | 关系、体面、说不出口的话 | 一点被理解的感觉 | 过年回谁家、父母老了 | 尽量不用数字 |

具体上限跑 `--rules`；长图文按比例放宽数字个数，换算和堆数段不放宽。

**数字预算五条**：

1. 一篇只立一个主数字，标题、首段、正文反复出现的是同一个数，其余能删就删。
2. 生活换算（“相当于两箱牛奶”）全文最多一次，用在最痛的那个数上。
3. 单段数字不超过三个（账本型拆账那一节除外），连续两段不能都在算。
4. 开头、小标题、结尾三个位置至多一处用数字，结尾永远落在人身上。
5. 每个数字都要有人拿着它：谁看到的、在哪张单子上、看到时在干什么。没人拿着的数字，删。

## 二、开头六式（和资讯线上一篇错开）

| 开头式 | 结构 | 适合 |
|---|---|---|
| 现场动作 | 时间地点 + 人正在做的小事 + 一个打断他的消息或念头 | 通用，首选 |
| 跑腿卡点 | 跑了第几趟、排了多久 + 卡在哪个物件或哪句话上 | 处境型、信息型 |
| 原话顶门 | 一句带刺的原话 + 说话时的现场 + 背后隐情 | 冲突型、情感型 |
| 时间死线 | 离截止还剩多久 + 身边人差点错过的现场 | 信息型（日期必须核实） |
| 直球亮底牌 | 先泼冷水亮结论 + 推翻表面认知 + 真正的卡点 | 熟热点反常识 |
| 账单暴击 | 一个零头金额 + 当事人看到它的动作 + 和预想的落差 | 仅账本型 |

例（只看结构，不照抄）：“这是他这个月第三次从社保大厅二楼下来。手里那张排队小票已经捏软了，窗口只回了一句：先回原单位补档案。”

## 三、主稿四层（每层回答读者心里一个问号，不是四笔账）

1. **他碰到了什么（事实层）**：先写人碰到的事，再带出是哪条新规。政策原文只摘一句最要紧的，其余用人话转述。主数字在这里第一次正式亮相。
2. **为什么偏偏卡在这儿（原因层）**：按题选一两个切口——口径温差（上面定原则，窗口为了免责多要两张证明）、成本转移（明面降了，暗处的门槛和时间补了回来）、谁都不想先让。写人和人的拉扯：窗口的一句话、房东的一个推脱，比三行成本更能讲清卡在哪。
3. **落到这拨人身上意味着什么（落地层）**：按主驱动给一样能带走的东西。账本型对比一次两种处境的账，马上回到人；处境型、冲突型写两种人的两种选择各要付出什么（时间、面子、关系，不一定是钱）；信息型给三到五条今天就能照做的动作，带渠道和时间节点；情感型给一个可以试试的小做法，或者干脆承认没有好办法。
4. **也有人不这么看（碰撞层）**：两三种网友声（真实转述标平台，或概括，不编原话），再把镜头拉回锚点人物。长图文里这一层的最后一两段就是过门，停在人的一个动作上，留一个口子。

长图文的延伸节不再走一遍四层，只接一个问题，常用接法“下一步、另一面、往深一层”（见 `s4-common.md` 第一节）。

## 四、小标题、过渡与结尾六式

**小标题四式**（替代“原因分析”“建议措施”）：处境落点式（“[人]卡住的，从来不是[表面那件事]”）、认知反转式（“口子是松了，可卡住人的是最后那一步”）、原话式（“不怕多跑两趟，就怕每个窗口说法不一样”）、拆解式（仅账本型，全文最多一个）。

**过渡句**（替换“首先、其次、综上所述”）：“要是只看这一条，那还真把事儿想简单了”“这事儿光看文件没感觉，拿[人名]的经历一说你就懂了”“听着挺美对吧？可一落到实际操作上，味儿就变了”“先别急着骂[某方]，站到他那边看看”。

**结尾六式**（必带问号，和资讯线上一篇错开）：

| 结尾式 | 写法 |
|---|---|
| 经历共鸣 | 你办[某事]的时候，有没有碰到过这种卡在最后一页纸的事？底下说说。 |
| 两难选择 | 一边是[A]，一边是[B]，换你怎么选？ |
| 潜台词追问 | 你最近那份外卖，是不是也没以前那个味儿了？ |
| 帮亲友问计 | 像她这种不上不下的情况，该现在办还是再等等？有懂行的支个招吗？ |
| 观点碰撞 | 有人觉得这步迈得太急，也有人觉得早该管了，你怎么看？ |
| 晒坐标 | 你们那儿落地了吗，和宣传的一样吗？（仅账本型、信息型，且不和正文算账叠用） |

## 五、四类题的打法

| 题 | 默认主驱动 | 核心矛盾 | 推进主线 | 必配细节 |
|---|---|---|---|---|
| 政策新规解读 | 信息型 / 处境型 | 文件写着“能办了”，老百姓关心能不能办、怎么不白跑 | 熟人跑腿现场 → 新规一句话 → 哪几类人最容易卡 → 避坑几步 → 各地执行差异 | 排队号票、窗口手写提示条、12345 的原话 |
| 行业生计观察 | 账本型（可选处境型） | 外人看着热闹，当事人越干越心虚 | 凌晨或收摊后的现场 → 一个刺眼的数 → 规则怎么卡住他 → 消费者也没占便宜 → 留白 | 后台截图、凌晨进货、磨损的工具 |
| 社会热点观察 | 处境型 / 冲突型 | 大家吵表面，文章写背后的生计与人情 | 日常切面 → 两类人的不同反应 → 各自在怕什么 → 不做道德审判 | 价签、业主群截图、攒着的塑料袋 |
| 家庭代际与职场 | 冲突型 / 情感型 | 谁都没错，但时间、精力和体面不够分 | 饭桌或走廊上的一句话 → 双方难念的经 → 体面背后的妥协 → 守住底线的务实解法 | 翻扣的手机、阳台上压低声音的电话、分装好的药盒 |

## 六、资讯线事实口径

- 账目自洽：文中的加减乘除动笔时核对一遍，不许“加起来是 A、却写剩 B”。
- 政策细则各地不同：写清是哪里的口径；查不到当地的，直说“咱们县什么时候跟进，我没查到，不敢瞎说”。
- 语料里的金额、比例、实操建议可能过时、各地不同，要用就去核实当地当年的公开页面。

## 七、资讯线自检（在 `s4-common.md` 第八节之外）

- [ ] 立项卡写了主驱动，骨架和它一致：非账本型没有专门的算账节。
- [ ] 一个主数字；换算最多一次；单段数字不超过三个；结尾没有数字。
- [ ] 第二层写的是人和人的拉扯，不是成本表。
- [ ] 第三层给的东西今天就能用：渠道、时间节点、电话，都核实过。
- [ ] 长图文的延伸没有再拆一遍账，没有换一个新主角重讲同一件事。
