# S4 共用写法：两条内容线都要守的东西

> **读法**：S4 先读本文件，再按立项卡的内容线读一份：资讯线读 `s4-news.md`，故事线读 `s4-story.md`；写微头条读 `s4-micro.md`。语料先读 `corpus/common.md`，资讯线再读对应垂类文件，故事线读 `corpus/story/`。
> **规则的数字以脚本为准**：篇幅档、数字预算、词表、及格线都在 `scripts/rules.py`，跑 `python3 scripts/qa_check.py --rules` 看。本文件只讲为什么和怎么写。
> **槽位只用 `[方括号]`**：任何花括号都会被判未替换占位符。

---

## 一、长图文：一张蓝图写主稿和延伸

长图文是默认体裁，约 3000 字：主稿约 2000 字，延伸约 1000 字。它不是“一篇 2000 字的稿子后面再接一篇 1000 字的稿子”，是**一篇稿子分两段走**：主稿回答主问题，延伸接住主稿留下的下一个问题。

### 1. 动笔前先排蓝图

照立项卡把每一节排成一行（可以写进立项卡“蓝图”，脚本会核对小标题）：

| 部分 | 小标题 | 这一节回答什么 | 谁在场、做什么 | 新事实与出处 |
|---|---|---|---|---|
| 引子 | 无 | 一个反常 | 锚点人物的一个动作 | 无 |
| 主稿 1~4 节 | 口语小标题 | 主问题拆成三四个小问号，一节一个 | 同一个人往前走 | 主稿出处 |
| 过门 | 主稿最后一两段 | 留一个口子 | 人停在一个动作上 | 无 |
| 延伸 1~2 节 | 第一个小标题写进“延伸.起始小标题” | 延伸.接的问题 | 同一个人再往前走一步 | 延伸.出处 |
| 收尾 | 延伸节最后一段 | 不回答完，抛给读者 | 一个动作或半句话 | 无 |

排不出延伸那两行，说明下一个问题离读者太远，改写短图文，不硬凑。

### 2. 延伸是扩写，不是拼接

头条首发要求原创。创作者帮助中心《首发激励计划》（2026-05-25 更新）把“拼接要点、整合汇编”“大篇幅引用公共信息（含百科）”判为非原创，把“空洞水化、事件重复描述、网络信息拼凑汇编、模板化标题”列为低成本内容。所以延伸节同时满足四条：

1. **接一个问题**：主稿读完，同一拨读者心里冒出的下一个问号。
2. **同一个人往下走**：锚点人物在延伸节里继续出场、多做一件事；不换主角，不换读者人群。
3. **新事实，自己的出处**：延伸节的硬事实单独核实，记进“延伸.出处”；不复述主稿讲过的事（脚本按 8 字片段查重合度）。
4. **有过门**：主稿最后留口子，延伸第一段接住。两段之间不放“相关阅读”“延伸阅读”这类字样，那等于告诉平台这是两篇拼的。

### 3. 三种接法（每条线各三种，立项卡“延伸.接法”）

| 内容线 | 接法 | 意思 | 反例（这就成了拼接） |
|---|---|---|---|
| 资讯线 | **下一步** | 办完这件事，紧接着碰到的那件事（清完旧手机，旧号码要不要销） | 另讲一遍“换手机注意事项大全” |
| 资讯线 | **另一面** | 同一件事落到同一个人的另一头（她替爸妈办完，轮到自己） | 换一个新人物重新讲同一件事 |
| 资讯线 | **往深一层** | 主稿留下的“为什么”，往制度、来历里挖一层（为什么偏偏要房东配合） | 把政策原文从头到尾贴一遍 |
| 故事线 | **别国同母题** | 别的文明怎么讲同一件事，相同在哪、不同在哪 | 把别国的故事从头复述一遍，不对照 |
| 故事线 | **原典与流行说法** | 原典写了什么、后来的改编和流行说法改成了什么 | 罗列一串影视作品名 |
| 故事线 | **今天的痕迹** | 故事落在今天的地名、习俗、节日、馆藏里的样子（要有出处） | 百科式的“文化影响”条目 |

### 4. 分界与收尾

- 延伸节第一个小标题写进立项卡“延伸.起始小标题”，脚本按它分查主稿和延伸的字数和重合度。
- 互动提问只放在延伸节最后；主稿结尾停在画面或动作上，不问。

## 二、开篇三段：3 秒、7 秒、15 秒

读者划走一篇只要 3 秒。前三段不铺背景、不背公文、不讲“很久很久以前”。

1. **第一段（≤80 字）**：一个人（或神、或鸟）、一个动作、一个反常。开头式按内容线挑，和同一条线的上一篇错开（名单见 `--rules`；每种开头式的写法在 `s4-news.md`、`s4-story.md`）。
2. **第二段（≤120 字）**：锚点人物入场。给他一个账之外的东西：一个习惯、一句口头禅、一个怕。只会算账的人、只会“坚持”的神，都是纸片人。
3. **第三段（一两句，≤50 字）**：亮底牌，一句有态度的实话，点破这篇真正要说的事。

## 三、标点只用规范中文标点（硬闸）

按 GB/T 15834 的大陆用法，标题、小标题、正文一律全角：

| 用 | 不用 |
|---|---|
| 引号“ ”，引号里再引用‘ ’ | 直角引号「 」『 』、英文直引号 " ' |
| ，。；：？！、 | 夹在中文里的 , . ; : ? ! |
| 括号（ ） | 半角 ( ) |
| 省略号……（两个“…”） | 单个 …、三个点 ...、句号连用 |
| 破折号——（两个“—”） | 单个 —、-- |
| 书名号《 》 | 用引号代替书名号 |
| 范围写“到”“至”：1100到1400字 | 波浪号 ~ ～ |

正文不用符号做点缀或列表（· • ● ★ → √ ✓ ※ 之类），要分条就用“先……再……”或另起一段。不留 Markdown 记号：`**加粗**`粘进头条编辑器会原样露出，要强调就在编辑器里加粗；`##` 小标题只在交稿稿里标结构，粘贴时换成编辑器的小标题样式。数字之间的比分、时刻（3:2、10:30）不算违规。间隔号“·”本技能一律不用（用户的硬要求，脚本按装饰符号拦）：书名带篇名写成“《山海经》的《北山经》”，外国人名直接连写（“普罗米修斯”）。

## 四、节奏：给手机屏幕留呼吸

- **六种功能块**：首段钩子（≤80 字）；正文段（单段 ≤150 字，手机约四五行，超了就拆）；呼吸独句（约每 300 字一个，6 到 20 字，独立成段）；口语小标题（全文 3~5 个，长图文主稿 3~4 个、延伸 1~2 个，不用四字对仗）；金句（全文一两处，放小节末尾或反转处）；收尾（最后一段一到三句，带问号）。
- **长短句三拍子**：中长句铺事实（不过 45 字）→ 中句转折（“可问题是”“结果呢”）→ 极短句钉死（“一分没少。”“他没接话。”）。每三句至少一句 10 字以内；连续三段不等长。
- **一节一个问号，不包饺子**：每节结尾留一个没解决的卡点或半句悬念，别把“发现问题、分析原因、给出方案、完美解决”在一节里走完。
- **时间变速**：卡点处放慢十倍（拆成三句动作），过场处快进十倍（一句话跨过两个月）。

## 五、写前八条纪律（动笔第一秒就站在人物的处境里）

去 AI 味最省力的办法不是写完再改，是动笔时就别写出来。改稿时怎么认出这些病，见 `s5-editing.md`。

1. **人物有事，不贴标签**：每段只办一件眼下的具体事。不写“节省”“焦虑”“执着”，写他在谁面前嘴硬、为什么跑第二趟、翅膀上沾了什么。
2. **细节跟着处境走**：只写人物此刻看得见、跟他的麻烦有关的东西，不用无人机式全景镜头罗列环境。
3. **引语在做事**：人物开口是为了试探、诉苦、抬杠、保面子。允许答非所问、话留半截；双方都知道的背景不借人物的嘴念给读者。对话一问一答不超过四拍，中间插一个动作。
4. **规则和背景后置**：先写人物踩到了什么坑，再顺嘴点出是哪条新规、哪部原典。人物没碰到的条款、原典里跟这篇无关的段落，一字不提。
5. **情感配给**：每节最多一个情绪峰值，越是心酸越不写情绪词，写手头在干什么。不总结成“五味杂陈”。
6. **闲笔有来路**：天气、器物、景色可以写，但要跟人物的处境咬合；删掉不影响的就是装饰。
7. **理不占尽**：给建议、下判断，站在平视的位置，承认无奈和自己的认知边界（“这个我没查到，不敢瞎说”）。
8. **结尾落人**：停在一个具体动作、一帧画面、半句实在话上，不升华、不总结寓意、不展望，结尾不出现新数字，然后接一句带问号的提问。

## 六、结尾提问

收尾词别篇篇都是“评论区聊聊”，换着用“底下说说”“留言说说”“你怎么看”（脚本认 评论区、你怎么看、聊聊、留言）。结尾式按内容线各一套，和同一条线的上一篇错开；每种的写法见 `s4-news.md`、`s4-story.md`。

## 七、真实性底线（两条线都适用）

1. **硬事实有出处**：政策条款、金额、日期、机构、原典原文、版本，只来自用户素材或本次打开核实的页面，写进立项卡出处。搜索摘要和 `corpus/` 里的内容都不算出处。查不到就坦白说没查到。
2. **合成人物不冒充亲历**：没有真实案例就用明示口吻（“说一个这阵子挺常见的情形”），不写“我表弟上周刚……”；故事线不用“我奶奶亲口讲过”包装合成情节。
3. **网友声不造假**：真实转述并标平台；没有就概括成“评论区里常见几种声音”，不编昵称、坐标、引号原话。
4. **语料不是素材**：示例人名、句子、语料数字照搬进成稿，是撞脸和失实的头号来源。

## 八、共用自检（交 S5 前，能机检的先跑 `qa_check.py 初稿.md --card 立项卡.json`）

- [ ] 标点全规范：无直角引号、半角标点、波浪号、装饰符号、`**`。
- [ ] 长图文：主稿回答了主问题；延伸接的是立项卡里那个问题，用的是立项卡里的接法；锚点人物在延伸里继续出场；延伸的新事实有自己的出处；没有“延伸阅读”字样；提问只在最后。
- [ ] 前三段：首段 ≤80 字、见人见动作见反常；次段人物有账之外的东西；第三段亮底牌。
- [ ] 节奏：单段 ≤150 字；约每 300 字一个独句段；没有连续三段等长；每节结尾不总结。
- [ ] 细节：每两三段一个具象锚点（动作、物件、地点、原话）；直接引语至少三处。
- [ ] 结尾落在人身上，没有新数字，最后一句带问号。
- [ ] 人称一致，零花括号残留。
- [ ] 防撞脸：人名本篇自起（不用语料示例名）；开头式、结尾式和同一条线的上一篇不同。
