# S2 立项：两条线各自打分，立项卡一次定全

> **核心任务**：把 S1 的候选（或用户给的题材、通稿、政策原文、一个神话故事）变成一张立项卡。立项卡一次定下：哪条内容线、主驱动、体裁、**主稿回答哪个问题、延伸接哪个问题**、锚点人物、开头式结尾式、出处。S3 照它起标题，S4 照它的蓝图成文，S6 拿它核对，S7 拿它记台账。
> **先读两份记录**：`outputs/toutiao/log.csv`（台账，查撞车）和 `outputs/toutiao/feedback.md`（用户改稿记录），存在就先读。
> **槽位只用 `[方括号]`**，不用花括号。

---

## 一、先分线

| 内容线 | 题材 | 主驱动 | 写法 |
|---|---|---|---|
| **资讯线** | 热点、政策、生活实用、社会观察 | 账本型 / 处境型 / 冲突型 / 信息型 / 情感型，五选一 | `s4-common.md` + `s4-news.md` |
| **故事线** | 神话、传说、民间故事、世界各国神话改编 | 故事型 | `s4-common.md` + `s4-story.md` |

拿不准时问一句：读者点进来，是想知道“这事跟我有什么关系”（资讯线），还是想听一个故事（故事线）？节日题两条线都可能，看主角是今天的人还是故事里的人。

## 二、资讯线打分（两把尺子都过线才立项）

### 第一把：五维爆款指数（< 62 淘汰）

`buzz = 冲突度×0.28 + 情绪值×0.22 + 实用性×0.20 + 身份代入×0.18 + 时效性×0.12`（权重是本技能自定的经验值）

| 维度 | 80 分以上长什么样 | 信号词 |
|---|---|---|
| 冲突度 | 有利益受损方、名义利好和实际落地有落差、新旧规碰撞 | 却、争议、门槛、缩水、差额、松动 |
| 情绪值 | 戳中憋屈、焦虑、不平、欣慰或好奇，想转给家里人 | 终于、竟然、担心、算不清 |
| 实用性 | 看完能省钱、省事、少走弯路、防骗，或想明白一件憋着的事 | 怎么、能领、办理、新规、落地 |
| 身份代入 | 指向庞大的明确人群，一眼对号入座 | 老人、家长、打工人、县城、车主、灵活就业 |
| 时效性 | 24 小时内冒头、政策落地满月、卡在节假日或月底 | 今天、实施、上调、月底前，热度 `new` / `up` |

### 第二把：四维互动分（定排产）

`互动分 = 情绪张力×0.32 + 可共情人群×0.28 + 争议空间×0.24 + 二创空间×0.16`

S 档 ≥ 86 当天第一顺位，并规划系列角度；A 档 76~85 当天排产；B 档 64~75 进备选池；C 档 < 64 淘汰。

### 三级降维（宏观题落到一个人身上）

`[热榜原题] → [人群处境与利益切面] → [锚点人物 + 一个具体处境或动作]`

| 热榜原题 | 读者视角立项题 | 主驱动 |
|---|---|---|
| 多地调整住房公积金租房提取条件 | 房租能全额提公积金了，可他最怕的是跟房东开这个口 | 处境型 |
| 多地试点商品房销售取消公摊 | 看了三个月房的小两口，被一句“按套内算”问住了 | 信息型 |
| 城乡居民基础养老金最低标准上调 | 村里大爷每月多领一点，他第一件事是给孙子打了个电话 | 情感型 |
| 规范外卖平台收费 | 一份外卖，小店老板手里到底剩多少 | 账本型 |
| 延长婚假政策落地 | 婚假能休满了，部门里却没人敢先开这个口 | 冲突型 |

五个例子只有一个账本型。**同一周账本型不超过一半**，否则整个账号都是账单味。

## 三、故事线打分（时效看节点）

### 五维故事指数（< 62 淘汰，权重是本技能自定的经验值）

`story = 认知缺口×0.26 + 处境共鸣×0.24 + 改编空间×0.20 + 节点时效×0.15 + 新鲜度×0.15`

| 维度 | 80 分以上长什么样 |
|---|---|
| 认知缺口 | 读者知道名字、不知道细节，或以为知道、其实记的是改编版（精卫、夸父、北欧诸神黄昏） |
| 处境共鸣 | 故事里有一个今天的人也会碰到的处境：认死理、被冷落、替别人扛、说不出口 |
| 改编空间 | 原典留了缝：没写动机、没写结局、配角没开口，补细节不用改大事件 |
| 节点时效 | 卡在节日、节气、影视热播、展览考古的节点上（见 `s1-evergreen.md`）；没有节点按 50 |
| 新鲜度 | 台账 30 天内没写过这个故事和母题；全网近期没有铺天盖地的同一种写法 |

四维互动分照用，“二创空间”改看这个母题能不能换版本、换国家再写。

### 定改编方式（三选一，写进立项卡）

原典重述 / 视角改写 / 母题对照，怎么选见 `s4-story.md` 第二节。连续两篇故事线别用同一种。

## 四、定体裁，同时定主问题和延伸

| 体裁 | 什么时候用 |
|---|---|
| **长图文（默认）** | 2600~3400 字：主稿约 2000 字回答**主问题**，延伸约 1000 字接住主稿之后冒出的**下一个问题** |
| 短图文 | 1100~2200 字。用户要短稿；或者主稿讲透以后，下一个问题离读者太远，硬凑延伸就成了拼接 |
| 微头条 | 300~1000 字。抢一个侧面、一个现场，写法见 `s4-micro.md` |

长图文立项时必须同时写下两个问题，写不出第二个，就改短图文：

- **主问题**：读者看到标题心里冒出的那个问号。例：“卖旧手机前恢复出厂，东西真的没了吗？”“精卫为什么要填海？”
- **延伸.接的问题**：主稿读完，同一拨读者心里冒出的下一个问号。例：“拔下来的旧号码要不要销？”“别的文明有没有这样一趟趟搬的人？”
- **延伸.接法**：资讯线 下一步 / 另一面 / 往深一层；故事线 别国同母题 / 原典与流行说法 / 今天的痕迹。
- **延伸.出处**：延伸节的新事实单独核实、单独记出处。

接法的含义和反例见 `s4-common.md` 第一节。

## 五、资讯线：12 垂类人群与角度库

立项时锁定 1 个精准人群 + 1 个情绪标签（焦虑、不平、共鸣、好奇、欣慰、憋屈）+ 1 个主驱动 + 1 条角度。“切身点”一栏是读者真正在意的东西，钱只是其中一种。故事线垂类统一写“神话传说”。

| 垂类 | 标题触发关键词 | 锁定目标人群 | 切身点（钱 / 时间 / 麻烦 / 面子 / 关系） | 常用主驱动 | 三个切入角度 |
|

## 六、排产纪律与三种状态

对着台账查：资讯线同赛道同日互斥、同一周账本型不超过一半、同一条线连续两篇不用同一种开头式和结尾式、锚点人名不重复；故事线 30 天内不写同一故事或同一母题、连续两篇不用同一种改编方式。

每条候选落进三种状态之一，淘汰和暂缓都要写操作级理由，不许只写“分低”：

1. **立项约稿**：过线，当天排产。
2. **进池备选**：分数够，但同赛道同日、需要补本地口径、或等节点，写明等什么。
3. **淘汰**：例“传闻题材，没有可核实的国内窗口和普通人处境支撑”“涉个案刑事细节，触红线”“本周已排两篇账本型，改处境型或移到下周”“这个故事上个月写过，换母题”。

## 七、产出：立项卡文件 + 一行摘要

复制 `templates/brief.json` 到 `outputs/toutiao/YYYY-MM-DD-slug/立项卡.json` 填实。

| 字段 | 填什么 |
|---|---|
| 内容线 | 资讯线 / 故事线 |
| 垂类 / 人群 / 情绪 | 资讯线 12 垂类之一；故事线写“神话传说” |
| 主驱动 | 资讯线五选一；故事线“故事型” |
| 体裁 | 长图文（默认）/ 短图文 / 微头条 |
| 主问题 | 主稿回答的问题 |
| 延伸 | 起始小标题、接的问题、接法、出处（长图文必填前两项） |
| 蓝图（可选） | 每节一行：部分（主稿或延伸）、小标题、这一节回答什么。S4 照它写，脚本会核对小标题 |
| 改编方式 / 母题 / 故事 / 所用版本 | 故事线必填。母题从 `corpus/story/motifs.md` 里选 |
| 锚点人物 | 名字（本篇自起；故事线就是故事主角）、是否真实案例、来源、人称 |
| 主数字 / 主数字出处 | 账本型必填，其他可空 |
| 开头式 / 结尾式 | 按内容线各一套，跑 `python3 scripts/qa_check.py --rules` 看名单 |
| 主标题 / 备选标题 | S3 定稿后回填 |
| 出处 | 每个硬事实一条：事实 + 链接（或“用户素材”）；故事线写所用原典与版本 |

```
[S2] [内容线] 选题“[一句话方向]” 分=[五维] 互动=[四维]（[档]） 主驱动=[…] 体裁=[…] 主问题=[…] 延伸接=[…] 人物=[名字·合成/真实] 状态=[立项约稿 / 进池·理由 / 淘汰·理由]
```
