# 语料库 · 三农乡土（农村自建房 / 种地成本 / 返乡创业 / 新农合缴费 / 农村人情酒席）

## 核心人物画像

- `在老家种了四十亩地的三舅`（57岁，皮肤晒成黑红色，算起化肥种子账来精确到毛）
- `村口当了二十年会计的老支书`（64岁，夹着个掉了皮的黑色公文包，全村哪户几口人一口报出）
- `从广东电子厂回乡包山养鸡的堂哥`（36岁，回来干了两年，抖音号发了八十条视频才几百粉丝）

## 场景与对接人
村委会大门口的水泥晒台 / 院子正中间的老枣树下 / 逢五排十的镇集市农资店门口；镇政府包村干部 / 村委会会计 / 镇农技站老李。

## 高辨识度动作与道具细节

- 院里水泥地上摊着金黄的玉米粒，木掀立在墙根，几只土鸡在晒垫边缘偷刨。
- 自建房审批图纸卷成筒塞在三轮车座垫底下，拿出来时四个角已经磨起了毛边。
- 镇集市上大白菜八毛一斤，三舅蹲在磅秤边跟收菜贩子为两分钱磨了十来分钟。
- 村口红砖墙上刷的通知被秋雨泡过一轮，白纸发脆，但盖着红章的截止日期还看得清。

## 当事人扎心原话库

- “城里人觉得回农村有院子有地就是神仙日子，那是没算过化肥、柴油和浇地电费这三笔硬账。”
- “新农合一人四百块看着不多，可农村一家老小六口人凑一块就是两千四，赶上秋粮没卖上价，真得犹豫好几天。”
- “现在村里办事不比往年，随礼起步两百，十一黄金周连吃八场酒，半季玉米白种了。”

## 专属实操建议

- 农村翻建老屋或新批宅基地，动第一锹土之前必须先拿到镇里盖章的《乡村建设规划许可证》，别听施工队说“先盖起来再补票”，一旦被卫片执法拍到拆改损失巨大。
- 耕地地力保护补贴和种粮补贴现在全打进“社保卡一卡通”金融账户，老人的旧存折如果停用了要及时去农商行换绑。
- 回乡包地流转搞种养，合同必须经过村委会备案，且白纸黑字写清“青苗补偿归属”和“极端天气免责条款”。
