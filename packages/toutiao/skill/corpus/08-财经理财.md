# 语料库 · 财经理财（存款利率下调 / 定期搬家 / 个税专项扣除 / 黄金波动 / 养老攒钱）

## 核心人物画像

- `单位传达室值班的老郑`（58岁，手里攒了28万养老钱，全村跑遍比哪家银行三年期利率高0.15%）
- `在城商行柜台干了八年的老同学小周`（34岁，每天接待几十个来问定期转存的大爷大妈）

## 场景与对接人
银行网点排长队的等候区 / 手机银行App资产页面前 / 单位走廊尽头的茶水间；银行大堂经理 / 理财客户经理 / 税务局个税汇算咨询窗口。

## 高辨识度动作与道具细节

- 银行门口LED电子屏滚动着最新挂牌利率，老郑背着手站在台阶下盯了两分钟，摇摇头转身走了。
- 客户经理拿出一张A4纸，用圆珠笔画了三条线，把“定期存款”和“理财产品”的区别讲得很慢。
- 20万到期资金从大行取出来，骑着电瓶车跨了两条街存进城商行，三年算下来多出1800块利息。
- 活期存折翻到最新一页，季度结息那一栏印着：6.24元。

## 当事人扎心原话库

- “老百姓存钱不是为了跑赢通胀发大财，是为了家里万一有人进医院，半夜能立马掏出钱来。”
- “你盯着人家那点高息赠品，人家盯的是你攒了半辈子的养老本金。”
- “利率从3字头一路掉到1字头，看着只是小数点动了一下，老两口一年买菜的钱就这么少了一小半。”

## 专属实操建议

- 家里存款如果超过50万，分开存进两到三家有“存款保险标识”的正规银行，每家本息合计控制在50万以内最稳妥。
- 去银行存钱遇到工作人员推荐“收益高一点的定期替代品”，一定指着合同问清楚四个字：“这是存款，还是保险/理财？保本写在哪一行？”。
- 每年12月1日到31日之间，务必打开“个人所得税App”确认一次下一年度的专项附加扣除（赡养老人、子女教育、房贷利息），漏点一次可能多扣上千块税。
