# 语料库 · 通用底座（每次 S4 先读这份；资讯线再读对应垂类文件，故事线再读 corpus/story/）

> **两条线怎么取**：资讯线用下面全部；故事线只用第一节的“网友声写法”、第二节人称锁和第三节金句母体的句式思路，母题与版本线索在 `corpus/story/motifs.md`，写法质感在 `corpus/story/texture.md`。
> **核心用法**：S4 动笔前，先取“全局共用资产”（时间、网友声写法、金句母体；零头金额与换算表**只给账本型和需要主数字的稿子用**），再打开 S2 锁定垂类的那一份（`corpus/01-民生社保.md` …… `corpus/12-文旅消费.md`），取“人物底色 / 现场场景 / 动作道具细节 / 扎心原话 / 落地建议 / 垂类金句”。只读用得上的那一份。
> **先人后账**：取素材时先挑人物和动作道具，最后才看金额。一篇稿子里，人物的习惯、顾虑和动作应该比数字多。
> **防撞脸铁律**：语料库是**处境与质感的支点**，不是让你一字不改照抄的台词！具体句子必须顺着当篇选题重新长出来，数字必须前后算术自洽。
> **人名每篇自起**：下面的人物（老周、陈阿姨、胖嫂……）是示例。成稿里的人要另起名字、另配年龄和职业，并和发稿台账里最近的稿子错开；`qa_check.py` 发现示例人名会在 hints 里提醒。
> **数字和建议不是出处**：这里的金额、比例、政策口径和“专属实操建议”是写作质感参考，可能过时，也可能各地不同。写进稿子前必须按 `references/s4-common.md` 第七节核实到当地、当年的公开页面；核实不了就别写成事实。
> **槽位符号铁律**：所有待填槽位一律使用 **`[方括号]`**（如 `坐标[地]`、`差出[钱]`），**严禁使用 `花括号（{ }）`**（会被 `qa_check.py` 判为未替换占位符一票否决）。

## 一、全局共用底座资产（跨垂类通用）

### 1. 生活化时间坐标（拒绝“近日/不久前”）
- **精确时刻**：上周三下午四点半 / 前天早上六点二十 / 昨晚十一点四十 / 礼拜天大清早 / 中午十二点刚过饭点
- **生活节点**：上个月发工资那天 / 五一放假前两天 / 开学头一个礼拜 / 去年交取暖费那阵子 / 腊月二十六赶集那天 / 月底结账那两天

### 2. 非整数零头金额与“颗粒度换算”参照表（账本型专用；全文换算最多一次）

> **量级匹配原则**：主账单写“两万三千八”，零头配“四千一、三千二”；主账单写“680块”，零头配“一百二、八十六块五”；主账单写“25块”，零头配“6块08分、1块2”。

### 3. 网友声写法（真实优先，概括兜底，不编昵称）
- **优先用真实声音**：从本次核实过的报道、原帖评论区里取 2~3 种不同处境的说法，**转述**并注明来自哪类平台（“原帖下面有位在县城开店的网友算过……”）。
- **没有真实来源时只能概括**：写成“评论区里常见三种声音：一种是……，一种是……，还有人……”，**不编网名、不编坐标、不给概括加引号冒充原话**。
- **下面六类是“声音类型”，用来提醒你别只写一种立场**，不是可以直接加引号贴进稿子的“原话”：
  - *跑腿折腾派*：“坐标`[地]`，上礼拜刚替我爸办完，问了三个人给三个说法，最后还是自己跑了一趟二楼窗口才落定。”
  - *精打算账派*：“我拿计算器算了一笔，按新标准一年下来能差出`[钱]`，虽说发不了财，但够给家里老人买两箱牛奶、提两桶花生油了。”
  - *防变味审慎派*：“政策初衷看着挺实在，就怕到了底下执行的时候又加土门槛，希望别又是一阵风。”
  - *现身说法派*：“我们这边上个月已经按这个办上了，钱是真到账了，就是排队排得人心焦，建议大家错开周一上午去。”
  - *冷暖自知派*：“说实话我头一个反应是不敢信，后来专门去官网翻了红头文件才认，早点把话讲这么明白多好。”
  - *两难叹息派*：“道理谁都懂，可落到一家一户头上，一边是`[A]`，一边是`[B]`，哪有那么容易选？”
- **改写示范**：✗“@南墙下的猫：坐标石家庄，上礼拜刚替我爸办完……” → ✓“不少替父母跑过手续的人说，同一个问题问三个窗口能听到三种说法，最后还是得自己跑一趟。”

### 4. 通用基层办事活路建议（写第三节“怎么办”时按需调用）
- 去窗口前先把身份证、户口本、旧卡摆一块儿用手机拍张照存相册，很多时候卡的就是一张复印件。
- 别光在短视频里看别人怎么说，直接拨 `区号 + 12345` 问一句当地执行口径，比在网上搜三天管用。
- 把截止日期和受理回执单号用红笔圈在日历或本子上，基层办事80%的亏都吃在“超期三天”上。
- 凡是电话或群里催着让你“先交一笔手续费/保证金才能领补贴”的，一律挂断电话去社区核实。
- 同一个问题如果在窗口问第一个人说“办不了”，隔天换个窗口或打上级专线再问一次，往往有转机。
- 能在政务App或小程序上试办的先在手机上点一遍，哪怕卡住也能看清缺哪张表，省下半天请假扣的全勤奖也是钱。

### 5. 通用底层暗账逻辑（写第二节“为什么偏偏卡在这儿”时调用）
- **中间层走样账**：上面定的是惠民大标准，中间转一手，到了具体办事窗口，为了“不出差错”往往会多要两张证明。
- **资金出处账**：钱从哪个池子里出、地方配套出多少、能持续补多久——这三件事没掰扯清楚，执行起来就会打折扣。
- **存量让利账**：蛋糕就这么大，新规让一方省了钱，就必然要另一方吐出利润，而让既得利益方吐钱从来是最难的。
- **隐性转嫁账**：明面上的门槛或费率确实降了，但暗地里的考核、捆绑成本或时间成本又从别的口子找补了回来。

## 二、称谓与人称一致性防错锁（S4/S5 必核）

- **女性角色锁定 `她`**：凡是称呼含 `阿姨 / 表姐 / 姐 / 嫂 / 妈 / 母亲 / 媳妇 / 婶 / 娘 / 奶奶 / 姑 / 姨 / 女士 / 小姑娘` 的人物，**全文从头到尾一律使用“她”**。
- **男性角色锁定 `他`**：凡是称呼含 `大爷 / 叔 / 舅 / 哥 / 表弟 / 老周 / 老马 / 老赵 / 老吴 / 老郑 / 师傅 / 小伙子` 的人物，**全文一律使用“他”**。
- **同段核对原则**：`qa_check.py` 会标出同一自然段里同时出现“他”和“她”的段落（AI 味每段轻扣 `-3`，并在风险清单里提醒人工核对）。一段里写两个异性人物很正常，读起来不会指错人就行；容易指错时，第二个人用称呼（“老伴”“儿子”“表姐”）代替代词。

## 三、金句构造（全文 1~2 处，放小节收尾或认知反转处）

> 一句顶一段，必带具体名词（钱/房租/算法/规则/体面），不写心灵鸡汤。各垂类的现成金句在对应垂类文件末尾，只借句式，别照抄。

### 八大金句母体
1. **【身份错觉反转式】你以为A，其实B**
   - 范例：“你以为我在赚食客的钱，其实我在给房东、平台和包装袋厂打工。”
   - 范例：“你以为你用满减券薅到了羊毛，其实羊毛早就折进少给的那两块鸡腿肉里了。”
2. **【规则归因穿透式】当所有人都在A，问题不在人，在规则**
   - 范例：“当一个行业里连最勤快的人都在喊算不清账，问题多半不在人身上，在分钱的规则上。”
3. **【新旧概念置换式】说白了，A 成了新的 B**
   - 范例：“说白了，流量成了新的房租。以前你跟房东谈，现在你跟算法谈，而算法不跟你谈。”
4. **【程度降维暴击式】对[行业/人]来说，‘够用’比‘完美’可怕得多**
   - 范例：“对靠手艺吃饭的人来说，最怕的不是对手比你强，是甲方觉得便宜货已经‘够用’了。”
5. **【面子剥离还原式】东西一旦不承担A，就终于只承担B**
   - 范例：“一件东西一旦不再承担送礼的‘面子’，就终于只用承担它自己的价钱。”
6. **【明暗双账对比式】明面上省的是A，暗地里搭进去的是B**
   - 范例：“明面上看是省下了八十块钱门票，暗地里搭进去的是一家老小在太阳底下排队的三个钟头。”
7. **【底线诉求白描式】不指望A，只盼着B**
   - 范例：“普通人过日子，从来不指望天上掉馅饼，只盼着办事的规则能写在一张明明白白的纸上。”
8. **【时间代价揭示式】以前拿A换B，现在连换的口子都窄了**
   - 范例：“以前总觉得年轻能拿熬夜换钱，过了四十岁才明白，医院窗口收走的每一分钱都带着当年的利息。”
