# 语料库 · 社会观察（老街早餐摊 / 社区老年食堂 / 菜篮子物价 / 老小区供暖 / 夜班摆摊）

## 核心人物画像

- `在老街口支了十年早餐摊的胖嫂`（49岁，每天凌晨三点半和面炸油条，手腕上永远贴着一贴止痛膏药）
- `每天十点四十准时端着不锈钢饭盒去社区食堂排队的独居赵大爷`（74岁，老伴走了三年，孩子们都在外地）

## 场景与对接人
冒着白气的清晨街口早餐摊 / 社区助老食堂刷卡机前 / 冬夜亮着黄灯的公交末班车站；社区网格员 / 市场监管巡查员 / 街道办民生科干事。

## 高辨识度动作与道具细节

- 胖嫂一边用长筷子翻着油锅里的油条，一边在心里盘算：这礼拜面粉每袋涨了六块，豆油涨了八块，可一根油条一块五的价牌愣是没敢改。
- 社区食堂十一点整才开窗打饭，十点四十门口已经排了七八个拎着保温桶的老人，凑一块儿比谁家今年的白菜便宜。
- 末班公交车最后一排角落里，穿工装裤的师傅靠着车窗睡着了，解放鞋帮子上还沾着干硬的水泥灰。
- 临街店铺的卷帘门拉下来一半，头顶那根老式日光灯管闪了三下才亮起来。

## 当事人扎心原话库

- “一碗面敢涨一块钱，明天老主顾就能少来一半；可要是不涨，我两口子每天干十四个钟头就是纯赚个热闹。”
- “社区食堂两荤一素卖12块，老人还嫌比自己在家做贵；可卖9块的话，没有补贴连厨师工资都发不起。”
- “一条街活不活，别看商场修得多气派，就看晚上九点以后，那些卖炒粉、修鞋配钥匙的小摊还在不在。”

## 专属实操建议

- 老小区遇到停水停暖或路灯不亮，单个住户打电话给物业往往石沉大海；在业主群里统计好门牌号，集中打12345或向街道社区书记反映，解决速度快三倍。
- 想出摊做小生意的，千万别一上来就花几万块加盟网红摊车；先去夜市蹲三天数数真实客流，问清城管划定的合规疏导点位置和时段。
- 老年人去社区食堂就餐前，先带身份证去居委会登记“高龄/助老就餐卡”，往往每顿能直接减免2到4块钱。
