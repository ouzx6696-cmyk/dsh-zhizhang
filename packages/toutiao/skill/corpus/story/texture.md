# 故事线写法质感（原则与方法，不是范句）

> **用法**：S4 写故事线前读一遍，S5 回看时对照第四节。这里只讲怎么找细节、怎么定声线，**不提供可以直接搬进稿子的句子**：同一个账号用同一批“漂亮句子”写十个神话，就是平台点名的模板化拼装。

---

## 一、从原典的缝里找细节

原典大多很短。补细节不是编新情节，是在原典写到和没写到的交界处，补一个合理的、看得见的东西。动笔前把原典逐句过一遍，每句问四个问题：

| 问 | 找什么 | 补的边界 |
|---|---|---|
| 它写了什么样子 | 颜色、形状、声音（如“文首、白喙、赤足”“其鸣自詨”） | 用原典给的样子做锚，不另起一套外貌 |
| 它没写什么动作 | 原典一句“常衔木石”，中间省掉了起飞、落海、返程 | 补动作的过程，不补新事件 |
| 它没写什么理由 | 为什么搬、为什么射、为什么回头 | 可以写人物“可能”怎么想，用推测口吻，不写成原典说的 |
| 它没写结局 | 海填没填平、人回没回来 | 不替原典补结局；“原典没写”本身就是好素材 |

## 二、神的身体感

让读者“摸得到”一个神或一只鸟，靠的是重量、温度、距离、疲劳，而不是形容词：

- 重量：衔得动多大的东西，扛着走了多远。
- 温度与湿度：海风、盐、日头，落在身体的哪个地方。
- 距离：从哪座山到哪片海，原典给了地名就用地名，不编里程。
- 疲劳与重复：第几趟和第一趟有什么不一样。
- 声音：原典记了叫声、哭声、歌声的，抓住它。

## 三、声线：说书人的大白话

- **像在饭桌上讲给一个没听过的人**：句子短，先说画面，再说来历。
- **不拽文**：原典短句可以引，引完马上用大白话接住；不写“只见”“端的是”“但见”这类章回体腔调，也不写成网文的“霸气侧漏”。
- **推测要标出来**：“原典没说它累不累”“可以想见”“也许”，读者分得清哪句是原典、哪句是你补的。
- **时间感**：别用“很久很久以前”“在远古时代”起手。直接从一个时刻进去。

## 四、故事线的套话清单（S5 回看时对照）

| 套话 | 毛病 | 改的方向 |
|---|---|---|
| 相传在远古时代 / 很久很久以前 | 万能开头 | 从最有画面的一刻进去 |
| 天地为之动容 / 感天动地 | 抽象情绪 | 写一个具体的反应：浪、风、旁观者的一句话 |
| 这个故事告诉我们 / 给我们的启示 | 寓意说教 | 停在原典最有分量的那一句或那个画面 |
| 中华民族自强不息的精神 | 大词空转 | 落到这一个角色、这一个动作上 |
| 考古证实 / 真实存在 | 史实化 | 没有出处就删，有出处就写成转述 |
| 它眼中闪过一丝坚毅 | T2 聚集 + 拟人过头 | 一只鸟的动作，就写鸟的动作 |

## 五、别国神话怎么写才不像百科

- 只讲和本篇母题可比的那一段，其余一句带过。
- 先说相同，再说不同；不同之处要落到一个具体的细节上（一个是自己选的，一个是被罚的）。
- 外国人名用通行译名，第一次出现时可以补一句身份，不堆族谱。
- 不评高下：不写“西方神话更残酷”“中国神话更有人情味”这类一刀切的结论。
