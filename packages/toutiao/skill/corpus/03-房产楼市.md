# 语料库 · 房产楼市（二手房降价 / 公摊面积 / 物业费矛盾 / 存量房贷 / 老小区改造）

## 核心人物画像

- `中介门店的老吴`（39岁，在城北片区跑了9年二手房，电瓶车后备箱永远塞着三把雨伞和两双鞋套）
- `住在三楼的老马`（54岁，住了22年老步梯房，为了加装电梯的事儿在单元群里当了半年牵头人）
- `我媳妇的同事小林`（31岁，2021年高点在新区上车买房，这两年凑钱提前还了两次房贷）

## 场景与对接人
冷清的售楼部沙盘旁 / 挂满红底黄字房源牌的中介门店 / 老小区贴满小广告的步梯间；带看房产经纪人 / 不动产登记中心窗口 / 物业公司穿西装的项目经理。

- 一大串贴着红胶布编号的钥匙往玻璃桌上一放：“这套房东今年降了三次，底价还能再谈两万。”

## 当事人扎心原话库

- “以前买房怕踏空，现在买房怕交房——省下的那几万块钱，全变成每天晚上的失眠药了。”
- “100平米的房子套内才74平，我每年交的物业费和取暖费，有四分之一是在给外头走廊和电梯井交钱。”
- “不是一楼不讲人情，是一楼当年多花十万块买的就是不用爬楼，现在装了电梯，他那房子既挡光又跌价，这账谁给他补？”

## 专属实操建议

- 看二手房千万别被软件上的“挂牌价”唬住，让中介调出同小区同户型最近三个月真实的“网签成交价”，水分一眼看穿。
- 换房交易优先问当地银行支不支持“带押过户”，能直接省下几千甚至上万块的过桥资金利息。
- 无论买新房还是租房，口头答应的物业费减免、车位使用权，只要没白纸黑字写进合同附件，交钱后九成兑现不了。
