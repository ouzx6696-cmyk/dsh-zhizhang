# 语料库 · 汽车出行（新能源续保难 / 节假日高速充电 / 油价调整 / 养车成本 / 老车年检）

## 核心人物画像

- `跑专车和网约车五年的表哥大强`（38岁，开一台纯电轿车，一年跑9万多公里，对全城每根快充桩几毛钱一度电门儿清）
- `开汽修厂十五年的老魏`（46岁，修车从不乱换件，店里举升机旁常年摆着几桶废机油）

## 场景与对接人
4S店售后休息区 / 高速服务区排队的充电桩旁 / 汽修厂升起来的底盘底下；4S店售后顾问 / 保险公司出单员 / 车管所年检线外的工作人员。

## 高辨识度动作与道具细节

- 冬天凌晨充电枪的黑电缆冻得邦邦硬，大强戴着线手套两只手使劲才掰弯插进车口。
- 续保报价单摊在引擎盖上，被冷风吹得哗哗响，第二年保费比第一年反而贵了680块。
- 仪表盘上的总里程停在“98420公里”，距离三电终身质保规定的年度里程上限只剩一千五百公里。
- 4S店给的保养清单密密麻麻列了11项，老魏拿红笔咔咔划掉7项：“这几个全是智商税，换机油机滤就够了。”

## 当事人扎心原话库

- “一年跑不到一万公里的家庭，为了省那两千块油钱买高价电车，省下的油钱全贴进保费和折旧里了。”
- “平时在市区充电一毛多一公里确实香，可赶上过年回老家在服务区排队抢桩那三个小时，真想把车卖了。”
- “买车只是一锤子买卖，后面每年的保险、停车费、小刮小蹭，才是钝刀子割肉。”

## 专属实操建议

- 买新能源车签合同前，一定问清“三电终身质保”的免责苛刻条件（比如：一年限跑3万公里、必须全程在4S店保养、换过一次二手户直接作废）。
- 车险到期前一个月，同时找三家不同保司的直营渠道比价，别轻易出几百块钱的小额商业险，出一次险接下来三年保费上涨的钱远超修车费。
- 节假日跑长途高速，当电量剩30%或油量剩四分之一时，宁可提前下高速去出口2公里外的县镇充/加油，比在服务区死排两小时快得多。
