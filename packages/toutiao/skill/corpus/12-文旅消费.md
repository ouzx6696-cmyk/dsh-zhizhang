# 语料库 · 文旅消费（景区免门票 / 老年低价游 / 县城电影院 / 错峰出行 / 宠物看病账）

## 核心人物画像

- `刚跟着99元三天两晚夕阳红团回来的退休三姨`（62岁，大包小包拎回三床蚕丝被和两盒乳胶枕，回来一查网价傻了眼）
- `在县城商场电影院干了四年的检票员小周`（27岁，见证了春节档人挤人和工作日包场的巨大落差）

## 场景与对接人
景区大门口的摆渡车检票闸机旁 / 工作日只开了一半灯的县城影院大厅 / 旅行社贴满特价海报的门店；举小旗的跟团导游 / 景区游客服务中心 / 宠物医院前台。

## 高辨识度动作与道具细节

- 五十多人的大巴团早上五点半集合，导游手里的小黄旗被冷风吹得卷成一团，第一站直接拉进了郊区玉石产业园。
- 景区免了80块钱的大门票，可停车场离核心景点还有9公里，景区观光车往返一人必买60块。
- 电影票根夹在透明手机壳背面，两张票加一桶爆米花花了118块，散场时后排观众都在吐槽不值票价。
- 旅行社给的A4纸行程单折了四折，第四天上午那栏用极小的字印着：“民俗文化体验馆（停留约120分钟）”。

## 当事人扎心原话库

- “大门票是免了，可从你把车停进景区停车场那一秒起，摆渡车、索道、烤肠、矿泉水，每一道关卡都在等着补票。”
- “99块钱连来回大巴油费都不够，人家凭什么管你三天吃住？还不是指望你在关了门的屋子里掏那几千块买床垫。”
- “现在大家出门旅游不是舍不得花钱，是烦透了那种花钱买罪受、拿游客当冤大头的套路。”

## 专属实操建议

- 父母要报老年旅行团，儿女一定帮着看一眼行程单：凡是团费低于正常往返路费、且写着“政企补贴/康养基地体验”的，100%是购物团，宁可自己出钱给爸妈定纯玩团。
- 去热门景区前先在社交平台搜“XX景区 避坑 摆渡车”，看清楚免票后有没有强制捆绑的交通车票。
- 带宠物去医院看病，进检查室抽血拍片前先让医生拉一张“分项报价单”，确认每一项检查的必要性再签字，能省下一半冤枉钱。
