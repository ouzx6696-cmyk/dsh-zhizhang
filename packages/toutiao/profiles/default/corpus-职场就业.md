# 语料：职场就业

适用：35 岁求职、裁员降薪、调岗、小店经营、骑手与网约车司机、考公考编、灵活就业。常配主驱动：处境型、冲突型、账本型（小店拆账）。
用法见 corpus-common 开头：人名自起；下文数字、渠道都是写法示范，以本次核实的出处为准。

## 读者与处境

- 干了十来年执行岗的中年员工：房贷还剩一大截，公司开始“优化”，不敢先开口谈。
- 城中村小店老板：凌晨进货、深夜收摊，外卖平台和房租两头压，越干越算不清账。
- 二十多岁大专生：送过外卖、换过两份工作，住隔断间，在考编和进厂之间来回想。
- 被要求签调岗或降薪单的人：怕签了吃亏，不签又怕被耗走。

## 现场与细节

- 地点：写字楼消防楼梯间、人才市场最里排展台、商圈骑手驿站、油烟熏黑的小店后厨、出租屋的折叠桌。
- 对接人：说话客气的人事、平台站长、劳务派遣中介、劳动仲裁窗口。
- 物件动作：
  - 工牌摘下来放在桌上，塑料壳背面还夹着一张饭卡。
  - 简历改到第十一版，把期望薪资往下调了一档，最后只打了一页。
  - 面试完在楼梯间站了两分钟，擦了把脸才给家里打电话。
  - 工位上的绿萝刚冒新芽，下面的纸箱已经用胶带封了十字。
  - 骑手头盔挂在电动车把上，充电宝的线从袖口穿出来。
- 数字口径：说“到手”不说“税前”，说“一个月扣多少”“赔几个月”，说“单价掉了几毛”。经济补偿怎么算、社保断缴影响什么，各地口径不同，以当地人社部门或法律条文原文为准。

## 人会这么说

- 试探：“这个月绩效怎么又是 B？我哪项没做到，你直说。”
- 嘴硬：“降点就降点，我又不是只能干这个。”说完把简历又打开了。
- 算账：“我以为在赚食客的钱，结果开门那一刻起就在给房东和平台打工。”

## 读者真问题

- 公司让我签调岗、降薪或“自愿离职”，签了会失去什么？
- 被裁了，补偿怎么算，找谁申请仲裁？
- 社保断了几个月，会影响哪些资格？
- 35 岁以后还能投哪些岗，招聘写“年龄不限”是真的吗？
- 送外卖、跑网约车，一天到底能落多少？

## 好角度

- 签与不签：把一张单子摆在人面前，写他拿着笔的那几分钟。示范：“人事把协议推过来，说下午五点前给个答复。他把手机计算器打开，又关上了。”
- 小店的糊涂账：一个主数字，其余回到人。账本型示范见 corpus-benchmark 第一篇。
- 门槛之后：35 岁那根线卡掉的不只是岗位，是剩下的选项变成什么样。写他看到的第三份招聘启事。
- 反例：“职场人要提升核心竞争力”“拥抱变化”，没有一个具体岗位、一张具体单子。

## 雷区

- 劳动法相关的补偿标准、仲裁时效、试用期规定一律引原文或人社部门公开解读，不凭印象写。
- 不点名具体公司裁员，除非有公开报道；不编“内部消息”。
- 骑手、司机收入因城市、时段差异极大，写成“他这个月”的个案，不写成行业平均。
- 招聘年龄歧视、加班费等话题容易写成情绪宣泄，判断要有出处支撑。
