# S4 微头条写法（两条线都能用）

热点刚冒头来不及写长文时抢一个侧面；一个现场、一句话就能立住的小切口；给长图文试风向。标点、纪律、事实写法照 s4-common。

没有标题、没有小标题，第一句就是标题。存稿时不写“# ”行，直接从首句开始；立项卡体裁填“微头条”，质检自动按微头条查。

## 一、结构

| 位置 | 篇幅 | 做什么 |
|---|---|---|
| 首句 | 8到30 字 | 人 + 正在做的事 + 一个反常，或一句原话。质检拿它当标题打分 |
| 现场 | 一到三段 | 在哪、手里拿着什么、说了什么 |
| 转折 | 一到两段 | “可他说完又补了一句”“后来才知道” |
| 落点 | 一段 | 停在动作或一句实话上 |
| 提问 | 一句 | 带问号，含互动词 |

全文 300到1000 字（档外只轻扣）；四段以上，每段一到三句；最后一段不出现数字；配图一到三处，单独一行【配图：画面描述】；至少一处直接引语；数字零到两个。

## 二、首句六式

1. 现场动作：“楼下修鞋的[人名]，今天把摊子往里挪了半米。”
2. 原话顶门：“‘这钱我不要了，你们别再打电话了。’网格员说，这是她这礼拜第三次听到。”
3. 反常结果：“全楼就三户没签加装电梯同意书，其中一户是牵头的那家。”
4. 身份点名：“替爸妈办过异地医保备案的，可能都卡过同一步。”
5. 时间节点：“离医保缴费截止还有一个礼拜，[人名]那份还没交。”（日期核实）
6. 直球判断：“说句可能挨骂的：社区食堂贵两块钱，不全怪食堂。”

## 三、故事线微头条

一个原典细节 + 一个画面 + 一个问题。版本和出处照 s4-story。不写成“冷知识合集”，那是拼凑汇编。

## 四、更容易踩的坑

- 第一人称硬事实冒充新闻（“我表弟上周刚提了三千多”）：没有真实案例不能写。
- 拿真实的人编段子：只用公开报道里的说法。
- 情绪词撑场（“看哭了”）：换成动作和物件。
- “点个关注不迷路”“转给需要的人”不算互动，后者还可能命中诱导分享。

## 五、标杆骨架

```
楼下修鞋的老钟，今天把摊子往里挪了半米。
不是城管来了。是隔壁新开的奶茶店排队，队伍一长就挡住他的小马扎。……
老钟那天收了她十块钱，比平时少要了一半。……
你家附近还有这样的老摊子吗？评论区说说。
```

首句见人、见动作、见反常；第二段先否定读者的猜测；结尾停在动作上再问。老钟是示例名，真发稿另起名字。交稿用 s7-delivery 的微头条精简版。
