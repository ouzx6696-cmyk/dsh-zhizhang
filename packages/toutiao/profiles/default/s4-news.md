# S4 资讯线写法

资讯线成文时在 s4-common 之后读。语料取 corpus-common 和垂类那一份，只借质感不借句子。

## 一、先认主驱动，再给数字

账单味是资讯线头号病：开头报金额、中段拆成本、结尾还在问“你们那儿到手多少”，人物只剩按计算器。病根是把切身等同于算钱。

| 主驱动 | 主角 | 读者带走 | 数字上限 | 换算 | 堆数段 |
|---|---|---|---|---|---|
| 账本型 | 一笔钱怎么来、怎么没 | 一个看清了的数 | 18 | 1 | 2 |
| 处境型 | 一个人卡在一件事里 | “说的就是我” | 8 | 1 | 0 |
| 冲突型 | 两方各有各的理 | 一个能吵的判断 | 8 | 1 | 0 |
| 信息型 | 规则变了怎么办 | 照着做的清单 | 14 | 1 | 1 |
| 情感型 | 关系、体面、说不出口的话 | 被理解的感觉 | 4 | 0 | 0 |

数字上限按短图文，长图文乘 1.5，换算和堆数段不放宽。数字指阿拉伯数字和带量词的中文数字（“三趟”“两千块”）；换算指“相当于”“顶得上”“够……交”“折合”；堆数段指一段 4 个数以上。超了逐个扣细节分，现行值以 `toutiao_rules` 为准。

用数五条：

1. 只立一个主数字，标题、首段、正文反复出现的是同一个，写进立项卡。
2. 换算最多一次，用在最痛的那个数上。
3. 单段不超过三个数（账本型拆账那节除外），连续两段不都在算。
4. 开头、小标题、结尾至多一处用数，结尾永远不用。
5. 每个数都有人拿着：谁看到的、在哪张单子上、看到时在干什么。没人拿着的删。

非账本型不设算账节。

## 二、开头六式（和资讯线上一篇错开）

| 开头式 | 结构 | 适合 |
|---|---|---|
| 现场动作 | 时间地点 + 正在做的小事 + 打断他的消息 | 通用 |
| 跑腿卡点 | 第几趟、排多久 + 卡在哪个物件或哪句话 | 处境型、信息型 |
| 原话顶门 | 带刺的原话 + 现场 + 隐情 | 冲突型、情感型 |
| 时间死线 | 离截止还剩多久 + 身边人差点错过（日期核实） | 信息型 |
| 直球亮底牌 | 先亮结论 + 推翻表面认知 + 真卡点 | 熟热点 |
| 账单暴击 | 一个零头金额 + 看到它的动作 + 落差 | 仅账本型 |

示意：“这是他这个月第三次从社保大厅二楼下来。手里那张排队小票已经捏软了，窗口只回了一句：先回原单位补档案。”

## 三、主稿四层（每层一个问号，不是四笔账）

1. 他碰到了什么：先写人碰到的事，再带出哪条新规；原文只摘一句，其余说人话。主数字在这里亮相。
2. 为什么偏偏卡在这儿：口径温差（窗口为免责多要两张证明）、成本转移（明面降了暗处补回）、谁都不想先让。写人和人的拉扯，不写成本表。
3. 落到这拨人身上意味着什么：账本型对比一次两种处境的账就回到人；处境型、冲突型写两种选择各付出什么（时间、面子、关系）；信息型给三到五条今天能照做的动作，带渠道和时间节点；情感型给一个小做法，或承认没有好办法。
4. 也有人不这么看：两三种声音（真实的标平台，否则概括），镜头拉回人物。长图文这一层的最后一两段就是过门。

延伸不再走四层，只接一个问题（接法见 s4-common）。

## 四、小标题、过渡、结尾

小标题：处境落点（“[人]卡住的，从来不是[表面那件事]”）、认知反转（“口子是松了，可卡住人的是最后那一步”）、原话（“不怕多跑两趟，就怕每个窗口说法不一样”）、拆解（仅账本型，最多一个）。

结尾六式（和资讯线上一篇错开）：

| 结尾式 | 示例 |
|---|---|
| 经历共鸣 | 你办[某事]时，有没有卡在最后一页纸上？评论区说说。 |
| 两难选择 | 一边是[A]，一边是[B]，换你怎么选？留言聊聊。 |
| 潜台词追问 | 你最近那份外卖，是不是也没以前那个味儿了？评论区聊聊。 |
| 帮亲友问计 | 像她这种情况，该现在办还是再等等？懂行的留言支个招。 |
| 观点碰撞 | 有人觉得太急，有人觉得早该管了，你怎么看？ |
| 晒坐标 | 你们那儿落地了吗？评论区说说。（仅账本型、信息型） |

## 五、四类题

| 题 | 默认主驱动 | 推进主线 | 必配细节 |
|---|---|---|---|
| 政策新规 | 信息型、处境型 | 跑腿现场 → 新规一句话 → 哪几类人易卡 → 避坑几步 → 各地差异 | 排队号票、窗口手写提示条、热线原话 |
| 行业生计 | 账本型、处境型 | 收摊后的现场 → 一个刺眼的数 → 规则怎么卡住他 → 消费者也没占便宜 | 后台截图、凌晨进货、磨损的工具 |
| 社会热点 | 处境型、冲突型 | 日常切面 → 两类人的反应 → 各自怕什么 → 不做道德审判 | 价签、业主群截图 |
| 家庭代际与职场 | 冲突型、情感型 | 饭桌上的一句话 → 双方难处 → 体面背后的妥协 → 守住底线的解法 | 翻扣的手机、分装好的药盒 |

## 六、事实口径与自检

- 账目自洽：动笔时把加减乘除核一遍。
- 政策写清是哪里的口径；查不到当地就直说没查到。语料里的金额、建议要核实当地当年的页面。
- [ ] 骨架和主驱动一致，非账本型没有算账节。
- [ ] 主数字和立项卡逐字一致；换算最多一次；结尾没有数。
- [ ] 第三层的渠道、时间节点、电话都核实过。
- [ ] 延伸没有再拆一遍账，没换新主角重讲。
