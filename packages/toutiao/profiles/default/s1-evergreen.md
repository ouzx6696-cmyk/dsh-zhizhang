# S1 常青题与节点（故事线为主）

要写神话、传说、民间故事、各国神话改编，或想借节日、影视热播、展览考古找题时用。产出候选清单（故事、母题、节点、切口），交 S2 按故事线打分。常青题不怕晚，怕撞：撞自己 30 天内写过的，撞全网写烂的。

## 一、找题入口

| 入口 | 动笔前核实 |
|---|---|
| 传统节日与节气，提前一到两周备稿 | 当年公历日期，写进出处 |
| 别国节日（万圣节、亡灵节） | 来历说法多，只写找得到出处的那种 |
| 神话题材影视、动画、游戏热播 | 上映或上线日期；只谈公开信息，不剧透，不编主创说法 |
| 博物馆新展、考古发现 | 打开报道；神话和文物的关联只写报道或馆方说明里有的 |

没有节点也能写，S2 节点时效按 50 分算。

## 二、节点与母题（线索，用哪一版动笔前核实，版本线索见 corpus-story-motifs）

| 节点 | 常配 |
|---|---|
| 春节 | 创世；年兽等说法成形较晚，出处查清 |
| 清明 | 冥府寻人；介子推是历史传说，别写成神话 |
| 端午 | 白蛇传的端午情节；屈原是历史人物，不当神话写 |
| 七夕 | 天鹅处女（牛郎织女、毛衣女） |
| 中元 | 冥府寻人（目连救母） |
| 中秋 | 不死药与奔月；吴刚伐桂（徒劳与坚持） |
| 重阳 | 桓景避灾（一般认为见于《续齐谐记》，需核实） |
| 冬至 | 逐日、射日 |
| 万圣节、亡灵节 | 冥府寻人；各地亡灵传说 |
| 圣诞 | 只写有出处的民俗来历，不把宗教内容当神话改编 |

立项卡“母题”只能填母题库里的 11 个：大洪水、射日、盗火、冥府寻人、变形、创世、屠龙斩怪、天鹅处女、逐日、不死药与奔月、徒劳与坚持。

## 三、三道筛

1. 撞题：`toutiao_ledger_show` 看 30 天内的故事和母题，先划掉；上一篇的改编方式这篇换掉。
2. 烂题：搜近期写法。大家都在讲同一个寓意，就换切口：被忽略的原典细节、配角视角、别国同类故事。找不到新切口就换题。
3. 边界：宗教人物和仪式、少数民族史诗与信仰、真实历史人物，不按故事线写。

春运、返乡、节礼这类节点题走资讯线，节点只回答“为什么今天写”。
