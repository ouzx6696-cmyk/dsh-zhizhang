# S4 共用写法：两条线都要守的

S4 先读这份，再取 s4-news 或 s4-story；微头条取 s4-micro。产出：`toutiao_draft_stage` 存的初稿，Markdown，以“# 主标题”开头，小标题用“## ”。

## 一、长图文：一张蓝图写主稿和延伸

一篇稿子分两段走，不是两篇拼起来。篇幅按质检口径（去掉空白的全部字符，含标点，配图标记不计）：全文 2600到3400，主稿 1700到2300，延伸 800到1300；短图文 1100到2200。

动笔前排蓝图，用 `toutiao_card_patch` 写进立项卡“蓝图”：

| 部分 | 回答什么 | 人在做什么 |
|---|---|---|
| 引子三段 | 一个反常 | 锚点人物的一个动作 |
| 主稿三到四节 | 主问题拆成三四个小问号，一节一个 | 同一个人往前走 |
| 过门（主稿最后一两段） | 留一个口子 | 人停在一个动作上 |
| 延伸一到两节，首节标题 = “延伸.起始小标题” | 延伸接的问题 | 同一个人再走一步 |
| 收尾 | 不答完，抛给读者 | 一个动作或半句话 |

排不出延伸那两行，就改短图文。

延伸是扩写，不是拼接，同时满足四条：

1. 接一个问题：同一拨读者读完主稿的下一个问号。
2. 同一个人往下走：不换主角，不换人群。
3. 新事实、自己的出处，不复述主稿。质检按 8 字片段比对，一成多重合扣分，四分之一以上否决。
4. 有过门：主稿留口子，延伸第一段接住；中间不放“延伸阅读”“相关阅读”。

| 线 | 接法 | 意思 | 写成这样就是拼接 |
|---|---|---|---|
| 资讯线 | 下一步 | 办完这件事紧接着碰到的事（清完旧手机，旧号码要不要销） | 另讲一遍“注意事项大全” |
| 资讯线 | 另一面 | 同一件事落到同一个人的另一头（替爸妈办完，轮到自己） | 换新人物重讲同一件事 |
| 资讯线 | 往深一层 | 主稿留下的“为什么”，往制度或来历挖一层 | 把政策原文从头贴一遍 |
| 故事线 | 别国同母题 | 别的文明怎么讲同一件事，同在哪、不同在哪 | 把别国故事从头复述 |
| 故事线 | 原典与流行说法 | 原典写了什么，后来被改成了什么 | 罗列影视作品名 |
| 故事线 | 今天的痕迹 | 落在今天的地名、习俗、馆藏里（有出处） | 百科式“文化影响” |

提问只放在延伸最后；主稿结尾停在画面或动作上，不问。

## 二、开篇三段

1. 第一段不超过 80 字（质检超 100 字扣分）：一个人、一个动作、一个反常。不铺背景，不背公文，不写“很久很久以前”。
2. 第二段人物入场，给他一个账之外的东西：一个习惯、一句口头禅、一个怕。
3. 第三段一两句，亮底牌，一句有态度的实话。

锚点人物名要在前三段出现，一直走到最后三段。

## 三、节奏（按质检真正量的写）

- 段长要起伏：独句段和满满一段交替，约每 300 字一个 6到20 字的独句段。段长整齐是 ai 维最重的单项扣分之一。
- 单段不超过 150 字，每段 1到6 句。
- 句长有长有短，平均每句 16到32 个汉字；长句不过 45 字；常用“中长句铺事实、中句转折、极短句钉死（‘他没接话。’）”。
- 相邻段开头两字不同；连续三句不同一开头；段首不写“第一、”“一是”“首先”。
- 转折处三四处“——”或“……”。
- 小标题三到五个，口语，不用四字对仗；配图标记单独一行“【配图：画面描述】”，长图文四处左右。
- 一节一个问号：节尾留卡点，别在一节里把发现、分析、解决走完。卡点处拆成三句动作放慢，过场一句话跨过两个月。

## 四、写前八条纪律（怎么认病见 s5-editing）

1. 人物有事，不贴标签：不写“焦虑”，写他在谁面前嘴硬、为什么跑第二趟。
2. 细节跟着处境走：只写人物此刻看得见、和他的麻烦有关的，不拍全景。
3. 引语在做事：试探、诉苦、抬杠、保面子；允许答非所问、话留半截；一问一答不超过四拍，中间插动作。全文直接引语至少五处。
4. 规则和背景后置：先写人踩了什么坑，再点出是哪条新规、哪部原典；没碰到的条款不提。
5. 情感配给：每节最多一个情绪峰值，越心酸越写手头在干什么。
6. 闲笔有来路：天气、器物要和处境咬合，删掉不影响的就是装饰。
7. 理不占尽：平视给建议，承认边界（“这个我没查到，不敢瞎说”）。
8. 结尾落人：停在动作、画面或半句实话上；不升华，不总结寓意；最后一段一到三句、没有数字，以提问收。

## 五、结尾提问

最后的提问里要有“评论区”“你怎么看”“聊聊”“留言”之一，质检只认这四个，缺了扣分。在四个里轮换着组句，别篇篇一样。

## 六、标点（硬闸）

| 用 | 不用 |
|---|---|
| “ ”，里面再套‘ ’ | 直角引号、英文直引号 |
| 全角，。；：？！（ ） | 夹在中文里的半角标点和括号 |
| 省略号、破折号都连打两个 | 只打一个、三个点、两个短横 |
| 范围写“到”“至” | 波浪号 |
| 《山海经》的《北山经》、普罗米修斯 | 间隔号和任何装饰符号 |

正文不留星号、单个井号；比分、时刻（3:2、10:30）不算违规。

## 七、事实落到句子上

- 合成人物用明示口吻：“说一个这阵子挺常见的情形”，不写“我表弟上周刚……”（立项卡标了合成时这是硬闸）。
- 网友声没有真实来源就概括：“评论区里常见几种声音”。
- 语料的人名、句子、数字只借质感。

- [ ] 开篇三段、节奏、结尾按上文；直接引语至少五处；标点规范，没有花括号。
