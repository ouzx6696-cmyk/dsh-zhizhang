# S2 立项：打分、定骨架、填立项卡

把候选或作者给的题材变成一张立项卡。卡定下内容线、主驱动、体裁、两个问题、人物、开头结尾式和出处；后面每一步和质检都照它核对。

## 一、分线与打分

读者点进来想知道“这事跟我有什么关系”是资讯线，想听一个故事是故事线。节日题看主角是今天的人还是故事里的人。

打分只为排先后，权重是经验值，低于 62 淘汰：

- 资讯线：冲突度 0.28（有受损方，名义利好和落地有落差）、情绪值 0.22（想转给家里人）、实用性 0.20（省钱、省事、防骗、想明白）、身份代入 0.18（一大拨人一眼对号）、时效性 0.12（24 小时内冒头、落地满月、节前月底）。
- 故事线：认知缺口 0.26（知道名字不知道细节，或记的是改编版）、处境共鸣 0.24、改编空间 0.20（原典没写动机、结局或配角没开口）、节点时效 0.15（无节点按 50）、新鲜度 0.15。

过线后定档：S 当天第一顺位并想系列角度；A 当天排产；B 进备选；C 淘汰。

## 二、宏观题落到一个人身上

`[热榜原题] → [哪拨人、哪块利益] → [一个人 + 一个具体处境或动作]`

| 原题 | 立项题 | 主驱动 |
|---|---|---|
| 多地调整公积金租房提取条件 | 房租能全额提公积金了，可他最怕的是跟房东开这个口 | 处境型 |
| 城乡居民基础养老金上调 | 村里大爷每月多领一点，他第一件事是给孙子打了个电话 | 情感型 |
| 规范外卖平台收费 | 一份外卖，小店老板手里到底剩多少 | 账本型 |
| 延长婚假政策落地 | 婚假能休满了，部门里却没人敢先开这个口 | 冲突型 |

切身不等于算钱，时间、麻烦、面子、关系都是。主驱动的写法见 s4-news。

## 三、体裁与两个问题

长图文（默认）：主稿回答主问题，延伸接同一拨读者读完主稿冒出的下一个问题。写不出第二个问号就改短图文；抢一个侧面用微头条（s4-micro）。

- 主问题例：“卖旧手机前恢复出厂，东西真的没了吗？”
- 接的问题例：“拔下来的旧号码要不要销？”不能和主问题相同。

## 四、排产与去向

资讯线同垂类同日只排一篇；7 天内账本型不过半；同线连续两篇不用同一开头式、结尾式；人名 10 篇内不重复。故事线 30 天内不写同一故事或母题；连续两篇不用同一改编方式。

每条候选去向写到能操作：立项；进池（写明等什么：等节点、补本地口径、错开同日）；淘汰（例“传闻，没有可核实的口径”“本周已两篇账本型”“上个月写过这个故事”）。不许只写“分低”。

## 五、填立项卡

先 `toutiao_article_create`（slug、line、genre），再 `toutiao_card_set` 写完整卡，结构照 template-card。工具预检后返回问题清单，有 fail 也会存，但要改好再写一遍。模板里的示例值（小覃、原话顶门、两难选择、那条房租题目）全部换成本篇的；留着 [方括号] 判没填，出现 {花括号} 会被质检当成未替换占位符。

“必填”指预检报 fail；“硬闸”指质检一票否决；“提示”指质检 warnings。

| 字段 | 怎么填好 | 检查 |
|---|---|---|
| 内容线 | 资讯线或故事线 | 必填，填错硬闸 |
| 题目方向 | 第二节那种立项题：人、处境、反常 | 不查，S3 的原料 |
| 垂类 | 资讯线选一：民生社保、职场就业、房产楼市、教育升学、健康养老、三农乡土、情感家庭、财经理财、汽车出行、科技数码、社会观察、文旅消费；故事线写“神话传说” | 必填，同日查重靠它 |
| 人群 | 一眼对号：“在省城租房的年轻人”，不写“广大群众” | 必填 |
| 情绪 | 一个词：焦虑、不平、共鸣、好奇、欣慰、憋屈 | 不查 |
| 主驱动 | 资讯线五选一，故事线填故事型 | 必填，填错硬闸 |
| 体裁 | 长图文、短图文、微头条 | 必填，决定篇幅档 |
| 主问题 | 一个问号 | 必填 |
| 延伸.起始小标题 | 延伸第一节标题，正文逐字出现，质检从这里切开两段 | 长图文必填，正文找不到是硬闸 |
| 延伸.接的问题 | 下一个问号 | 长图文必填 |
| 延伸.接法 | 资讯线：下一步、另一面、往深一层；故事线：别国同母题、原典与流行说法、今天的痕迹 | 不在名单提示 |
| 延伸.出处 | 延伸新事实单独记“事实 + 链接” | 空着提示 |
| 蓝图 | 建议填，每节一行：部分、小标题、这一节回答；结构改了回填 | 和正文小标题对不上提示 |
| 改编方式、母题、故事、所用版本 | 故事线填：改编方式见 s4-story；母题从库里 11 个选（见 s1-evergreen）；故事如“精卫填海”；版本写书名加篇名或通行译本。资讯线留空 | 故事线前三项必填，版本提示 |
| 锚点人物.名字 | 本篇自起，不用语料示例名，和最近 10 篇错开；故事线是主角。两字以上的名字进标题算“具体的人” | 正文没出现是硬闸；没在前三段入场、没走到最后三段、延伸里没出现都提示 |
| 锚点人物.真实案例 | 只有作者给了真实案例才填 true，并写来源 | false 时写“我表弟上周……”是硬闸 |
| 锚点人物.人称 | 他或她，全文一致 | 同段混用扣分 |
| 主数字 | 账本型必填，其他可空；填正文逐字出现的那串，如“6.08” | 正文找不到是硬闸 |
| 主数字出处 | 填了主数字就要填 | 必填 |
| 开头式、结尾式 | 名单见 s4-news、s4-story，和同线上一篇错开 | 不在名单或重复提示 |
| 主标题、备选标题 | 留空，S3 用 `toutiao_headline_set` 回填 | 超 34 字报错 |
| 出处 | 每个硬事实一条“事实 + 链接”，链接是本次打开核实的页面或写“作者素材”；故事线写原典 | 必填 |

## 六、产出

`[S2] [内容线] “[题目方向]” [档] 主驱动=[主驱动] 体裁=[体裁] 主问题=[主问题] 延伸接=[接的问题] 人物=[名字，合成或真实] 去向=[去向与理由]`
