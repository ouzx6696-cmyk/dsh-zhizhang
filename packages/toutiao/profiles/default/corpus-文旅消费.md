# 语料：文旅消费

适用：景区免门票与二次消费、老年低价团、县城影院与演出、错峰出行、节假日消费、宠物看病开支。常配主驱动：账本型、处境型、信息型。
用法见 corpus-common 开头：人名自起；下文数字、渠道都是写法示范，以本次核实的出处为准。

## 读者与处境

- 跟低价团回来的退休老人：拎回几床被子和乳胶枕，回家一查网价愣住了。
- 县城影院检票员：春节档挤爆，工作日一场只卖出几张票。
- 带一家老小出游的中年人：门票免了，停车、摆渡车、索道一路花下来。
- 养宠物的年轻人：猫狗一场病，检查单比自己看病还长。

## 现场与细节

- 地点：景区摆渡车闸机、旅行社门店、大巴车上、县城影院大厅、宠物医院前台。
- 对接人：举小旗的导游、景区游客中心、旅行社店员、宠物医生。
- 物件动作：
  - 大巴团清早五点半集合，导游的小黄旗被风吹得卷成一团。
  - 行程单折成四折，第四天上午那栏小字印着“文化体验馆，停留约两小时”。
  - 免了大门票，停车场离景点还有好几公里，摆渡车一人一张票。
  - 电影票根夹在手机壳背面，散场时后排有人小声说不值。
  - 宠物医院的分项报价单一拉老长，主人拿着笔一项项问。
- 数字口径：游客说“门票多少、算上吃住行一共花了多少”，老人说“团费才几十块”。门票政策、旅游投诉渠道、景区收费以文旅部门和景区官方公告为准。

## 人会这么说

- 老人：“几十块管三天吃住，我也觉得不对劲，可大家都报了。”
- 游客：“门票是免了，从停车那一刻起，每道关卡都在等着补票。”
- 宠物主人：“这项检查必须做吗？能不能先做最要紧的？”

## 读者真问题

- 低价老年团怎么识别是不是购物团？
- 景区免门票后哪些费用是必须的，哪些能绕开？
- 节假日出行怎么错峰，哪些时段人少？
- 被强制购物或买贵了，怎么投诉、退货？
- 宠物看病怎么避免过度检查？

## 好角度

- 行程单上的小字：信息型，教子女帮父母看行程单，哪几行要警惕。示范：“女儿把行程单摊在饭桌上，拿手机电筒照着第四天那一栏，念给她妈听。”
- 免票之后的账：账本型，主数字是一家人一天的总花销，换算最多一次。
- 空场的影院：处境型，写检票员看到的冷热，不下行业结论。
- 反例：“旅游消费回暖，文旅市场迎来新机遇”，通稿口吻，没有一个游客。

## 雷区

- 不点名具体景区、旅行社做负面评价，除非有官方通报或公开报道。
- 景区收费、免票政策随时调整，写清时间并核实官方公告。
- 投诉渠道写官方公开的热线和平台，不编号码。
- 不写“百分之百是购物团”这类绝对化判断，写成“这几种迹象要多留个心”。
