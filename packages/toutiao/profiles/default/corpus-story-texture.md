# 语料：故事线写法质感

故事线 S4 动笔前读一遍，S5 回看时对照第四节。这里只讲怎么找细节、怎么定声线，不给可以搬进稿子的句子：同一个账号拿同一批漂亮句子写十个神话，就是平台点名的模板化拼装。

## 一、从原典的缝里找细节

补细节不是编新情节，是在原典写到和没写到的交界处，补一个合理、看得见的东西。把原典逐句过一遍，每句问四件事：

| 问 | 找什么 | 边界 |
|---|---|---|
| 写了什么样子 | 颜色、形状、声音（如“文首、白喙、赤足”“其鸣自詨”） | 用原典给的样子做锚，不另起一套外貌 |
| 省了什么动作 | “常衔木石”中间省掉的起飞、落海、返程 | 补过程，不补新事件 |
| 没写什么理由 | 为什么搬、为什么射、为什么回头 | 用推测口吻写“可能”，不写成原典说的 |
| 没写结局 | 海填没填平、人回没回来 | 不替原典补结局，“原典没写”本身就是看点 |

再盯住原典里的单字：一个“故”、一个“常”、一个“窃”、“不返”和“死”的差别，常常就是一节的主心骨。

## 二、身体感：用重量、温度、距离、疲劳代替形容词

- 重量：衔得动多大的东西，扛着走了多远。
- 温度湿度：海风、盐、日头落在身体哪个地方。
- 距离：原典给了地名就用地名，不编里程。
- 重复与疲劳：第几趟和第一趟哪里不一样，去时和回时哪里不一样。
- 声音：原典记了叫声、哭声、歌声的，抓住它。
判据：每节至少一处能摸到的身体细节，且来自原典或标明是推测。

## 三、声线：饭桌上讲给没听过的人

- 句子短，先说画面，再说来历；出处后置、一句带过。
- 原典短句可以引，引完马上用大白话接住；不用“只见”“端的是”“但见”的章回腔，也不用网文腔。
- 推测要标出来：“原典没说它累不累”“这是我替它想的”“也许”，读者分得清哪句是原典、哪句是你补的。
- 别国神话：只讲和本篇母题可比的那一段；先说相同再说不同，不同落到一个具体细节上（一个自己选，一个被罚）；通行译名，第一次出现补一句身份，不堆族谱；不评高下，不写“西方神话更残酷”。

## 四、故事线套话对照（S5 回看用）

| 套话 | 毛病 | 改的方向 |
|---|---|---|
| 相传在远古时代、很久很久以前 | 万能开头 | 从最有画面的一刻进去 |
| 天地为之动容、感天动地 | 抽象情绪 | 写一个具体反应：浪、风、旁观者一句话 |
| 这个故事告诉我们、给我们的启示 | 寓意说教 | 停在原典最有分量的那句或那个画面 |
| 中华民族自强不息的精神 | 大词空转 | 落到这一个角色、这一个动作 |
| 考古证实、真实存在 | 史实化 | 没出处就删，有出处写成转述 |
| 它眼中闪过一丝坚毅 | 拟人过头 | 一只鸟就写鸟的动作 |
