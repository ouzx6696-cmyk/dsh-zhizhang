# 拆解库：结构与入库参考

> 用于需要入库、归位或比较时。具体根路径与写入边界见技能根 `库位置.md`。分析稿不必先建库，目录也不决定拆解方法。

## 1. 建议布局（按需增加）

```text
<库根>/
  顶层认知.md               用途、边界和必要观察
  批次台账.md               实际阅读范围、产物入口与下一步
  骨架书候选清单.md         有检索用途时派生
  题材映射.md               有题材包导航用途时派生
  待归平台/                仅当该库现行入口仍使用，不预建
  <平台>/<题材>/books/
    <书名>.md              自足拆解卡，含发展概览
    <书名>-幕骨架.md        概览过长或需独立引用时才拆
    <书名>-阅读卡.md        需要细记录时选用
    <书名>-第N章深拆.md     需要关键写法时选用
```

单本默认一份自足卡。拆出概览后原卡只留摘要与链接，不保留完整副本。题材页、平台画像、对照表、假设台账、总结与索引均有实际用途才创建，旧命名可继续兼容。

## 2. 平台与题材怎么定

平台用可核来源，如官方作品页、明确来源头或作者明示；编号、章长、文件名仅为线索。平台未确认保持未知；只有入库时才读目标库现行入口，按其已授权规则落位。没有未知平台落位规则就询问必要位置，不预建暂存区。仍可分析文本，不混入已确认平台统计。平台规则需要外部来源和日期，不能从作品风格倒推。

内容题材按正文判断，官方标签可作旁证；上架分类不等于内容题材。混合内容保留主要落位与其他标签，不为了桶名压平实际驱动，也不强制固定分类优先序。

## 3. 单本内容与阅读范围

以任务问题为中心，记录原文中的事件、选择、信息、关系、表达过程及来源。结构分析按幕、事件群、关系、探索、认知或连续流描述，不自动一章一幕；无需结构切分的局部问题可只记录相关过程。

正文、作者书外说明和分析解释分别标来源。书外设定可作补充背景，但不能冒充正文呈现。阅读范围区分目录扫描、正文已读、深读与未读；边界附近已读不等于内部已读，未经阅读不能填写逐章内容。

## 4. 入库与比较

卡片保留原文入口、位置、事实／推断／待验证、迁移条件、易失效处及未读影响。反例有则记录，无则说明未检验，不为了入库自行找新书。

单本是案例，多本仍是有限样本观察。比较前定问题和口径，每项统计单独确定有效分母，不能把未读当未出现。平台与题材是背景，不是唯一可能的知识单位；明确范围的跨平台比较允许，不混成通用数值参数。

## 5. 与装填的接口

装填只读相关成果，从本轮问题取证据和机制：人物选择的条件、阶段转接、具体过程、信息与体验组织、使用限制等。没有合适参考可按作者材料推导并注明边界，不预设库里已有设定模式、单位规模或爽点统计。

引用简记书名、实际范围与位置，区分原作观察、效果解释和本书重新设计。原作切法、样本频次或预算数字不强制成为作者要求。迁移机制，不复制专有设定、情节细节和长段表达。

## 6. 维护与三根

技能根存指令模板；库根存知识数据；作品根存原创规划。解析以 `库位置.md` 为准。没有指定或获准的位置不自行建库、扫盘或写到任意原稿旁。

只更新受本轮影响的成果和必要导航。共享文件单 writer，导航由现行成果派生，不重复全文；旧结论作废或削弱时说明原因，保留有价值的反例和勘误，不要求无限保留所有过程表。

意图稿自检留在本次授权工作区或作者项目，不作为正文案例入库。配套模板在本技能 `资产/拆解/`，不与具体库的数据目录混淆。
