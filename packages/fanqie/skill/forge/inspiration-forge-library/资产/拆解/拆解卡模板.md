# 拆解卡：一本书一份（驱动 ＋ 可迁移做法 ＋ 证据边界）

> **用途**：单本拆解卡——先答驱动与读者体验，再看发展与变化，最后给可迁移做法与用途边界。
> **何时选用**：用户要完整拆解一本书、入库或更新库卡、做多本比较时。只问“这段为什么好看、能学什么”时，改用 `精简拆解模板.md`。
> **读完做什么**：照 `字段规范.md` 选词填字段；发展与变化概览见第 3 节，可迁移做法见第 4 节。
> **不要读什么**：读后感不进卡。

> 用法：在授权工作区按任务填写相关节；只有明确入库才写 `<库根>/<平台>/<题材>/books/<书名>.md`，不为模板扩大分析范围。
> **默认一份自足卡**——发展与变化概览就在本卡第 3 节，**不默认另开文件、不要求两处重复**。
> **只有**结构概览本身过长、或需被别的文件独立引用时，才单独成文 `<书名>-幕骨架.md`，
> 本卡第 3 节只留摘要＋指向；**拆分是例外，不是默认**。
> **书按「主题材」落位**，跨题材属性只写进标签栏（用于检索）。
> **平台未确认保持未知。** 入库按目标库已授权的未知平台落位规则，无规则则问必要位置；分析不受阻，不预建暂存区（见 `库结构.md` 第 2 节）。
> 没读到的章、没覆盖的卷**一律写"所选范围未体现／未读"**，不写"无／缺失"。

## 1. 来源与阅读范围（读了什么、没读什么）

**阅读范围分开声明**（互不代替）：

| 范围 | 值 |

## 2. 驱动与读者体验（先填这一节）

> 作用：**防止把这本书塞进别人的模板**。不能判断时说明是材料不足、问题不适用还是存在多种解释，不强造唯一驱动。
> **不问"必有金手指／三幕／反派"**——只问它实际靠什么在推进读者。

| 问题 | 答案 |
|---|---|
| 文本邀请读者期待、关注或体验什么 | 【用具体过程支持；未测读者反应按解释标推断】 |
| **压力**来自哪里 | 【】 |
| **关系**如何起作用 | 【】 |
| **探索／信息推进**靠什么 | 【】 |
| 一句话驱动 | 【】 |
| 推进靠外部事件还是人物选择 | 【外部事件／人物选择／混合】 |
| 判断（**标明是判断**） | 【】 |

> **证据写法**：重要结论都要带**章号位置**，并区分 **【事实】／【推断】／【待验证】**；
> 没有的结构写"所选范围未体现"，不写"无／缺失"。

## 3. 发展与变化概览

> **按本轮问题描述实际发展**，可以使用幕、事件群、一场一局、关系线、探索段或认知台阶，不声称大多数作品必属某一种。
> **用哪个单位就在这里声明哪个**（例："本书按事件群切"）。
> **没有稳定的分段**就说明这是**连续流**，**不硬凑幕**。

**单位说明**：【本书按 X 单位切／连续流，不分单位】

| 单位与范围 | 起点及关键过程 | 结果或变化 | 边界依据与核实状态 |
|---|---|---|---|
| 【单位名 · 起止，可写"第X章内"】 | 【起点状态 → 关键过程】 | 【局面从 X 变成 Y】 | 【事件或短引文／位置 ＋ 已核／待核】 |

**分区（不许混）**：

- **已读内结构**：读过正文才写的行，标核实状态；
- **仅目录候选**：只据目录／章题拟的行，标"候选（待核）"；
- **未读**：明确留出缺口，不假装覆盖。

> **切点纪律**：章内切点要用**事件或短引文／位置**说清两侧归属，让读者能复核；
> **不用"末章＋1"这种机械等式**充当接续证明。
> 确有分析用途时补人物、信息与规则细节，不要求填写装填侧工作表。
> 定位方法见 `锚点体系.md`／`锚点判据.md`，本卡自足，不依赖主技能模板。

## 4. 可迁移做法（本节最值钱）

> 从这本书里提炼**具体做法**——**不是贴标签**；**条数不固定**（有 1 条写 1 条、有 5 条写 5 条，不凑数）。
> **只迁移机制**——不照搬原作的专有设定、台词、情节细节。

每条写全下面几样：

| 项 | 内容 |
|---|---|
| 原作具体动作与过程（＋**章号位置**） | 【作者在这本书里做了什么、怎么做】 |
| 观察到的变化 | 【文本中事件、信息、关系或表现方式怎么变；未测读者效果不当事实】 |
| 为什么起效（**【推断】**） | 【分析，标明是推断】 |
| 迁移要保留的条件关系 | 【换成别的故事，哪些关系必须不变】 |
| 可替换的内容 | 【人物／资源／事件可换成什么】 |
| 容易失效处 | 【哪一步没做到就崩；崩了会怎样】 |

### 做法 1：【一句话说清这条做法】

（照上表逐项填）

### 做法 2～N：【同上，有则写，无则不写】

| 技法卡字段 | 内容 |

| 技法名称（用具体叙事动作命名） | 【如：“看足筹码再掀桌”高含金量拒招安法】 |

## 5. 用途与边界

| 项 | 值 |
|---|---|
| **本卡强度** | **单本案例（1 本）**——参考素材，**不是规律** |
| **尚未核实**对用途的影响 | 【哪些结论还【待验证】，用的时候要留意什么】 |
| **未读**对用途的影响 | 【没读到哪些范围，因此哪些用途暂时不成立】 |
| **下一步最需要补读什么** | 【按对结论的影响排序】 |

> **不许列计数凑字段**——对判断没用的数字（"证据 3 条、推断 5 条"）不写。

## （可选）加厚：设定 / 人物 / 章

> **默认不做**——只在有明确用途时才加，**从正文反推，只记正文实际用到的**。
> 设定：规则与代价、体系刻度、势力、资源、身份（没有刻度写"所选范围未体现"）。
> 人物：不写"善良／腹黑"这类标签，落到欲望·恐惧·误判·限制·选择。
> 章：具体经历、信息与体验组织、结果和章末做法。章级统计需要实际阅读与可核记录，不以是否套用阅读卡模板决定资格。
> 使用 `字段规范.md` 区分事实与解释；只有本轮需要统计时统一定义和同义词，不强制文学内容落入固定词表。
