# 证据、推断与机制：虚构教学示例

> 本页全部为本套技能编写的虚构材料，不是真实作品拆解、平台数据或读者实验。示范记录方法，不将例子入库为外部证据，也不要求每条观察填同样多的表格。

## 1. 已读片段：说了什么不等于真相是什么

授权任务：只分析以下片段怎样推进信息，不入库。来源记为“教学片段甲，第1–2段”，平台未确认。

**教学片段甲**

1. 许禾把收据交给柜员：“我记得是周二交的。”柜员对照日期，收据写着周三，没有直接改登记。
2. 两人翻到原始收件簿。簿上同一编号记为周三，登记表却录成周四。柜员按更正流程改了登记。许禾收回收据：“那是我记错了一天。”

| 记录 | 类型与支持范围 |
|---|---|
| 许禾声称记得周二 | 【事实】甲§1确有此说法；不是“客观上周二交件” |
| 收据与原簿同一编号为周三，登记为周四 | 【事实】甲§1–2的文本明示 |
| 柜员没有仅凭口述更改，而在核原簿后按流程更正 | 【事实】甲§1–2的行动顺序 |
| 两种可对照材料让更正有可理解的依据 | 【推断】对组织方式的解释，不是读者理解度实测 |
| 登记出错是有人故意阻挠 | 【待验证】片段无动机证据，不能因日期冲突推定舞弊 |

阅读声明：目录未提供；正文已读甲§1–2；深读同范围的信息与核验过程；其他正文未提供。不能写“全书通过办事冲突推进”。

**机制记录示范**

- 原作过程与位置：甲§1的口述/收据冲突 → §2核同号原簿 → 更正登记。
- 可观察变化：行动从口头争执的可能性转到可核流程，登记获得更正；不声称双方关系已经改善。
- 效果解释：把“可信”落实在材料关系上，而不是由叙述者保证柜员公正。
- 迁移条件：材料确可接触、编号对应、流程允许据原簿更正，人物有核验动机。
- 可以替换：人物身份、办事对象、材料载体和表达；不必照搬收据事件序列。
- 失效边界：两份材料都来自同一错误源时不构成独立佐证；材料可能伪造而故事未核时，不能推出客观日期绝对真实。

这条机制可用于信息发现或专业操作，不要求制造敌人、额外惩罚或章末威胁。

## 2. 只有目录：保留候选，不填未读内容

给定目录：“第1章 来信／第2章 旧车站／第3章 回家”。正文均未提供。

不合格：“主角收到父亲遗书，去车站找到线索，回家完成和解；三幕已核。”

合格：“扫描了三个章题，可作为来信—地点—归返的定位候选；人物、信件内容、事件顺序与结构边界未核。需要对应正文才能说明发生了什么。若任务只整理目录，至此交付。”

章节标题不是全文证据。缺正文只阻塞依赖正文的结论，不阻塞整理已有目录，也不授权自行找整本书。

## 3. 安静关系：变化不必来自对抗

**教学片段乙**：“茶还热着。”母亲把杯子往里挪了些。女儿在对面坐下，讲起昨晚窗外那场雨。母亲听完，接着讲自己年轻时也遇到过一场同样突然的雨。

【事实】乙写了让杯、落座与两段经历的交流。【推断】相似经历的轮流讲述可能让相处感得到延续。【未核】是否完成多年和解、是否最受读者欢迎，片段没有依据。

可借的是“以回应延续共同注意”，不是“每段对白都要交易”。如果对方根本不愿交流，照搬分享往事未必产生亲近；要先重设计人物关系和回应条件。

## 4. 有效分母与补读更新

假设任务给三份样本，其中甲、乙正文完整，丙只有目录。若甲乙都出现“凭材料核验”，可记“在已检查的2份正文中出现2份”；不能写3份都支持，也不能把丙当未出现。此数只为该统计口径，不能自动证明有效或普遍。

之后用户授权补读丙正文，才按实际结果更新有效分母和证据状态，记录来源/范围/日期。无新增证据的格式清理只整理旧状态；证据状态只随实际补读与新证据改变。
