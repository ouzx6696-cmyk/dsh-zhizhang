# 开篇拆解与技法卡提取示例（快爽档）· 以《这座山归我了》前三章为例

> **档位与用途**：拆的是一部快爽档原创教学稿。示范怎样按 `SKILL.md` 的五层拆解（L1–L5）读开篇，把阅读感受落成可交给 `inspiration-forge` 和 `novel-writer` 的技法卡。文中的回报间隔、章末方式只描述这部稿子，不当作其他档位的标准。材料是本套技能原创教学文本，不是出版作品或平台样本。

## 一、 阅读范围与定位

- **实读范围**：《这座山归我了》C001-C003 全文（三章完整首单元，约 5300 字）。
- **一句话高概念反差**：连测石都点不亮的宗门底层修风道临工（表面弱势处境），靠双手直连裸露灵脉的独门接脉手艺，硬生生从大宗拆山舟口中截胡一座坠落仙山当山主（核心卖点）。
- **目标番茄用途**：用于指导【仙侠/高武/职业逆袭】题材怎样在前三章里让主角当场讨回押金、尽早亮出主线、合作方各有所图，并在第三章真正拿到山、当场享有。

## 三、 提取可复用的技法卡

### 技法卡 01：《“看足筹码再掀桌”——高含金量拒招安写法》
- **适用瓶颈**：反派拿钱/地位招揽主角时，常见写法是让主角喊道德口号“我绝不为五斗米折腰”，既假又干瘪。
- **三步做法**：
  1. **算清现实账**：让主角看到对手筹码时，立刻在脑中换算成自己渴望已久的具体世俗物件（如：街口那座贴红纸卖120金、带枣树的小院，抵得上5年积蓄）。
  2. **要求验真货**：不急着骂回去，反而让对手把真金白银摆到明面上看个够（“钱摆到船头”、“真好看”），证实诱惑极度真实。
  3. **轻描淡写要更大的**：在对方以为稳拿的瞬间，平静抛出自己真正的野心（“我还是要这座山”），逼对手立刻从利诱转为狠辣施压。
- **原著切片印证**：C002 姜照野算完枣树小院的账，让程铎把金锭压着红布排在船栏边看足了，夸一句“真好看”，再回“我还是要这座山”。
- **容易写成套话的地方**：避免“眼中闪过一丝不屑”、“区区臭钱也想收买我的尊严”等口号式台词。
- **跨题材重造示例**：【都市职场/鉴宝】对手开出百万年薪买主角手里的残卷，主角先算清这笔钱能把老家欠款连本带利还清还能买套江景房，让对方把合同公章拍在桌上看了三秒，然后合上盖子：“这卷东西立起来的字号，不止这个数。”

### 技法卡 02：《“借敌之重断敌之索”——受限能力以弱胜强破局法》
- **适用瓶颈**：主角能力有严格限制（如不能隔空轰杀巨舰），面对体量碾压的对手陷入死局，常见写法容易临时开挂爆种或让反派莫名犯蠢。
- **三步做法**：
  1. **推到物理死限**：明确正面角力已输（小船绞机拉不过巨舟双索，铁齿逼近）。
  2. **逆用对手贪念与物理规则**：主角主动撤掉自己维持平衡的能力（松手断风），把“保护对象”瞬间变成砸向对手的“致命重锤”。
  3. **卡死对手止损时间差**：对手为了保命/保船不得不主动切断连接（弃索），主角在对手换装备的空窗期贴脸完成最后一步闭环（重接风路+合锁环）。
- **容易写成套话的地方**：避免写成“主角爆发潜能，双手突然涌出万丈金光硬生生拉断铁索”（破坏能力设定）。

## 四、 迁移四项（对应交接契约 §7.3 技法迁移包）

- **当前番茄用途**：仙侠/奇幻/职业流的开篇设计（快爽档）。
- **可迁移核心体验**：底层手艺人不靠磕头熬资历，直接用独门手艺截胡核心生产资料（山峰/店铺/工坊/灵田），并在第三章完整享受当家做主的痛快感。
- **必须重造的条件**：新作需另设【核心生产资料类型】、【主角手艺的物理接触限制】、【合伙人的独立利益诉求】与【对手不得不弃手的止损底线】。
- **主动舍弃项**：不照搬“飞山—石桥滑槽—双索拆山舟”器械组合；C002中段密集的船位旋转与挂钩工序可按实际阅读负担压缩，把篇幅留给人物选择与回应。
