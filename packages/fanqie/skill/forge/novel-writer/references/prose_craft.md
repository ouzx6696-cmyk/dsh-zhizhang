# 表达：写前提醒与写后回看

> 动笔前读前半，写完一章后读后半。
>
> 它是提示，不是禁令。**不评分，也不必每章提交检查报告。**

## 一、写前：让表达服从处境

### 先写人物眼前的事

人物不是执行章纲任务的工具。先知道他此刻想办成什么、担心失去什么、相信什么，以及手边有什么。让他的选择从这些东西里长出来。配角也有自己的处境，不只在主角需要消息时才出现。

### 细节要有理由

不平均介绍房间里的每样东西。**叙述者的眼光、人物的处境和场景正在发生的事，决定什么值得看见。**

具体不等于多报尺寸、品牌和数量，也不等于给每句心理判断配一个身体动作。

### 对话跟着关系走

说话可以求证、商量、隐瞒、争辩，也可以只是相处。不同的人如何接话，取决于他听懂了什么、愿意回应什么和彼此的关系，**不是为了凑对白轮次**。

共同知道的背景不必借嘴重新宣读；直接回答、沉默、岔开和说一半都可以成立。

### 设定在需要时出现

规则和背景应帮助读者理解眼前的判断、行动或后果。可以先展示运作，也可以用简短说明建立预期，取决于本书的讲法。

角色的误解、客观规则和作者锁定设定要分开，**不用临时新规则救场**，也不隐去人物此刻确实会使用的关键条件。

### 让一章完整地抵达

开头从读者能接上的处境、声音、动作、静景或心理进入，**不为"第一行必须有人动"服务**。

结尾抵达章纲写定的结果或体验；悬念和完整收束都可以成立。能在本场自然办完的事就写完，不为制造翻页强行扣住答案或塞进危机。

### 写出真正的经历

避免用"得知、确认、处理、解决"跳过关键过程。该展开时写出人物怎样行动、别人怎样回应、办法为何改变；本就简单的过程可以概述。**不为了打破安静而制造失败、转折或未结事项。**

### 篇幅和情绪服从亲历价值

重要的谈话、选择、操作和感受写充分，重复过程和无需亲历的跨度可以略写。

闲谈、风景和低信息片刻可以建立相处质感，不必按配额插入。情绪的分量来自人物实际经历，**不规定每章几个峰值，也不强迫所有心理都变成动作**。

### 后台不要挤掉前台

流程、账目和数字只写到读者理解眼前事情所需的程度。若核账、谈价或手续本身就是人物正在经历的难处，就写出过程；只是后台办完的事项可以带过。

判断标准是：读者是否因亲历它而改变了理解或感受。

## 二、写后：按症状回看

写完一章后，哪里读起来像模板、空转或跳过了经历，就回看哪里。

### 可能的重复信号

以下句式本身都可以正常使用，**只有在反复承担同一作用、让节拍变得机械时才需要处理**：

- "不是A而是B""仿佛""与此同时""让 / 令 / 使"；
- "他感到 / 觉得 / 意识到"；
- "心中涌起一股……""嘴角勾起一抹……""眼中闪过一丝……"；
- 一丝、一抹、些许、不禁、突然等反复出现。

先看整段是否真的空泛，再决定改不改。**长句不一定要拆，短句也不一定要补长**；心理、概述和直接表达都可以有效。

### 按症状定位

| 症状 | 回到哪里 |
|---|---|
| 人物像在交作业 | 回到他此刻真正想办的事和顾虑，不要让叙述替他总结意义 |
| 对白只在搬信息 | 看说话的人想让对方做什么，是否有隐瞒、试探或直接相处的需要 |
| 经历被压缩 | 检查关键结果前的行动、回应和判断是否真的写出来；没有需要时不硬造障碍 |
| 情绪等强度 | 把笔墨给真正改变人物理解、关系或选择的地方，不把矛盾感受压成"心情复杂" |
| 笔调漂移 | 比较本书相近场景，而不是要求所有场景同一种速度和语域 |
| 结尾失焦 | 看本章是否抵达章纲落点；可以留下后果，也可以完整收束 |
| 后台挤占前台 | 账目、流程和资料只保留会改变读者理解或人物选择的部分 |

### 不要误杀

角色口癖、基本对白标签、对话里的情绪词、刻意的排比、引用的消息或书信，**都不因出现信号就自动删除**。心理不必一律改成身体反应，动作也不能替代缺失的剧情。

### 回看原则

改不改看本书的阅读体验、人物是否可信、前后事实是否一致。

**发现问题来自故事或章纲时，回到故事和提纲解决**；不要靠换词、补动作或强塞断章把空场景装饰得更像小说。

## 三、八类题材的笔墨重心与声线（速查）

按本书题材承诺调配叙事视距、声线、动作密度与情绪浓度。表里是常见取向，本书已有讲法和 `state/writing_style.md` 优先；常见节奏档位：1、2、5、7 多为快爽档，4、6 多为稳推档，3、8 多为慢燃或稳推档。

| 题材类别 | 推荐叙事声线与视距 | 主要篇幅该给什么 | 容易失手的地方 |
|---|---|---|---|
| **1. 仙侠/高武/能力夺权**<br>（如《这座山归我了》《借你这一拳》） | **热烈开阔 / 紧绷利落**：允许以主角为重心的全知视野扩展场面规模，或贴身限知写肉体痛感与发力 | 能力运转的物理接触感、生死一线的重心转换、对手见招拆招的压迫感、夺得控制权后的公开巡礼与痛快享有 | 避免把打斗写成技能名称对轰播报；避免赢了之后突然让主角圣母谦让 |
| **2. 都市/年代/鉴宝经营**<br>（如《掌柜说它会招财》） | **市井烟火 / 行家眼光**：带着行话质感，对货色、成色、人情往来敏感 | 验货看破门道的细节瞬间、坐地起价与压价的话术拉扯、真金白银落袋点数的踏实感 | 避免写成枯燥的行业百科；避免账目算错、成本凭空消失 |
| **3. 悬疑/规则/民俗奇谈**<br>（如《雾港旧声铺》） | **冷静克制 / 感官敏锐**：限知视角紧贴主角观察，环境细节只挑有异常或能提供线索的部分 | 发现反常痕迹的瞬间、用独门手艺交叉核验的过程、局部真相落地时对人心的冲击 | 避免靠一惊一乍的感叹号凑恐怖感；避免把线索边界写成编辑免责声明 |
| **4. 言情/情感博弈/婚姻世情**<br>（如《两张车票》） | **细腻敏锐 / 潜台词充分**：允许高密度内心自辩与微观动作捕捉（如解塑料袋死结、拨开半个煎蛋） | 双方在利益与承诺不兼容时的试探、回避、摊牌，以及一个微动作暴露出的真实边界位移 | 避免用“深深地看着她、心中无比感动”代替真实交锋；避免单方面道歉强行大团圆 |
| **5. 复仇/重生/逆袭打脸** | **冷冽果断 / 节奏明快**：不拖泥带水，前因后果清晰，出招直奔对方命门 | 截胡先机的干脆利落、对手算盘落空时的仓促补救、把旧账连本带利讨回来的现场交割 | 避免长篇累牍复习前世怎么惨死；避免只赢口舌之快却让对手全身而退 |
| **6. 历史/权谋/群像竞技**<br>（如《最后一道闸》） | **沉稳老辣 / 多方利害并置**：同一句话落进不同人耳朵里立刻触发不同算计 | 各方围绕同一规则/利益点的公开阳谋博弈、执行方案时的突发变数与临场决断 | 避免让配角排队当应声虫；避免在情绪高潮处插播大段史料科普 |
| **7. 轻喜/反套路/脑洞日常** | **一本正经胡说八道 / 强自辩反差**：表面越郑重其事，处境越窘迫好笑 | 角色为保住体面而进行的精密找补、离谱道具在严格规则下的乌龙效果 | 避免全员段子手互飙网络烂梗；避免为了搞笑破坏基本逻辑与器物规则 |
| **8. 治愈/种田/慢生活** | **温润松弛 / 细节精准**：于寻常器物和一日三餐中见人情分寸 | 手艺修复物件的踏实感、人与人之间不越界的善意接住、季节与生活的点滴积累 | 避免无病呻吟的散文空景；避免章尾强行制造车祸绝症骗眼泪 |

## 四、声线锚定：用“人物观察偏见”代替空洞形容词

在建立或维护 `state/writing_style.md` 时，可用 2–3 条具体的**观察偏见**代替“文风幽默、节奏明快”等抽象词汇：
- **市井掌柜风**：“凡事第一眼先算成本与折耗；嘴上称呼一律往阔气里叫（折叠桌叫柜台），心里把每一文钱的去向算得门儿清。”
- **狠人夺权风**：“不跟看不起自己的人争口舌，只看对方手里攥着什么可抢的实利；一旦咬住机会，哪怕手掌磨破也不松口，拿到手就要站在高处让所有人看见。”
- **拧巴情感风**：“嘴上说的理由全都冠冕堂皇，心理活动却在诚实拆穿自己的自私；越是理亏，越希望对方先发火好让自己顺理成章反击。”
- **冷静查证风**（慢燃档）：“先看哪里和平时不一样，再想谁有机会动过；话只说到证据撑得住的地方，剩下的留在手上反复翻。”
