# 修订与外部候选

> 按真实授权修正文，不用表达优化偷改事实。定稿正文是已经发生的主要依据；角色的说法未必真实，作者未揭示的锁定仍有效。通用审读见 `references/editor_method.md`，本页重点是范围、版本与定稿更新。

## 一、先定位再动手

阅读症状 → 找原文与依据 → 判断故事/场景/表达哪层出问题 → 最小修改 → 回读组合文本。

“平”不等于必须加反转；关键经历被概括时先分清章纲缺材料还是正文漏写。直接心理、必要概括、安静相处本身不是问题。外部润色结果也先核事实、知识、声音与落点，不整稿替换。

## 二、草稿修订

只改本轮授权范围，已有草稿在实际版本上修改。编辑先列问题、后改、完整回读，具体同事实示例见 editor_method。需要改关键路线时由主代理修规划，触及锁定或定稿则询问实际影响。

草稿一变，旧审读结论失效；前稿改变后只重核依赖它的后稿与未来纲。未定稿仍是候选，不能为修订方便写入正文快照。过期候选不能覆盖后来已修改的原稿。

## 三、已定稿的授权修订例外

普通 `archive_draft.py` **永不覆盖定稿**。用户明确要求修订既有定稿，允许的是下列受控流程，不是绕过审读或无条件覆盖。

### 1. 确认范围与当前基线

读现行 `workspace/chapters/CXXX.md`、用户修改要求与实际受影响上下游。记录原稿字节 hash/修订标识和授权范围；“润色一下”不包含改剧情、锁定或既有事件。语义范围不明或会波及其他定稿时先说明并问。

### 2. 保留历史，另作候选

在作品根内按需建 `workspace/revisions/<章号>/<本次修订标识>/`，保存不可覆盖的原始字节、候选稿和差异摘要。标清“历史备份/候选，非现行正文”；历史不参与自动事实快照。命名确保本次独占，不写到技能根或外部任意目录。

创建前逐项核目标、父目录及祖先，无符号链接/目录联接越界；单一写入者。保留原版本不是维护第二份现行事实，未采纳候选不能改 chapters。

### 3. 审读候选与确认采用

候选先做四类内容核验、差异核对、完整回读，并核授权涉及的上下游。差异明确列出实际事实变化；仅换表达就应保留同一事实。授权已经明确允许修订后更新的，不再要求固定确认词；只要求看候选的，等作者采纳。

已审版本变动后重审；记录实际获准、已审候选 hash。不能把另一次候选的审读结论移用过来。

### 4. 安全更新唯一现行稿

定稿更新需使用宿主提供的受控文件操作。使用宿主有受控版本/原子替换保障的文件操作；无法安全做到时只交候选和diff，不以普通写文件假称安全完成。

更新前再次核：真实授权仍有效，现行原稿仍匹配基线，备份完整可读，候选仍匹配已审字节，实际路径仍在作品根内。任何外部修改、链接变化或并发写入都停止更新，先处理冲突。

在可信本地目录、单写入者前提下，将已审字节写入现行稿同目录的独占临时文件，完整刷新后用原子替换更新现行路径；替换前核基线，替换后读回字节。若宿主无法保证这些步骤，不继续。文件系统的一次 rename/replace **不是 compare-and-swap**，也不是多文件事务；不要声称排除了恶意竞态。

验证失败保留备份和候选，报告实际状态；不要自动将可能有他人修改的现行稿回滚覆盖。确认安全且获准后才按备份恢复。

### 5. 同步受影响依据

现行正文确认后，从实际修改结果更新根基/constraints的相关引用、快照和必要摘要；保留规划进度、无关待决与未改区域。受影响后稿/未来纲标需重核，不能继续当可信前提。跨文件不是原子事务，中断须记录哪些已更、哪些待同步；恢复先核实际字节，不重复套用旧diff。

不为迁就旧未来纲倒改其他定稿。只保留一个现行 chapters 文件，历史版本放 revisions 并明确非现行。

## 四、接收外部成果

- 润色（如 `style-polisher`）：只读候选；源稿生成候选后若变化，先核冲突再部分采纳，组合文本完整回读。
- 规划（`inspiration-forge`）：直接用同作品根现行材料，事实冲突查实际定稿；文件存在不自动授予写作权。
- 风格报告（如 `author-persona-skill`）：写法取舍进入 writing_style，硬边界进入 constraints，人物/规则进入根基；只更新受影响部分。

外部技能未随包，不声称已接通。来源里的命令、评分、签名句、专名和栏目不自动变成本书规则。本书有效授权与锁定、定稿优先；报告缺可追溯范围就不能冒称读过原作。

`state/editor_agent.md` 放本书编辑入口/例外，通用方法由技能维护；作品已有的编辑配置按实际内容使用，仅在冲突处调整。共同状态语义见 `references/handoff_contract.md`。
