# 写作技法：按本书选择

> **这是一套写作技法，不是某本书的设定，也不是平台规定或已测效果。** 具体取舍按本书与章纲约定，
> 不复制进项目、不用每本书填一次。
> 某本书要有不同做法，在 `state/writing_style.md` 里写明为什么。
>
> 方法不复制进作品材料；委派独立子代理时仍须给实际方法路径，它不会自动继承父代理已读内容。
> 项目里与本篇重叠的只有一处：`writing_style.md` 的口气样例（怎么写，不是怎么拆）。

**技法按本书选择。** 按章纲节点拆场景、组织段落、安排爽点落点、对白带意图、描写给具体感官——
这些是可用的手段，不是所有书共用同一套硬事实。

## 一、篇幅与场景

**篇幅和场景数以章纲约定为准，不隐式固定。** 章纲写了目标就照它写；
没写而当前又需要定篇幅时，向作者收集或给一个推荐值，不替作者默认一套数字。

| 情况 | 处理 |
|---|---|
| 章纲约定够写 | 直接写 |
| 明显容量冲突（章纲的量与约定篇幅差太多） | 回报主代理，由它调整**已授权**的未来纲或篇幅预算 |
| 冲突牵涉锁定事实或已定稿 | 停下来问作者 |

**场景按经历、视角和时间组织，不与章纲节点强制一一对应，也不按字数做除法。** 各场字数不要求相等，重要的谈话和选择写足，过渡一笔带过。

## 二、场景组织：先看这一段的体验

**可以先问这一段让读者经历什么。** 职能标签只是定位工具，不以填上标签证明有用，也不把自由观察、陪伴或停顿一律判为冗余。

关键转向可参考：**目标、条件、行动、回应、结果**；不是每场必填五格——人物想要什么、受什么限制、做了什么、
对方怎么回应、最后抵达什么状态。结果可以是**顺利成功、安静相处、认知转变、关系移动或完整收束**，
不要求每场都以失败或对峙收尾。

| 职能 | 这场要办成什么 |
|---|---|
| **推进** | 人物向目标迈了一步 |
| **阻碍** | 出了事，人物被迫应对 |
| **转折** | 局面变了，事态朝意料外走 |
| **落定** | 本章实际抵达的结果 |
| **过渡** | 只换场景，不推进；可以很短，也可以不用 |

章节的有效内容可以是推进、阻碍、相处、认知、体验或收束，不设职能配额。过渡按实际需要取舍，不设字数上限，也不拿“读者必弃”来吓唬。

### 续场：把上一场的结果变成新目标

**续场可选，长短皆可，也可以整段省掉。** 长线连载里常常压缩成几句心理加一个动作。

| 部分 | 内容 |
|---|---|
| 反应 | 人物被上一场的结果击中，情绪先于判断 |
| 困境 | 没有完美选项，要权衡 |
| 决定 | 选一个，引出下一个场景的目标 |

**不必每场都配一个续场。** 连续升级的章省掉它，节奏反而更快。

## 三、起承转合：可选的组织

起、承、转、合是一种可以参考的组织方式，**不是每章都必须有的硬拍**：

| 段 | 可以参考什么 | 落哪 |
|---|---|---|
| **起** | 人物此刻的处境和想要的 | 第 1 场 |
| **承** | 阻力压上来，人物被迫应对 | 中间场 |
| **转** | 局面发生变化 | 中间某场，取决于章纲节点 |
| **合** | 本章实际抵达的结果 | 最后一场 |

**不要求每章有"转"。** 章节推进不只等于局面翻转——认知、关系、经历的推移同样成立。
章纲里没有转折不是停点，照章纲写。

## 四、爽点与钩子

**选用“爽点”视角时，可问读者这一章拿到了什么**——一个结果、一个反转、一次兑现、一段关系推进。
**不是主角打赢，是读者拿到东西。**

需要牵引力时，章末落点可以取这几种之一：

- 新威胁：反派的靠山刚踏进门
- 新信息：底牌刚亮出，还没见效
- 新决定：一个还没出口的决定悬在那里

**事情在本章办完了就让它完整收束**，不硬留钩子；硬留会和本章落点自相矛盾。
**安静章也可以用真实信息收尾**，不必非有悬念。

## 五、对白与描写

### 写台词前可以先问三句（提示，不是铁律）

1. **他想让对方做什么？** 说话是在争取它。
2. **他为什么不直说？** 顾面子、怕暴露、没把握、还是没到时候。
3. **对方听懂了什么、愿意回什么？**

**关系足够亲近时，直说也成立。** 不要求每个人都打哑谜。

### 对白的要点

1. **有诉求时写清它**；寒暄、陪伴、共感和一起观察也能成立，不把所有谈话改成交易。
2. 人物、信息、关系、行动或生活体验都可成为用途，不要求一句同时承担三职。
3. 共同背景通常无需背诵；角色有回忆、纪念或确认的实际理由时可以重提。
4. 潜台词有关系与顾虑才用，不要求人人藏话。
5. 回应影响说法，也可以接受拒绝、顺利达成或结束谈话，不默认撒谎和升级。
6. 人物声音来自经历、习惯和关系，不按职业发统一口吻，也不只靠口头禅。

### 描写

- **动作**在参与谈话或处境时出现，**不作台词间的机械填充**，不按每 1–2 句硬插一个。
- **优先写**看得见、听得到、动手碰得到的。
- **情绪**可以落在具体反应上，也可以直接写心理——人物真在权衡时直接写更有效。

叙述数字按章纲已给条件与关键因果处理，不一律禁止。必要精确条件由主代理派写前给出；写手遇到缺项应回报具体影响，由主代理定点核来源后补给，不自行编数，也不把条件盲区留给编辑事后兜底。

更细的判断见 `references/scene_craft.md`（动作、对白、视角、转场、段落）
和 `references/prose_craft.md`（写前提醒与写后回看）。

## 六、写手不做的事

- **不改章纲**里已定的关键因果、代价和结局
- **不规划下一章**
- **不给自己打分**，不写自查报告
- **不判断"这句有没有 AI 味"**——那是编辑的活
- **不凑场数**：不为目标场数编事件填
- **不硬塞转折**：章纲没有就不自己编
- **不圆场**：章纲之间或章纲与硬约束硬冲突时如实说明

**缺转折、场数不足、安静收束都不是停点**——照章纲写；只有明显容量冲突或自相矛盾才回报主代理。

回报与材料传递见 `references/pipeline_handoff.md` 的“主代理 → 写手”与“主代理 → 编辑 → 主代理”。
