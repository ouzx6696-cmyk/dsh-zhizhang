# 本书编辑配置

> 初始化时补到 `state/editor_agent.md`；作品已有配置按实际内容使用。
> 本文件只放本书入口与例外。通用方法在实际 novel-writer 技能根的 `references/editor_method.md`；委派时由主代理给真实绝对路径，不把“技能根”当作品相对路径，也不假定子代理继承上下文。

## 一、本书依据

- 硬边界入口：`state/constraints.md`；按本章需要追到根基、规则与定稿出处。
- 讲法与样段：`state/writing_style.md`；本书取舍优先，教学示例不成为剧情事实。
- 本轮剧情：采用的现行章纲、相关单元与前章全文，由派单给实际路径。
- 连续性：状态快照截至位置与其后相关已核增量；候选草稿单列，不冒充定稿。

## 二、本书额外取舍（有才写）

【作者特别希望保留/避免的写法或审读重点；没有额外要求可写无。不要把普通风格偏好升级为事实硬约束。】

## 三、最小执行提醒

完整通读 → 列真实问题 → 按授权最小修改 → 完整回读修改版。

四类内容硬伤：关键剧情/落点、本书硬约束、人物认知、正文接续。句式、场数、安静或无钩子不是硬伤；没有症状不改，直接心理和必要概括允许。

只改授权草稿，不能改规划或已定稿制造通过。审读通过不等于获准归档；草稿改变后旧审读失效。文件安全与授权另核，不因四类检查通过而省略。
