# 第三章 挂钟还欠一天

下午回渡站，林绒先找昨天拆开的钟。

它还摊在昨天的桌上，旁边多了一张老许写的纸：别收废铁。纸角压着一颗螺帽，大概是他遍寻不着胶带后的办法。

“你那孩子来了吗？”他从门外探头。

“鞋补了。”

“还要钱没有？”

林绒把纸拿开：“八块。”

老许哦了一声，没笑。他进来搬开旁边堆的木板，给她留了条能转身的路，又说后面的入口已经交给负责封闭的人，今天不用从那边走。

桌上那只钟昨晚已调过，偏在装回钟壳前遇见了鞋。林绒先用带来的小钳子理好壳内一处松脱的卡扣，再把钟面与外壳合妥，立在桌边试走。老许拿自己的手机对时间，每隔一会儿便瞄一眼，像看一个刚学会守约的人。

表针走过两格，她才把拆下的挂墙螺钉装进小袋：“搬运时这些别混了。”

“这钟还得记来源，下一处接收的人要。”老许从柜里拿出两本旧册，一本新的交接单，“你修好的算一项，你看看名字怎么写。”

她在新表上签下“林绒”，老许把工钱递给她。钱是原先讲好的数目，不多不少，她点过，收进包里。

他翻旧册找钟的登记，指腹在页边来回搓。册子受过潮，几张粘着，翻开时有薄薄的纸屑留在桌上。

林绒原想提醒他慢一点，视线却停在刚露出来的那页。

那里有父亲的名字。

字并不大，挤在维修人那一栏；末一笔往上带，几乎碰到旁边的日期。父亲写完字总喜欢这样收一下，她学过一阵，老师说像把句号甩丢了，后来才改回来。

“等一下。”

老许的手停在半空。

那一项不是她眼前的挂钟。记录写的是候船厅侧门插销，换过一只。林绒先看年月，接着翻回前页，再翻到后一页。纸上没有大张旗鼓的东西，只是连续往下记的日期、物件和费用。

这一笔，晚了一天。

紧挨父亲名字的日期，是他离家的第二天。

林绒看着那几个数字，很想立刻拿手机拍下来，发给所有当年帮忙找过他的人。手已经摸到包口，又停住。

家里知道父亲哪天出的门。后来一直以为他当天搭船走了，却没有谁拿到过一张登船的凭证。三年过去，众人说得多了，她也渐渐把“该是那天走的”记成“就是那天走的”。

现在另一本册子说了另一件事。

“这行是当天记的吗？”

老许弯下腰：“你爸？”

她点头，手指压在日期下面，没有压住字。

“那时候不是我管登记。”他看了一会儿，“活干完补一笔也有。你别光看这个就……”

“我知道。”

她说得有点快。老许便不往下说了。

林绒重新问：“有没有哪一栏能看出是补记？”

老许把表头逐项给她看。没有。他去翻封面的值班名册，找到当时经办人的姓名：陈伯平。人还在港城，去年办理设备交接时来过这里。

“你认识他？”

“打过电话。你要问，我先给他发个消息。”

林绒说好，声音比刚才低了些。老许在手机上打了几行字，发出去，才把旧册转给她。她问能否拍这条记录，他点头，用空白纸盖住旁边无关的条目。

镜头对了两次焦。第一张，日期被她的手指挡住了。她挪开手，重拍。

“也可能不是他写的。”她说。

老许没急着同意，也没急着否认，只把旧册放在一边，不再急着装箱。

墙上那圈浅印还在。挂钟立在桌边滴答走着，没人打算再把它挂回去；新交接单已经写好了去处。

老许问照片清不清楚。她说清楚，却仍把那一行日期放大，一直放到笔画的边缘都散了。那几笔没有多出一个字。她关掉照片，免得手指又往回划。

老许把装螺钉的小袋系在钟背的挂环上，林绒弯腰收工具。钳子漏在桌脚，她已走出半步，还是回来把它装好；工钱也在内袋，下午的活没有丢下。

手机响了一声。老许看完，告诉她，陈伯平说明天下午在原来的渡口茶棚，可以过去找他。

林绒把时间记下来，给自己留了一行问题：那天记的是哪一天的活？

离开时她没有再绕到后面的检修口。渡站的大门敞着，明天该去哪里，她这回知道了。
