# 第四章 登记日

林绒提早到了二十分钟，陈伯平已经坐在茶棚里。

他面前横着一个牛皮纸夹，茶杯被挤到桌角。林绒问了一声名字，他就把对面的塑料凳拉出来，说老许早上送交接材料，照着她问的那笔活，把旧工单也带来了。

“我翻过了。你看看是不是这张。”

她坐下，包还搁在膝上。手机里那张照片昨晚已被她单独存进一个相册，相册只有一张，名字叫“渡站”。

陈伯平从纸夹里抽出三张订在一起的工单，底下压着一页登记册的复印件，是老许一并带来的。他将工单翻到第二张，指着右下方。

侧门。换插销一只。维修人那栏是她熟悉的名字，字比册子上松一点，没有挤到线外。

林绒先看日期。

不晚了。

工单写的完工日，就是父亲从家里出去的那天。

她把手机放到纸旁，重新找照片上的年份。年月、项目、费用都对。陈伯平又把工单右上角的号码与复印页上的一行对给她看。确是同一笔，登记在后一天。

“那为什么这里晚了？”

“抄上去就是后一天。”陈伯平把另外两张也摊开，“我收单先夹着，再一批登。你看，这两笔也在这页上。”

她沿着号码找到另两行。三笔工单的完工日有前有后，登进册子的日子却一样。

“每天都这样？”

“不见得。有时当天，有时攒两天。”他点着父亲那张，“这笔登晚了，不是多干了一天。”

棚外有人抖开篷布，积水哗地落下来。林绒把手机往桌里挪，三张纸都没淋到。陈伯平端回茶杯，等她接着问。

“我爸是当天签的吗？”

“没另记签字的日子。”

“也可能第二天才签。”

“可能补签。哪一张是谁什么时候拿来的，我现在记不住了。”

昨天老许也提醒过补记，她自己也问过。可从别人嘴里听见“可能”，总比看见这张工单容易些。可能里还空着一点地方，她能把父亲放进去。

“你那两天值班，应该见过他？”

陈伯平摘下老花镜，擦了擦，又戴回去。

“我见过你爸。哪天见的，真说不准。他有没有坐船，我没看见。”

林绒将相册关掉，又打开。她原本备了几句问话：他第二天几点到的，穿什么衣服，身边有没有人。第一句已经问不下去，后面却还排得整齐。

“你能不能再想一下？”

“我从昨晚就在想。”

“东西都留着，人怎么一点也——”

陈伯平伸来替她按纸的手停住了。

林绒盯着被风吹起的页角，把它按回桌上。

“对不住。我不是说你。”

他把茶喝了，没接这句话。林绒删掉备忘录里的“第二天几点到”，往下划到昨天最后留的那个问题，写上：是补登记日。

写完，她又看了眼工单。

“这个能拍吗？”

“能。别拿走，还要交接。”

她拍完父亲那张，又照下整批的页角和登记页。陈伯平用纸夹压住边，不让它们乱翻。林绒逐张看照片，确认没有把数字挡住，才将手机放下。

茶棚老板来问要不要续水。她说不用，杯子却还满着，老板的壶嘴朝她那里停了停，又收回去。她端起来喝了一口，茶早凉了。

工单在陈伯平手里重新叠好。三张，订在一处，她认得的那一张夹在中间。他往牛皮纸夹里送时，她险些又说等一下。

再打开，还是那几个字。

她点开母亲的名字，打了一句“问清楚了”。打完自己看着，后面该跟什么？她把光标放到句末，却又退回来，改成“我四点回店”。这又像在等母亲问她在哪儿、怎么了。她将这一行全删了，锁住屏幕。

“谢谢你。”她说。

陈伯平扣好纸夹：“以后要对这笔账，让老许找我。别的，我确实不知道。”

电话就在这时响起来。陌生号码，林绒等了两声才接。

对面是个女人，问是不是燕子招牌那家修补铺。她说是。女人说自己叫顾棠，原在这条街卖布，今天搬去隔街的铺面；刚从修补铺门前经过，见门关着，照门牌拨来的。

“下午还开吗？”

林绒望着桌上的纸夹。

“开。你修什么？”

“装剪刀那些东西的木盒，盖裂了，合页也松。我想搬完顺便带走。你四点能回来吗？”

她看了看时间。回店不用这么久。

“能。拿来我先看看。”

电话断了，林绒给号码存下名字，在后面加上“木盒，四点”。陈伯平起身拎纸夹，她跟着去柜边结茶钱，他摆了摆手，说刚才等她的时候就付过了。

她在茶棚外站了一会儿。备忘录里还剩两个问题，穿什么衣服，身边有没有人。没有确切的哪一天，这两句如今不知道该问谁。

她没删它们，退出页面，把顾棠的通话记录留在最上面。

四点回来。至少这件事，她刚刚答应了。
