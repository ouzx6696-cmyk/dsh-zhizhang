# 《这座山归我了》：胜利兑现与正文审读

本例为原创三章教学正文。学习能力怎样改变行动、对手怎样回应，以及胜利怎样被使用和享有；新作须重造欲望、能力和事件链。

## 1. 正文入口

- [C001《借我一条船》](这座山归我了-C001.md)：被拒给山，谈成合作，能力真正缓住坠峰。
- [C002《整座都要》](这座山归我了-C002.md)：对手侧拖，伙伴换位，金钱诱惑与仍要整山的欲望。
- [C003《这座山归我了》](这座山归我了-C003.md)：借坠重逼放索，永久闭合，驾驶山、回渡口并享有胜利。

## 2. 理解正文所需的设定

姜照野在山坞做过五年临工，想取得能自行决定去处和收什么人的飞山。讲法为热烈、开阔的第三人称全知，以她为重心，可以短暂进入对手、伙伴与渡口。

- 山心借高空灵风，经闭合的托山脉托山和转向；不能凭空造风。废峰旧主已撤印遣空，复航者可占有。
- 姜双手分别触及裸露断端才能临时接路；任一手离开即断。她借风，不以自身灵力托山，也不能控制他船。
- 完整石桥偏离内槽，拉回并合锁环即可永久接通；断端露脉面在外侧，不夹手。石台有踏坎、上阶通印台。
- 燕九独立拥有九鲤号，要三年免费泊位与一间栈房；她操船，阿岑挂索拨环，不能修时可撤回。
- 程铎用双索侧拖废峰，想送入拆解架。他有合理赢面，也会保船；双索不能长期承受完全失去托力的山。
- 第三章短暂断风，迫使程打开卸索扣；姜重新接风，燕和阿岑回位完成修复。胜利后要实际驾驶、停泊与交付合作所得。

## 3. 审读时检查什么

| 位置 | 容易出现的问题 | 处理原则 |
| --- | --- | --- |
| C001抵近废峰 | 尚未到场便知道全部故障；把借风写成自身负重 | 观察支持尝试，到场再确认解法；明确能力承担什么 |
| C001合作 | 燕在没登峰前替主角决定全部安排 | 先谈自己的泊位条件，保留独立判断和退出权 |
| C002挂索与换位 | 索钩去向不明；绕行关系难辨；重复讲操作 | 保留决定下一步的空间关系，其余过渡概述 |
| C002看钱 | 把诱惑写成虚伪试探，削平主角野心 | 让她认真想象钱的用途，仍选择整座山 |
| C003摆脱双索 | 只放绞盘线，未解除与大舟的连接 | 用已有卸索扣明确脱船；关键执行设计须回写规划 |
| C003能力断开 | “白光灭一半”让人误读为仍保留部分托力 | 表述与任一手离开即断的规则一致 |
| C003庆祝 | 一句“众人震惊”代替享有，或凭空添奖励 | 写松手后山仍升、调掌后山转向、燕实际使用泊位 |

上下阶、回船等非决定性过渡可一句概述。需要补关键解法时按设计变更处理；表达修订不能偷偷增加能力。

## 4. 回报怎样成为经历

三章的主要兑现是：她松开双手，山仍在升；她调掌，山能转向；她终于能决定去哪儿。燕真用上泊位，回应的是燕自己的欲望。不要把所有故事的兑现套成泊位、收据或换名牌。

全知可以从谷口、招募台和泊台写胜利进入生活。取回名帖的人与仍排大宗队伍的人并存，燕先考虑栈房怎么用；群体并不需要逐一认证主角伟大。庆祝可以保留野心，也无需附惩罚。

## 5. 取舍与适用范围

C002从桥停到第二次挂索的定位与操作负担偏重。借鉴时可压缩重复说明，把篇幅留给姜对钱的诱惑、等待中的判断及与阿岑的关系；保留手不能离开断端的限制。

本例覆盖一个近端单元。招人、过冬航行和航权之争只是后续方向，尚不足以构成全书规划。示例不提供读者偏好或市场效果结论。
