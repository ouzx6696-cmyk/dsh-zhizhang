# 商业连载章纲范例（以末世工程向作品为例）

> 这份范例说明章纲写到多细算够：写手不必再发明关键因果、关键证据、关键选择和撑起主要篇幅的经历；措辞、微动作和现场细节仍由正文完成。
> 本页为章纲格式教学示例，原出处未核实，不作为原作事实或市场案例。取用具体关系与四块组织方式，新作须重造专有名词和事件链。
> 可参阅，非门禁。番茄长篇连载（含技能默认）且问题适用时更贴切，不照搬硬冲突密度、四拍、代价或章末钩子。

## 范例一：高强度推进章

```text
# C015 路上有别人

> 视角：第三人称限知，贴着周野。
> 目标篇幅：2800—3200 字，仅为本例约定。
> 锁定事实：C014 已焊死左门并加装角钢铲；车外改装痕迹可见，需隐瞒的是特殊钢层的形成方式与车内结构。
> 人物知识边界：周野有前世避难所受管制的记忆，知道当年的军需用语；不知道本次车队所属、电台那端是谁、当前“避难码”的规则。不能凭旧记忆认定他们就是前世那批人。
> 承接与人物此刻：首次上路，前车留下可行驶的雪道，他想跟上以判断路况；有改装无线电，缺对方身份与封路情况。

## 1. 剧情梗概

周野沿重型车队的履带印驶上冰封省道。追赶时接到电台盘问，他以清障车身份回应以隐藏车内底细，却因此被前方封路者标记为待拦车辆。

## 2. 核心冲突与看点

- 新增钢层加重负荷，周野无法无条件提速，只能沿压实雪道缩短距离。
- 对方索要周野没有的避难码，他要探知前方通行条件，又不能交出车内信息。旧记忆只能提供措辞参考，不能替代当前情报。

## 3. 情节推进节点

- 周野在入口发现六道宽履带印，沿压实的痕迹绕开陷雪；看见前车尾灯后尝试追近，车头持续震响。
- 他在路边停车查看钢层与支架的受力处，确认不能再加速，重新上路时留出制动距离，不靠凭空提速追上。
- 无线电公频传来盘问：“后方自卸车，报避难码与吨位，三号桥已管制。”周野问是否允许清障车通行，对方只重申报码。
- 周野借前世听过的军需口吻答“重载清障车，无码”，不报车内结构。对方回“前车放行，后车桥头待检”，随即切断通话；周野知道无法混过盘问，减速驶向桥头。

## 4. 章末落点

弯道尽头红色信号弹升空，三台武装推土机封住桥头，已放行的车队从侧道离开。周野停在制动距离内，看清检查点位置；下一章从是否接受检查的现实选择开始，不直接宣告他知道对方身份。
```

写手得到追车理由、能力限制、信息取得与对方回应；具体路感、声音和现场动作仍由正文完成。人物已知与读者未揭示不能混为一谈。

## 范例二：安静章，可完整收束

```text
# C023 夜里的修理铺

> 视角：第三人称限知，贴着周野。
> 目标篇幅：2200—2600 字，仅为本例约定。
> 锁定事实：老骆左手腕有旧伤，与女儿守铺；周野还有半箱柴油，按原计划够行驶两天。女儿不知道车内隐藏结构。
> 人物知识边界：周野不知老骆的经历；老骆只从车重与外观差异判断车有秘密，不知道能力来源。女儿只见过车外。
> 承接与人物此刻：C022 补给谈崩，周野要找过夜处与北路消息，不能暴露车内，也不能耗尽剩余油料。

## 1. 剧情梗概

周野获准把车停在修理铺外，与老骆一起修好供暖机的化油器。两人从互相防备转为有限信任；周野让出所剩柴油的一半，即四分之一箱，留作铺内夜间供暖，得到老骆亲眼见过北路近期通车的消息。

## 2. 核心冲突与看点

- 周野需要住处和可靠路况，却不愿开车厢；老骆需要让女儿今晚暖和，也不想因收留来路不明的人被牵连。二人通过一起修供暖机试探对方是否尊重边界。
- 让油会把周野的计划续航减至约一天；他接受这一损失，是因修理铺可过夜且北路消息指向一天行程内的检查站。检查站能否补给仍未核，不能当作已保证收益。

## 3. 情节推进节点

- 卷帘门半开，老骆只允许周野停车在外，不让他把车开进铺内。女儿从里间问暖气何时能开，周野见到供暖机旁的漏油痕。
- 老骆旧伤使他拧不稳细螺钉，周野扶住化油器，两人边拆边讨论堵塞位置；老骆没有借机要看车厢，周野也不追问旧伤。
- 化油器修好但油桶已空。周野取出四分之一箱柴油，明确不打开车厢，也不交代去处；老骆接受，让他用铺内空床过夜。
- 供暖机启动后，老骆说旧北路十年前塌过，三天前他却亲眼见到车队从新修的东侧岔路回来；他在旧图上指出岔口与一天行程内的检查站，只保证自己看见的部分。
- 周野把新路位置标下，不把“有检查站”听成“必有补给”。两人听着机器稳定运转，老骆让女儿回暖起来的里间，周野睡下。

## 4. 章末落点

天亮前周野检查余油、收好标过岔口的地图，向老骆告别，再往北走。住处、供暖与有限交换在本章办完；新路是可核的下一步线索，不硬造突袭或假钩子。
```

安静章同样有具体经历、互相尊重边界与有限信任。所剩半箱、让出四分之一箱、再剩四分之一箱保持一致；可靠消息与未保证补给分清，不让写手自己补交易理由。

## 写完章纲后对照四项

1. 人物为何行动、顾虑什么、有什么条件，是否已在头注或节点给出？根基与硬边界由主代理抽取本章条件，不假定写手会扫全目录。
2. 关键因果、证据、选择和主要经历是否给足？正常措辞与现场细节仍留给正文。
3. 本章人和事是否具体，还是只有可互换的抽象任务？没有真实材料就补所需规划，不套四拍兜底。
4. 章末是否是实际抵达的结果或体验？悬念、心理、静景与完整收束都可成立。
