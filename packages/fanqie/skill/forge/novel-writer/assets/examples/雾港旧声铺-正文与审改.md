# 《雾港旧声铺》：五章接续与证据边界

原创教学正文依次为 [C001《先别缝》](雾港旧声铺-C001.md)、[C002《八块钱》](雾港旧声铺-C002.md)、[C003《挂钟还欠一天》](雾港旧声铺-C003.md)、[C004《登记日》](雾港旧声铺-C004.md)、[C005《先修盒子》](雾港旧声铺-C005.md)。学习有限能力、局部答案与人物欲望怎样参与不同事务，不套用修物委托的事件骨架。

## 1. 设定与讲法

第三人称限知林绒，语言清楚、有生活感，允许必要说明、直接心理与完整收束。这是本例的城市幻想兼人情悬疑取向，其他题材可有更强烈的争胜和分歧。

林绒触碰旧物破损处，可听见破损当时近旁实际说出的一句话。同一破口同句，无日期，不能追问、定位或读心；修复后留声消失，他人听不见。父亲失踪三年，能力不会因寻父而升级。

## 2. 五章的推进与承接

| 章节 | 本章经历与结果 | 接续不能越过的边界 |
| --- | --- | --- |
| C001 | 断鞋留声引出求助；核痕迹、喊话，救援人员救出阿满；约次日修鞋 | 旧声不证明当下有人；林不独自下井；钟未完工，鞋已归孩子 |
| C002 | 祖孙来店，讨论留鞋；检查双鞋，只换左扣，恰收八元 | 修复不等于恐惧治愈；门前两种声音来自木板，右鞋未坏不换 |
| C003 | 完成挂钟、收原约工钱；父亲姓名旁日期晚一天，约见经办人 | 条目是侧门插销；日期与笔迹不能证明父亲在场或登船 |
| C004 | 工单与登记页对照，答清补登记；接四点木盒委托 | 答清登记性质，未答清登船与去向；顾棠不是父亲线索人 |
| C005 | 林追问陌生旧话而延误；五点二十交盒收二十，失去潜在续单 | 木盒与父亲无关；抽屉尚未成交，不算现金损失；一次收手不等于永久成长 |

## 3. C001：把不确定线索变成负责任的行动

阿满爬回检修口时左脚搭栏，喊“别关灯”的同时鞋扣扯断。留声必须与破损时刻对应，不能把跌落后才说的话提前录进鞋中。

林绒告诉老许听见求助，但不能确认方位与是否仍在。未干蓝漆支持近期接触；老许暂停拆灯并联络救援，安全外侧喊话获得敲击后才确认有人。老许不听异能，不由新漆直接推到活人位置。救援为虚构情节。

钟一直拆在桌上，墙留浅印。等待、救援和离场都须沿用这个位置；不能把未完成的工作写成已经结算。

## 4. C002：日常选择也需要具体调度

祖母先递右鞋，再从袋中拿左鞋，避免袋子已经递出却仍由原持有人松袋口。两只鞋分别检查，右鞋不换、左鞋换黑扣，收费八元。

孩子只在门外木板玩过，听祖母说燕子招牌后才知道是这里，与前章问店址相容。修鞋前旧声仍在，桌旁活着的孩子问扣子；修后留声消失，日常继续。不要用一句“恐惧痊愈”代替这段经历。

## 5. C003：主题呼应不能伪造前章

如果后章写“上午有个孩子问我，东西补好是不是就都跟以前一样”，须核前章是否真有这句。没有就删掉这次回忆，不倒改前章替后章补证。林绒可以当场放大日期又关掉照片，让欲望进入眼前行动。

钟壳装回后立桌试走，挂墙螺钉另存；小钳带走。消息要有实际发送动作，原约工钱不改成昨夜才谈定。经办人正常回复，约成会面，不能靠无依据失联拖延。

## 6. 状态怎样随正文前进

C003结束时，鞋随孩子离店、断扣入废料盒、挂钟留渡站交接、工具由林带走。父亲线状态只到“有日期疑点，约见经办人”。C004取得对照材料后才能记“补登记已答清”，仍不能记“父亲晚走一天”。

C005结清的是修盒与二十元工钱；续单机会没有成交，客户信任也未自动恢复。已发生、人物所知与尚未设计的远期答案分别维护。
