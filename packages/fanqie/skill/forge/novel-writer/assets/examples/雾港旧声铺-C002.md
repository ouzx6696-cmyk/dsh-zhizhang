# 第二章 八块钱

九点还差三分，阿满在门外问：“你今天开门吗？”

林绒手里正捏着门板上的挂锁。

“你等我把这个拿下来。”

阿满站得笔直，一双鞋装在透明袋里，祖母替他拎着。他今天穿着凉鞋，进门时走得慢，倒没有要人抱；祖母的手一直搭在他肩上，跨过门槛又摸了摸他的额头。

林绒把矮凳挪到桌边。阿满坐下来，先把八块钱放好，再伸手去接鞋。袋子在两人之间停了一下。

“我想了一晚上，”祖母说，“要不还是别补了。我带他买双新的，这双看着就……”

她没把后半句说完，将袋口拧在手里。

阿满盯着那两只鞋，没碰钱。

“别急。”林绒没有去拿剪刀，“他昨晚说要补，今天还要吗？”

“要。”

“为什么？”

“以前穿这个踩你门口，会响。”

“你以前来过？”

“在外面玩。昨天奶奶说燕子，我才知道是这里。”

林绒朝门口看了一眼。店前铺了几块木板，右边那块是后来换的，颜色深，脚落下去的声音也短；老的那块声音空一些。阿满用手指敲凳面，先一下重的，又一下轻的。

“一个咚，一个嗒。新的我还不会。”

祖母吸了口气：“你还想往那种地方跑？”

“不是渡口。”他急了，指着几步外的门，“就这里。”

林绒把门撑开，让祖母看清那两块平整的板。她没说老人想多了，也没说孩子已经没事；昨晚那只光脚露在毯子外的样子，她自己还记得。

“鞋底我也看看。要是破了，响也不能留着。”

祖母从袋口抽出没断扣的右鞋，递给她。鞋底磨平了一点，没有开裂，扣带拉动时也稳。阿满把脚往凉鞋里缩了缩，像在等一个判决。

祖母终于松开袋口，低声说：“我看见它，就想起你不在上面。”

阿满没马上说话。

“我以后不一个人走渡口外边。”他说，“先不去了。”

祖母摸了摸他的后脑勺。过了一会儿，她把袋里的左鞋也放到桌上，问林绒有没有结实些的扣子。林绒先检查这只鞋的底和帮，再打开抽屉。

抽屉里有三小盒搭扣。阿满看中了亮银色的，林绒拿起来，挨着原来的扣带比了一下，又放回去。

“这个太大。”

“那黑的。”

“黑的可以。两边不一样，你介意吗？”

他想了想，摇头，又指着她刚检查过的右鞋。林绒把它放回凳边。

“这只没坏。不换，还是八块。”

祖母点了点头。阿满把叠成四折的钱展开，压在桌角，看着她拆掉断扣旁翘起的旧线。

左拇指触到破口时，昨夜的声音又来了。

“别关灯，我还在下面。”

桌旁的孩子正问，那盒金色的小扣是不是给大人用的。

林绒答是。他又问大人为什么不喜欢亮银色，她说也有喜欢的，只是鞋不一样。这几句话接在一起，旧声便显得很远，像隔着两扇关好的门；她仍听得清，却不用再朝哪处黑暗里找人。

她把合适的新扣缝牢，收住线头，指腹重新按过修好的地方。

没有声音了。

阿满伸长脖子：“好了？”

“先穿，别急着跑。”

祖母扶着他的肩，他自己把凉鞋脱下，将脚伸进蓝布鞋。林绒看他站稳，问哪边紧。他走了两步，说左边有一点。她重新调好扣带，让他再试，直到他不再总往左脚低头。

八块钱留在桌角。林绒数好，收进抽屉，把拆下来的旧扣放到他面前，问要不要。

阿满看了一会儿：“不要了。”

出门时，他先踏上深色的木板，咚地一下，又移到旧板，嗒地一下。两种声音跟他先前学的不太一样。他皱起鼻子，重新走了一回。

祖母已经迈到巷子里，又停下来。

“走吗？”

“再一下。”

她没催，等他最后踩完，才牵起他的手。林绒站在门内，看见左鞋的新黑扣和右鞋磨白的旧扣，随着他的脚步一前一后出了巷口。

桌上还留着一截不能再用的旧扣。她把它放进废料盒，合上盖，拿出下午去渡站要带的小钳子。
