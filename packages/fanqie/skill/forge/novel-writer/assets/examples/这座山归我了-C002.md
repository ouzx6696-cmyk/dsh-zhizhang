# 第二章 整座都要

阿岑抱着吊钩跳上石台，先朝姜照野的手看了一眼。

那两只手既没长大，也没有发出比山更亮的光。掌下白纹连成了线，风沿她的指缝过去，山上的松树一排接一排立直；从谷口望来的人只能看见云梭峰缓住了，阿岑却看得见，她的一边袖口已经磨破，正努力不让掌心被震开。

他把吊钩往肩上一甩，蹲到石桥旁。

“这头拉过去？”

“对着槽，先别合环。”

阿岑探手摸了摸槽底，抓出一把碎石，把吊钩扣上桥边的旧孔，朝燕九挥手：“船头再往右，让它直着进！”

绞机响起来。

石桥在槽边磨出一线青灰，向内移了半尺。姜照野看着那道缝，心里已经先跑上峰顶：空着的大殿不用再给别人留正座，北崖可以挂她喜欢的红灯，瀑布底下的货道要拓宽，九鲤号长一点的货箱才过得去。

山顶那片敞亮地方要先留给自己，卧房正对日出，推窗就是云海。若有来客嫌她占了最好的位置，她要请那人走到崖边，看一看她今日是从哪里爬上来的。余下那么大的山，谈得拢的人尽可以挑；但这一回，得先问她。

忽然，桥停了。

阿岑趴下去看，吊索斜绷在半空，正把桥往槽沿上压。他没伸手硬推，先冲船上喊：“停绞！”

九鲤号的帆还鼓着，山壁却在他们眼前一点点转。

程铎站在大舟船头，右手向外一摆，前拖索收紧，后拖索稍放。巨舟不再只拖住山，它要把山转过去，让原本朝向小船的石台从船侧挪开。九鲤号的绞索随之倾斜。桥已拉近的半尺还在，接下来的路却被扭偏了。

“姜照野！”程铎举起传声筒，“一百二十金，下来，帮我把风石拆全！”

阿岑看了她一眼，又看了她一眼。

白沙渡靠近石阶的那条街，有间带小院的房子，门上招卖的红纸贴了两个月，恰是一百二十金。姜照野每次路过都要向里瞥一眼，院中一棵枣树，墙外过船，站在自家门口就看得见。

她的手掌还压着风，脑中却极快地算了一遍：五年积蓄不够，他这一句话，够了。

“钱摆到船头。”她喊。

程铎盯着她。片刻后，一个木盘递到船栏边，金锭压着红布，顺着日光一字排开。大舟的甲板很高，红布却亮得连阿岑都看见了。

姜照野看足了，仰起头：“真好看。”

“上来就是你的。”

“我还是要这座山。”

程铎把传声筒放下，指向右舷。木盘没有撒，金锭也没有砸，回了账房；右舷多上了两名绞机手。

燕九骂了一句。不是骂姜不肯拿钱，是大舟把她能走的口子收窄了。要重新对准石槽，九鲤号必须换到拖索另一侧；大舟腹下看着空，拆解架上却伸着几排铁齿，帆进去容易，出来得留下半幅。

“别从底下！”姜照野喊。

“用你教！”燕九回得更响，“阿岑，卸钩，把索扔回来！我绕后索！”

阿岑先松开钩扣，将带钩的绞索从石桥上撤下，交给船上的人收回。他蹲在石台内侧，避开晃动的桥，抬头看姜照野。她双脚站在踏坎里，身体顺着山的倾斜往左偏；掌下那条白线却仍稳稳地亮着。

“还能撑多久？”燕九问。

“你能过，我就能等。”

燕九没有再说好听的话，九鲤号的船头陡然压低。后拖索从帆顶擦过去，离得近，阿岑甚至能看清索上缠着的旧麻线；小船贴着山腰往后走，巨舟侧投下来的阴影一寸寸压上它的帆。

石台前空了。

阿岑望着那片空处，忽然不知道手该放哪儿。平日船换位，他在船上，如今船带着所有熟悉的声响转到山后，只留下铁索碾石头的闷声。姜照野伸不了手，他便往前半步，替她挡住一块从崖上滚下的小石。

“你以前接过这么大的？”

“没有。”

“那你刚才答得那么快。”

“我接住了才答的。”

他低头看了看脚下。山确实还在，托着他们两个，连一旁那簇从石缝生出的草，也只是朝东偏了一点。

阿岑将两手的石灰在裤边擦净，盯住小船将要出现的地方。

姜照野两肩开始发酸，倒不觉得自己是在托山。托住山的是奔流的风，她只是站在门口，双手替它把路撑开。难的是不能松，不能摸一摸额上的汗，也不能扶住正在晃的山壁；山转一寸，她就得跟着调一寸，像头一回学着在摇晃的甲板上端一碗滚汤。

她从小端过许多碗，泼过，也烫过。父亲的船不大，母亲总说她走路没有轻重。如今这整座山在脚下，她反而慢了，膝弯顺着震动，掌心一丝不离。

山后忽然传来一声哨。

九鲤号的红帆从阴影里冲出来。燕九站得笔直，一手压舵，一手冲石台上比了个手势。新的绞索飞过来，阿岑接住，顺势绕桥，吊钩重新扣牢。

“拉！”

石桥抖了一下，先前卡住的边缘从槽沿上退开，终于正正地滑了进去。阿岑跟着它往内挪，手已伸向锁环，只等最后那半尺。

大舟的绞机声突然盖过了他们。

两根拖索一齐收紧，松林向同一个方向弯下去。程铎不再同他们较哪边对得准；若让那根桥进去，整峰就会成了能走的活物，他手上的索留不住多久。他要赶在这之前把山收进架中，哪怕压裂外头的岩壳。

铁肚子投下的影子越过石台，拆解架的尖齿一根根露出来，像一排正朝山腰闭合的牙。

燕九回头看见它，手没有离舵：“照野！换法子，拉不过！”

姜照野望向大舟，再望向脚下远得发白的谷底。

她一直在替这座山站稳。

可那条船，受不起整座山坠下去的重量。
