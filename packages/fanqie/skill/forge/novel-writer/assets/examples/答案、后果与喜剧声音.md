# 答案、后果与喜剧声音：三个正文示例

> **使用定位**：局部答案要有证明范围，答案之后人物仍可带着欲望行动；喜剧的自辩也是卖点，不能统统删成动作报告。《掌柜》的搭档仍偏务实提醒者，不作配角自主性范本；账目修对与笑声效果是两种判断。

完整正文为 [C004《登记日》](雾港旧声铺-C004.md)、[C005《先修盒子》](雾港旧声铺-C005.md)、[《掌柜说它会招财》](掌柜说它会招财.md)。本文自带采用依据，写作技能独立安装即可使用；前三章全文及接续入口见 [雾港旧声铺](雾港旧声铺-正文与审改.md)。

## 1. 三种叙事任务

C004示范旧问题获得局部答案；C005示范人物欲望怎样影响普通履约；《掌柜说它会招财》示范第一人称自辩与喜剧声音。三篇均为原创教学材料。

## 2. C004：把问题答掉，人物仍可能失望

### 采用依据

前三章已写：林绒救出阿满，第二天只换左鞋扣收八元，旧扣入废料盒；当日下午完成渡站挂钟、收原约工钱，钟留交接，小钳带走。旧维修册父亲名旁的日期晚离家一天，条目是侧门插销，不是挂钟。家人无登船凭证；老许不是当年经办，已联系陈伯平，约次日下午原渡口茶棚。

能力仍是触破口听破损时近旁实际一句，同破口同句，无日期/定位/读心，修好后消失，他人听不见。C004不用能力解决档案问题，不改旧三章。

本章规划：陈正常到场，老许早上因交接送来旧工单，陈按条目找过；同笔工单完工日等于父亲离家日、登记日晚一天。陈可说明批次登记，不记得具体送单或签字日、未见登船。答完本条日期问题后，顾棠按门牌电话问修木盒，林约四点回店先看；不是下一位父亲线索人。

### 问题与处理示例

工单、有限证据和正常会面已经具备时，仍须检查证据是否只靠口述、情绪是否被重复判词削平。

- 初稿另两单“都是这么记的”，读者没有见登记侧对照。修后补老许带的登记页复印件、工单号码匹配及三笔完工日不一而登记日相同。补登记页属于关键证据设计，须同步规划依据，按设计变更处理。
- 初稿让她突然说“那就是，他那天走了”，再由陈纠正，旁白与笔记又重复边界。修后让她实际想保住补签可能，急到说“东西都留着，人怎么一点也——”，随后道歉却没有得到圆满安慰。删除的是作者设题讲解，不是她的不理性。
- 删“相册有四张却比昨天小”等同义象征堆叠，保留不愿收纸与当场改删给母亲的消息，也保留“可能里还空着一点地方”这句心理解释。少解释不是绝对准则。
- 母亲消息在现场输入，不虚构昨日未发的新事件；茶钱由陈预付，林只是后来想结，避免一次离席又称早付过。

### 落点与取舍

登记日性质有答案，但签字时刻、是否登船、去向均未知；不能把“晚一天不支持到场”写成“已经证明当天离开”。工单对照增加事务质感，也占了情绪篇幅；本例选择让读者亲自核对，快节奏题材未必需要同样展开。

四点委托是她刚答应能做的事，不是已经放下父亲。林仍有急躁与渴望，陈也不用成为治愈导师。

## 3. C005：失约不能只靠钟针走过去

### 采用依据

同日下午四点，顾棠带外婆木盒，裂盖与松合页；林约五点取、二十元，顾同意内加铜衬。顾搬店，工具要拿去裁垫布，四只发涩抽屉先问能否修、以后再约，尚无价与时间。

林触破口听陌生男人说“别跟她说，我自己走”，第一次就知道不是父亲，却仍想问出解释。顾只要修好。能力不增信息，盒子无父亲关联。采用结果是五点失约、五点二十完成、顾付二十却不再约抽屉；旧话含义不解。

### 问题与处理示例

- 初稿四点四十拿铜片，掉地再捡就到五点，不足以支撑二十分钟延误。修后明确本来赶得上，她却主动松开夹具，等顾回来再问，暗自把“来时已好”改成“当着她也能做完”。张望与捂热铜衬承接等待，不需逐分钟直播。
- 夹具只是临时夹合，让手指够不到破口；松开后能再触碰，不是修复后声音重启。真正修好才消失，规则不因情绪改变。
- 初稿顾说“修盒子还是查盒子”“我不是来找话的”，像替编辑议题作答。修后她先提醒五点，回来拿出剪刀说明等着裁垫布；她不知异能，也无需讲隐私道理。
- 初稿“没有发现林绒的手”越过限知；改可见行为。初稿多出未用铜片、没写过记录却称“刚记的抽屉”，分别修为碎屑与开头先记待约意向。
- 保留林明知不是父亲仍追问、仍在想用一个解释替延误找价值的心理；末尾想拨号又退，不用“我学会尊重了”结案。

### 落点与取舍

修好、付钱、谢帮开门都真实，拒绝续约也真实，两者不互相抵消。抽屉没成交，不计算不存在的现金损失；一次退出拨号也不证明永久成长。

删掉利落金句，牺牲一点台词锋利，换成眼前工具与时间的压力；并非以后所有对话都应这样写。林的推测仍占篇幅，是行动成因，续写时若再同义重讲就会拖。

## 4. 喜剧：把账修对，不把人改成说明书

### 采用依据

架空仙市，第一人称陆谦爱体面、会算小账、嘴硬但能办事；陶七合伙分红，有自己的取布安排。卖八只普通便携灯罩，每只进七文、卖十二文，事先买三送一；木獾租八文。本例只按货本和租金算余款，不作现实经营模型。

木獾只有关/录/放：录档记随后第一句连续人声，明显停顿止；放档投随租铜筹重放，铜筹能从底口取回，不是钱。它不识谎、读心、搬货、造钱；正常可关，不能硬拖设备危机。

误录“穷话回家再说” → 正常重录广告 → 戏班杂务逐只试尺寸 → 八只按六只价付72 → 交货 → 扣56货本与8租金，余8各4 → 改录售罄、明早九点 → 关机收筹待归还。买家不是蠢人，没有额外大客户救场，陆也不因一单变谦谦君子。

### 问题与处理示例

- 初稿开头偶添“交摊钱”，结账未扣；删这个新成本，恢复写前口径。初稿说木獾比两个活掌柜赚得多，但两人合计也是八；改为木獾八、每位活掌柜四，笑还在，数学不谎。
- 补关档、录档、放档与末枚铜筹回收。铜筹只触发播放，不混营业额；结尾收好待还，不称已完成归还。
- 陶七初稿几乎句句机锋且包办提醒、写单与接送；修后删部分接梗，让她试货、坚持取布，把收桌留给陆，次日去货栈等他。陆真写单、盖印、绑绳、送街口，不以虚荣取消本事。
- 买家实试第七只，摆正再试、要长绳；删“没有要求凭空担保”的作者表扬，靠需求与动作体现认真。
- 保留较长自辩、“停得太稳重”“铺子缩回桌”“从木獾那头算”。它们不只重复事情，还让读者看到他怎样包装事情；一概删短会改掉主要喜剧来源。

### 落点与取舍

最后承认话都由自己说，又仍称折叠桌为“柜台”。他能履约，虚荣也还在，不给道德净化或全街膜拜。

删互怼可能减少瞬间段子密度，却给实际事务留空间；陶七仍较多处于提醒者位置，本章未充分展示她自己的成败。是否好笑、修后是否更受欢迎，无读者验证。

## 5. 能带走什么，不能变成什么

- 局部答案可以真结清，更大未知留其合理边界；后续可以来自生活和前段留下的欲望，不一定再给谜面。
- 关键时段由行为承担，后果由实际选择承担；不是每分钟直播，也不是每个主角都必须误事受教。
- 修数字、状态与证据，不顺手把偏见和讲述趣味消毒；多话、克制、激烈各需具体作用，不设唯一腔调。
- 删一句前问它提供了什么，换一种讲法也要承认得到与失去的东西；不把“少解释”当所有问题答案。

这些例子用于说明具体处理方法，不提供文学效果或市场收益结论。
