# 设定取舍示例：抽象说法怎样落到具体选择

> 以下为自拟的教学示例，只展示取舍理由；不是任何真实项目的事实或确认。

## 人物：自己相信什么，实际怎样选择

抽象标签是“修理店主周到、公平，又有些固执”。只列这些词，仍不知道一位熟客拿着急用的电扇插队时，他会怎么办。

一种候选：他认定自己从不偏心，却会先修熟客的东西，再把它解释成“这个顺手，耽误不了多久”。陌生顾客问起等候次序时，他才发现自己用熟悉程度替别人判断了急缓。可写之处是他怎样面对这一选择，不是让叙述者揭穿一句“他其实很虚伪”。

根基只需保留影响后续的欲望、惯用办法与认知差异。也可以选另一种人物：他确实按约定次序处理，熟客理解并愿意等待，关系依然能写。自我矛盾不是人物成立的门票；插队事件与过往经历在真实项目中都只能作为候选，不能伪装成原文。

## 规则：是谁定的，约束谁，是否真有例外

“周日不营业”在本例中是店主为休息订的店规，不是行业法则，更不是物理上不能修。暂拟的例外是：周六已约定、周日只来取件的顾客，可以按约取走成品；这不自动意味着周日接新活，也不意味着加钱就能破例。

根基可简记适用范围与已确定的例外；不把“沉默片刻才开门”记作规则代价，那只是某次反应。若人物误以为邻店也必须遵守这条规矩，要另记为他的误解，不能扩大客观规则。

这一差异会影响选择：新顾客临时求修，他可以拒绝、商量周一来，或提出一次破例的候选。是否改变长期规矩，要看本书约定及后续叙事，不能从一次开门推断以后都营业。

## 题材：把标签发展为本书的阅读承诺

“社区日常”还不足以决定故事。本例暂拟承诺是：通过修理与取件，写陌生人怎样逐渐愿意互相托付。于是，旧物修好后主人迟迟不来取，可以发展等待、误解与重逢；不必自动升级成重病或事故。

这不是禁止重病、事故或街区改造。若用户没有相应约定，“本书不写这些”就不能登记成禁令。根基可以保留题材定位和具体承诺，桥段仍按它在本书中的作用判断。

换成另一本悬疑，承诺可能是“读者能回看线索，理解判断如何修正”；换成成长故事，可能是“一个人逐渐学会承担自己选定的生活”。它们会改变展开重点，却都不要求每条信息必有反转、每次成长先受苦。
