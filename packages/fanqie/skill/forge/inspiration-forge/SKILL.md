# Inspiration Forge · 番茄灵感装填与章纲规划

把作者的脑洞、人物、设定和拆书技法，推导成写手拿来就能下笔的规划：题材想给读者什么 → 作品形态与平台节点 → 近端兑现 → 相邻单元的变化 → 远端候选。

## 2. 先定节奏档位，再用番茄刻度

作品已记录的平台、档位和作者选择优先。未记录平台时按番茄长篇取向（`资产/番茄平台.md`，单章按社区常见约 2000–2500 字起步，注明“默认，可改”）；未记录档位时按题材与作者材料建议一档，同样注明可改。档位定义见 `资产/交接契约.md` 第7.1节：

- 快爽档：前 300 字见处境；小回报约 1–2 章、阶段回报约 4–6 章；受压一般不跨 2 章。
- 稳推档：首章立住处境与所求；按事件自然完成，单元内必有可见进展。
- 慢燃档：先立氛围与问题；以信息揭示和关系移动为主要回报，允许长压。

平台节点对各档都成立：前 2 万字（约前 10 章）是连载首申材料，主线入口、人物动机和题材体验要看得清；前 8 万字（约前 40 章）是推荐评估材料，至少一次完整的推进与兑现已经发生；完本签约（2026-10-12 起 Lv.0、Lv.1 新作只能选完本）要求规划给出全书主线、关键回收与收束。数字会变，以 `资产/番茄平台.md` 的核对日期和作者后台为准。

## 3. 各档都成立的六条

- 卖点进入办法：把书名里的职业、能力或金手指换成普通名词，故事还能照演，就回去重推办法（`方法论.md` 第11.1节）。
- 对手可行回应：先列对手当场看见、知道、要保的东西，再推他最合理的反应，不靠降智送高光（第11.4节）。
- 回报在场兑现：结果要被人物使用、享受或承受；安静收尾与顺利办成同样有效（第11.5节、第8节）。
- 压缩不删依据：章纲标清主要篇幅与压缩过场；压缩时保留让对方改主意的事实、筹码或证物（第11.6节）。
- 卖点改变局面、对手主动出招：推进主线的章在章纲第 2 块写明卖点改变局面的那一拍，去掉它结果不变就重推；主要对手出场的章写明他的主动一招（`资产/交接契约.md` 第7.1节）。
- 慢不等于少：稳推、慢燃档每章也要有一个读者看得见的变化（新信息、关系移动、行动后果或实际进展）；连读时说不出某章变化，就补事件而不是补解释。

人物用 `方法论.md` 第4节推出行动；辨识度不够再补日常面具、底线、当下所求、标志性动作或器物（第11.3节），当下所求不限于钱。

## 4. 产物落位、制作顺序与边界

- 相对作品根维护 `state/story_foundation.md`、`state/current_state.md`、`workspace/volumes/V01.md`（多卷按需）、`workspace/acts/A01.md`、`workspace/outlines/C001.md`。
- 制作顺序：定范围、平台与档位 → 倒推最小上游与参考机制（需查库时读 `库位置.md`） → 按根基、阶段、单元、章纲制作 → 连读核因果、旧账与每章变化（幕纲与章纲里的日期、天数、金额要对得上） → 按 `资产/novel-writer交接格式.md` 交出开写依据，然后停止。
- 边界：拆解库只读；候选规划不冒充已发生事实；规划交付不自动开写正文，也不授予定稿权限；只迁移机制，不照搬原著专有人物与事件链。
