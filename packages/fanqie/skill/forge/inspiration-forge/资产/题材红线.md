# 题材风险与作者约束


> **用途**：提示题材相关的逻辑风险，并说明哪些约束才算硬约束
> **何时读**：规划涉及某题材、担心踩逻辑坑时
> **读完做什么**：把命中的风险带进设计问题；硬约束只按作者约定、现行根基、定稿事实与任务边界
> **不要读什么**：这里不是题材禁令，也没有禁词表、POV 次数表、章数铺垫表或固定境界表

> 来源：公开网文写作方法论文档的整理与本技能自建内容的合并（引用来源见技能根目录 `LICENSE`）。

**先说清这份文件是什么**：默认情况下，本文件给的是**风险提示**，不是题材禁令。它帮助发现逻辑上容易出问题的地方，**不把题材偏好写成规范**。

---

## 1. 什么才算硬约束

只有这几种来源算**硬约束**：

- 作者明确约定；
- 现行根基规则（`story_foundation.md` 里已锁定、会约束后续设计的规则）；
- 已定稿正文里发生的事实；
- 本轮任务边界。

不在上述范围内的审美选择（视角用第几人称、爱用哪些词、某类情节要不要写、是否混合中西词汇），由作者决定，**不由题材标签决定**。指出技术性风险时说清依据，**不拿"我见过 / 一般这样写"当规则**，也不请求作者逐项回答所有审美问题——能继续的先做，只有缺项会改变结果时才问。

**本文件刻意不含**这些固定参数：每章 POV 次数、每章线索量、铺垫章数、必须写生理压力、通用禁词黑名单、固定战斗境界列表、"同一方式不能打败两次"这类禁令、女性角色的泛化评判。它们不是通用约束，需要时由作者或根基另行约定。

---

## 2. 各题材真正相关的逻辑风险

> 下表按题材列出**容易踩的逻辑坑**，供设计时自查。命中不等于禁止，而是提醒"这里需要交代清楚"。

| 题材 | 主要逻辑风险 |
|---|---|
| `xianxia` 东方仙侠 | 战力体系前后不一（为情节方便忽高忽低）；突破/进阶缺依据；因果或规则设定沦为空话；大关（如天劫）写成走过场；能力与所付代价不匹配 |
| `xuanhuan` 传统玄幻 | 升级无依据；对手失败靠降智；战力标尺混乱；配角只当工具人 |
| `urban` 都市大类 | 生活水平、职业常识与角色设定不匹配（悬浮感）；对话脱离现实语境 |
| `urban-romance` 都市言情 | 关系跳跃（没有事件支撑就深情/死忠）；人物降智；用情绪宣泄代替情绪描写 |
| `urban-daily` / `urban-farming` 都市日常·种田 | 内容节奏与所写的生活不符；经营里的资源去向不清 |
| `urban-brained` / `urban-cultivation` / `urban-high-martial` 都市脑洞·修真·高武 | 能力的可行条件和边界不清；既有消耗未被遵守；设定前后矛盾 |
| `war-god` 战神赘婿 | 打脸反复同一模式；身份反差失去可信 |
| `western-fantasy` 西方奇幻 | 力量体系前后矛盾；世界观只靠个别词汇区分却不自洽；种族扁平化 |
| `ancient-politics` 古风权谋 | 权谋简单化（把对手写成蠢货）；信息传递不合逻辑；制度、礼仪与行为逻辑错误 |
| `historical` 历史大类 | 时代制度/服饰/器物张冠李戴；未核的史实当已核（未知须查证或标未核）；大段考据或旁白说明代替场景 |
| `historical-brained` 历史脑洞 | 金手指/科技推进无代价与限制；碾压式改写 |
| `anti-japanese-war` 抗战谍战 | 情报传递不合理；代价空泛 |
| `scifi-apocalypse` 科幻末世 | 科幻设定前后矛盾；逻辑漏洞；生存/物理压力不持续；机甲等规则前后不一 |
| `suspense-crime` 悬疑刑侦 | 推理不可追溯（跳过证据直接得结论）；专业流程/鉴定时间不合理；证据来源不可信，证人给出全知信息 |
| `suspense-paranormal` 悬疑灵异 | 恐怖只靠突然出现而非积累；规则不清就收尾 |
| `suspense-brained` 悬疑脑洞 | 规则事前没建立清楚就使用；智斗双方不对等 |
| `game-sports` 游戏体育 | 赛事目标与结算不清 |
| `derivative` 系（含动漫/男频衍生） | 见下文『衍生类：原作事实与作者 if 的分界』 |

## 3. 衍生类：原作事实与作者 if 的分界

衍生内容**仅在授权任务里**处理。原则：

- 区分**原作既定事实**与**作者明确要求的 if 变化**，两者不混，并在规划里标出各自来源。
- **不复制**原作的专有表达（特定台词、专有设定、独有场景细节）当自己的内容。
- "是否保留原作主角的高光""是否改写原作的悲剧"是**作者取向**，**不默认判为禁止**：作者说要改就改，说要守就守。把它当题材风险提示，而不是题材禁令。

---

## 4. 未知信息的处理

题材涉及的专业流程或史实，若不确定，**查证或标"未核"**，不虚构；标未核时说明它影响哪一步设计。需要作者决定的，只问会改变结果的那一项，不逐项罗列所有审美问题。

---

## 5. 覆盖说明

- 变体题材（如 `urban-daily`、`war-god`、`suspense-paranormal` 等）没有单独的题材风险条目时，按相近题材的风险提示判断，或直接向作者确认；**不凭空编造条目**。
- 本文件不含库样本统计；需要时的库内对应关系见 `拆解库/题材映射.md`，没有合适项就写无。
- 把题材提示转成可经历的故事、把风险落成具体修正的做法，见 `方法论.md`；可选的推进组织见 `结构形状.md`。
