# novel-writer 交接格式

通用主责、产物/证据状态与权限只在本技能 `资产/交接契约.md` 定义；本页补规划进入写作的具体责任。写作端派单见 novel-writer 技能根下的 `references/pipeline_handoff.md`（不在本技能目录内）。独立安装不依赖兄弟目录；它未安装就如实报告，接口有差异时按实际文件适配。

## 1. 机制先成为本书设计

从拆解成果只取相关机制、来源、实际范围与条件；重新设计人物、规则、证据、行动和结果。不把原书卡、专名或长段原句直接交写手当素材。无参考但材料充分可原创推导；不为流程造库。

## 2. 同一个作品根

- `state/story_foundation.md`：现行主线、人物、规则与锁定；事实/候选分开。
- `workspace/volumes/V01.md`：多卷才有。
- `workspace/acts/A01.md`：相关单元输入、具体推进和输出；局部任务可在章纲补最小依据。
- `workspace/outlines/C001.md`：现行章纲直接消费，不抄第二份。
- `state/current_state.md`：规划进度和正文快照分区；没有正文写无。

写作阶段按需补风格、编辑配置与硬边界入口，保留已有规划。复杂细目用 `workspace/plans/` 等，不批量改名。完整规则只留权威版本，硬边界入口可链接。

## 3. 章纲与轻量头注

新稿四块正文为剧情梗概、核心冲突与看点、情节推进节点、章末落点；头注为视角、目标篇幅、锁定事实、人物知识边界。模板在 `资产/模板/chapter_outline.md`。无额外锁定可明确写无；篇幅未定但不影响当前任务可注明。

跨会话或委派有用时再记录采用状态、依据修订/候选依赖、实际授权范围与下一步，不强新台账。作者自有格式只要内容充分就直接使用，局部适配冲突，不为机械格式批量改写。

关键选择、证据来源和主要经历应足以开写；对白、措辞、微动作留正文。节点不是五格表，也不强四拍、反转、代价、固定场数或钩子。示例见 `资产/章纲示例.md`。

## 4. 派写前由谁补条件

主代理核本章相关锁定、规则与实际定稿，将必要条件投影进章纲/派单；写手不代替主代理裁决全书约束，但必须遵守本章条件。编辑保有完整硬边界入口，必要时查相关出处。

写手拿到本章纲、前章全文（首章无；候选前稿标候选）、相关单元、状态及快照后有出处的必要增量、本书风格。不能为少读把关键证据和前章全文省掉；也不要求五状态文件全读。真实技能根、作品根、材料入口、唯一目标和停点要交清。

## 5. 正文回传

审读通过、真实归档授权和当前字节版本分别判断；草稿变动后旧审读失效。普通归档不覆盖现行定稿；授权修订用写作端 revision.md。

已定稿事实只校准受影响未来规划与状态；锁定/定稿冲突由作者裁决，不倒改正文救旧纲。未定稿可作条件依赖但不能进入定稿快照。生成稿和编辑通过不自动回参考库。

## 6. 完成说明

只报完成范围、实际入口、未决影响、剩余与下一步。格式/准备度工具、内容连读与文学评估分别声明；文件衔接不等于宿主自动调用或文学效果已验证。

## 7. 写手开写指令包（可选，随章纲附带）

跨会话或委派写手时，可在交付末尾附上这一块；字段含义与 `资产/交接契约.md` 第7.3节一致，缺项写无。

```markdown
### 写手开写指令包
- 写作范围与轨道：【如：C001–C003 连写；直出轨或诊断重构轨】
- 节奏档位：【快爽／稳推／慢燃／自定】
- 本章兑现：【本章读者最等的体验是什么，结果怎样在场落地】
- 视角人物此刻：【限知或全知；身体状态、手头筹码、当下所求与顾虑】
- 对手可行回应：【对手已知：……→ 本章合理反应：……】
- 篇幅分配：
  - 主要篇幅：【具体场面与阻力】
  - 压缩过场：【带过的流程，以及压缩时不能删的转向依据】
  - 旧账与知情红线：【本章必须接住的前文道具、伤势、账目、信息边界】
- 章末：【落点画面；需要钩子时写类型（危机／反转／收获／余韵），也可以完整收束】
```
