# 世界模块与世界状态

> **从主角第一次出现的地方往外建。** 用不到的地点、势力、历史先不写。
> 根据本轮所需依据组织人物和世界条件；两者可以相互推导，不按题材预设一律谁先谁后。
> 以下细目与状态记录按需增删；候选规划标明状态，实际变化另标定稿正文出处，不把未来预填成事实。

## 1. 世界模块

> 每块给一个便于跨章引用的标签（如 `#力量-金丹`、`#地理-北城`）；用不到就留空。

| 模块 | 要点 | 标签 |
|---|---|---|
| 力量 / 能力体系 | 阶梯、规则、上限与代价 | `#力量-` |
| 势力 / 种族 | 立场、强弱、与主角关系 | `#势力-` |
| 政治体系 | 谁掌权、规则、禁忌 | `#政治-` |
| 经济体系 | 货币、稀缺资源 | `#经济-` |
| 地理地图 | 关键地点、距离、势力范围 | `#地理-` |
| 历史大事记 | 开局前发生过什么、留下的线索 | `#史-` |

**都市/言情**把"力量体系"换成"圈层规则/职场规则"即可，**不要求都建**。

## 3. 世界状态随章表（需要时再记）

> 世界要随剧情变状态、并约束人物能做什么时，再记；不要求每章都记。

```
# 世界状态
- 第1章  【战争=是；某城损毁=20%；主角位置=…】
- 第8章  【某城损毁=60%；粮道断=是】
```

**用途**：防"主角去北城，可北城上一章已被夷平 / 此前从没提过它存在"。

## 4. 写章前世界四问

1. 当前世界状态是什么？
2. 主角此刻在世界里**能做什么 / 不能做什么**？
3. 本章冲突点是从世界规则里长出来的吗？
4. 环境 / 天气 / 地形对本章的情绪或行动有什么影响？

> 世界观是地基，**不是展览馆**。读者要故事，不要设定集。
