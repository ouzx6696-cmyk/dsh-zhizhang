# 黄金三章快启动示例（快爽档）·《鉴宝：从典当行断头账开始》

> **档位与用途**：快爽档示例，适合都市、年代、鉴宝、职业逆袭等强节奏商业题材。展示辨识抓手、对手可行回应和首卷回报节奏怎样落进章纲。文中“前300字”“七三分配”“小／中／大回报”等刻度只属于快爽档；稳推、慢燃作品不照搬，按 `资产/交接契约.md` §7.1 与本书 `story_foundation.md` 记录的档位取用。

## 一、 故事根基与高概念定位

- **形态**：长篇连载（黄金前三章首单元示范）
- **一句话高概念反差**：被掌柜推出去顶“收假货坏账”黑锅的典当行末等学徒（表面绝境），凭“双手掂重摸骨即可还原器物前三次易主磕碰痕迹”的独门验伤手艺，当场逼做局者吐出双倍封口费并反手盘下死当库（核心爽点）。

## 二、 人物辨识抓手与当下所求

### 主角：沈砚（19岁，永昌典当行三年学徒）
1. **外在保护色**：见人三分笑、随身揣半截算盘尺、凡事先问“折耗谁认”的市井小柜员。
2. **内在底色与逆鳞**：绝不替别人背坏账黑锅；谁动他的饭碗和招牌，当场连本带利讨回来。
3. **当下所求**：账上被栽赃三十两“假宣德炉”亏空，今日日落前不平账就要被扣光三年身契押银并逐出行会。
4. **标志性动作/器物锚点**：用大拇指指甲盖刮器物底足听声、用算盘尺量指缝。

### 核心对手：刘朝奉（典当行二掌柜）
- **自身所求与底线**：想独吞那尊真宣德炉的差价，把早年库房里一只掉包铜炉赖给沈砚平账；但他明年要接任总号大朝奉，绝不能在东家查账前闹出行会验伤丑闻。
- **已知处境 -> 可行回应**：
  - **已知**：沈砚没有入库原单，且铜炉确实在沈砚经手的副柜里。
  - **合理回应**：第一反应绝不是无脑咆哮，而是拿“免赔二十两、只扣十年身契押银十两”装好人哄沈砚画押认栽；当沈砚当众点出炉底暗伤是三个月前总库铁架刮痕时，刘朝奉立刻改口称“库房混放误拿”，并试图私下塞钱买走那只炉子封口。

## 四、 C001《押银一分不让》高密度可开写章纲示范

> - **视角与声线**：第三人称限知沈砚，市井冷隽、算账利落；左手拇指沾着刚擦铜炉留下的黑铁锈。
> - **目标字数**：2200字左右。
> - **本章看点**：300字切入逼签死局，靠“摸底足辨陈伤”第一口亮出鉴宝真本事，护住押银并主动敲梆掀桌。

1. **【切入（前300字）】**：算盘珠子拨到尽头，刘朝奉把一张写好“学徒沈砚眼拙收假、自愿以三年押银十两抵赔”的红契推到沈砚手边，印泥盒已经打开。
2. **【交锋与可行回应】**：
   - 刘朝奉假意叹气：“原本要赔三十两，我替你在东家面前担了二十两，按个手印，明天还能留你在后院看门。”（软刀子逼签）
   - 沈砚没碰印泥，双手托起桌上的铜炉，拇指刮过底足内侧一道半月形凹坑——指腹传来“先窄后宽、带樟木油脂包浆”的旧伤触感，上面却盖着一层刚用粗砂纸打磨出的生刺。
   - 沈砚把炉底翻过来朝向围观的两个柜员：“我是昨天才接的副柜，但这炉底压出来的樟木油印，非得在咱们总库三号架顶层压够半年才出得来。刘叔，这炉子到底是昨天进的门，还是在总库里睡了半年才挪到我账上的？”
3. **【主要篇幅与压缩过场】**：
   - **主要篇幅（快爽档可参考约七成）**：逼签时的软硬拉扯、拇指刮底足辨识“樟木油包浆压痕”的具体触感与话术交锋。
   - **压缩过场（约三成）**：典当行日常早课与昨日收货流程一句话带过，但**必须保留“沈砚昨日接手副柜时交接单上只有编号无器物详图”这一转向依据**。
4. **【章末落点与钩子】**：刘朝奉脸色铁青伸手要收回铜炉说“明日再查”，沈砚先一步抽走柜台下的枣木槌，反手敲响了柜台上方那面只有“封库核大账”才准敲的黄铜梆子。铜音震落梁上积灰。
