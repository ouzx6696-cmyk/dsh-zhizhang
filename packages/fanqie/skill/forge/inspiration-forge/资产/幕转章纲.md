# 从推进单元到章纲

用于已有幕或实际推进路径、需要展开章节时。章纲容器见 `资产/模板/chapter_outline.md`，推导原则见 `方法论.md` 第7节；本文件只展开章界、主要经历与批次接续。

## 1. 先读本段路径，不先套章数

读输入处境、具体行动与回应、选择依据和输出。辨认本段哪些经历值得让读者亲历，哪些是常规手续可略写。已有作者篇幅预算用于估容量，不从原作平均幕长或固定三拍倒推章数。

主要经历太少时回上游补真正需要的过程，或合并章节；不是让写手自行添事故。内容过密时调整章界，保留关键因果。一种变化可跨章，一章可有彼此关联的多个行动。

## 2. 给每章分配具体任务

沿路径安排本章关键经历与结果，说明和前后怎样连接。可以由后果推动，也可以由未完成目标、关系发展、视角和时间推进，不能只有“铺垫—过渡—高潮”的标签。

章界可落在事情办完、一次认识形成、关系变化或真实未结处，不强制危机高峰前截断。并行视角要注明时间、信息和汇合关系，不硬排成单线因果。

## 3. 展开节点

按本章实际发生顺序写：谁接触什么或采取什么行动，得到怎样的回应，什么改变了下一步，作出何种选择或形成何种发现，结果是什么。

关键证据需有来源和解释过程；重要策略需有可行条件；其他人物回应需符合其目标或处境。“谈完同意”“核实成功”“关系加深”不能代替作为主场景的过程。

顺利成功、安静相处和探索见识都可以支撑章节。不要为凑四拍强加失败、降智对手、惨烈代价或意外。若起承转合有助组织可使用，不是模板配额。

## 4. 给足与留白

读者主要经历与转向依据要确定，不能把支撑本章的关键选择留成“正文自由发挥”。措辞、微动作、现场节奏、每句对白交给写手，不把章纲写成正文。

规划可直接说明人物动机和体验方向，但不能只写情绪标签替代行动。专业过程若正是冲突核心，就给关键步骤；与本章无关的细账不铺开。

## 5. 落点与接续

章末写抵达的结果、关系或体验，及下一章真实需要接的内容。可完整收束；有未结就说明是什么，不强制每章新缺口、旧债或固定间隔的金手指揭示、送别与破功。

同一批连读，检查这一段的主要体验是否重复、关键依据是否遗漏、人物知识是否越界、前后结果是否对得上。修相关内容，不统计六个位置数字或维护强制判据总表。

## 6. 保存下一步

一章一份落 `workspace/outlines/C001.md`，相关章节在所属单元的章节链中定位。分批结束更新 `state/current_state.md` 的完成范围、剩余、下一步输入和未决项。

下一批从现行文件续接。原计划变化时同步受影响的未来章节；涉及作者锁定或定稿事实先说明冲突，不把未来结果写进正文快照。
