# 开书立项：卖点、主角、规则、节奏档位与读者承诺

什么时候用：开新书，或把脑洞推成能开写的故事根基。
产出：作者认可的根基（卖点、关键人物、影响行动的规则、节奏档位、读者承诺）。卷幕结构见 plan-structure，章纲见 plan-outline。

## 工具路线

1. 建作品：fanqie_project_create（title 必填；genre、premise 有就填，premise 写一句话卖点）。已有作品先 fanqie_status 或 fanqie_foundation_get，有效旧材料直接用。
2. 推演根基，二选一：
   - 灵感闭环（默认）：fanqie_inspire_start（goal、genre、pace，可带已采纳拆书卡）→ fanqie_inspire_forge_brief → 按本文推演 → fanqie_inspire_stage（kind=foundation）→ 给作者看 → fanqie_inspire_accept（apply=true）。
   - 作者已给足材料并明确让你直接写：fanqie_foundation_set，只传要改的字段。
3. 作者没点头，候选只停在 stage。规划交付不自动开写正文。

只在缺项会改变交付形态时问，最多两件，附建议值让作者一句话确认：签约模式（完本要规划到全书收束）；节奏档位（没说就按题材建议一档，写“按某档默认，可改”）。

## 1. 卖点：一句话加替换检验

句式：给想要某种体验的读者，看一个处在【表面处境】的人，靠【独有的办法、手艺、身份或信息差】，撬动【什么阻力】，近期拿到【什么】。

替换检验：把卖点里的职业、能力或金手指换成普通名词，故事照样能演，说明卖点没进入人物的解法。回去重推“他怎么用这个办法破局”，不要加设定。

- 反例：“鉴宝天才学徒在典当行逆袭。”换成普通学徒也能演。
- 正例：“被推出去顶假货坏账的末等学徒，凭摸底足辨旧伤的手艺，当场逼做局者吐出封口费，反手盘下死当库。”去掉辨伤手艺，第一场就破不了。

## 2. 主角与欲望：人物是决策引擎

关键人物每人五项，够推出选择就停：欲望；当下处境（被什么推着、期限）；认知（知道、不知道、误以为）；方法与资源；顾虑（不肯付的代价，有才写）。

判据：给他本轮实际处境，能推出一个有依据的下一步。推不出就补处境或动机，不补性格词。不为“立体”硬造秘密和缺点。配角离开主角也有自己的事，只在主角需要消息时出现就是工具人。

辨识度不够再补抓手：日常面具、底线与逆鳞、当下所求、一两个标志性动作或器物。当下所求可以是钱，也可以是安全、面子、关系、真相、一口气，别把所有人写成在算账。

核心对手加一行“已知处境 → 可行回应”：他当场看见什么、知道什么、要保什么，再推最合理的反应（否认、拖延、加价、收买、断尾、妥协、合作）。不靠降智送高光。

## 3. 世界与规则：只记会改变行动的

从主角第一次出现的地方往外建，用不到的先不写。每条规则写：能做什么、不能做什么（可验证，不写“很强”）；谁能用、生效条件、上限；代价（有实际消耗才记）；人物以为的版本（与客观规则分开，差异要能进剧情）。

- 立规则前问：谁会因此改变行动，读者能在正文感到吗？答不上就不立。
- 先立后守：规划阶段规则被情节绕过，回来补限制，不在下一章临时圆；已被定稿正文用过的规则不改，冲突报作者（见 plan-structure 第 7 节）。
- 硬机制书可按三问闭环，让升级可信：获得要什么接触条件，为什么需要特定的人、工具或工序，每次变强消耗什么（材料、时间、损耗、风险、关系）。本书明确没有消耗就不造代价。
- 医疗、法律、史实、工艺的关键处，查证或标“未核”。
- 时间只在期限、并行线、行程影响剧情时精确；资源流向复杂才记账。
- 起名：主要人物连读一遍，读音不撞；别名登记到正式名下；称谓和物名合时代；改名同步所有引用处。

## 4. 节奏档位：立项时选一档

写进根基 pace（快爽、稳推、慢燃）。作者没定就按题材建议一档：逆袭、打脸、系统、鉴宝、高武、重生偏快爽；权谋、经营、种田、日常、多数言情偏稳推；悬疑、灵异、刑侦、温情、群像偏慢燃。交付写“节奏按某档默认，可改”，作者确认前不算锁定。各档刻度和“卖点亲自改变局面、对手主动出招、慢不等于少”等硬要求见 rhythm，这里不重复。

立项时只核一件事：选定的档位和读者承诺对得上。承诺“当场打脸”却选慢燃，或承诺“慢慢看一种生活”却按快爽排受压上限，先改一边。

## 5. 读者承诺

根基写清：长期体验（读者追什么）；开篇第一口（爽点、奇观、疑问、氛围、关系都行，按本书驱动选）；主线（谁想做什么、根本阻力）；终点方向（未定写“未定”，不能同时声称收束已规划）；取舍（本书不写什么）。

题材速查（设计提示，不是市场统计）：

| 主体验 | 开篇让读者尝到 | 中后段新增量 | 冒充内容的水文 |
|---|---|---|---|
| 成长、高武、仙侠 | 有辨识度的能力首秀，当场改变生死或资源归属 | 能力新用法、对手针对性反制、地盘扩张 | 刷面板、路人排队震惊 |
| 悬疑、规则、民俗 | 尽早切入怪异处境，凭手艺或观察给出首个小答案 | 局部答案推翻表象，牵出更深利益网 | 只挖不填、靠梦和巧合破案 |
| 复仇、重生、逆袭 | 第一章斩断旧吸血关系或截胡先机 | 夺回控制权，双方按新筹码洗牌 | 连写受虐铺垫、只打嘴炮 |
| 经营、种田、年代 | 专业判断或信息差解决温饱或第一桶金 | 产业升级、分润博弈 | 百科式工序、报流水 |
| 言情、双强 | 双方基于底线的初次交锋或利益绑定 | 信任边界实质移动 | 贴糖标签、误会传话拖章 |
| 历史、权谋 | 借制度漏洞破眼前死局 | 势力洗牌、盟友对手互换 | 现代口号碾压、满朝皆傻 |
| 轻喜、脑洞 | 离谱设定撞上认真的世俗规矩 | 设定在更复杂规则下的连锁反应 | 烂梗堆砌、破坏因果 |
| 日常、治愈 | 生活质感与小确幸落袋 | 关系沉淀、旧事回响 | 无主线流水账、硬塞绝症 |

高发逻辑坑：战力标尺忽高忽低、升级无依据、关系无事件支撑就跳跃、资源去向不清、推理跳过证据、时代器物错位。衍生作品分开原作事实与作者 if，不复制原作专有表达。

## 6. 平台节点对立项的影响

签约、推荐的字数节点与规则见 platform（以作者后台当期为准）。立项时据此定两件：签约模式未知且会改变交付形态时问一次，走完本路径就把全书主线、关键回收与收束列进 planned；连载路径就让主线入口、人物动机和第一次完整的推进兑现落在前段章纲里。

## 7. 四态分开，字段落位

已发生（定稿正文落地的）、锁定（作者不许改的）、采用（批准开写的方案）、候选（备选，不当事实透支）分开写。

| 内容 | 字段 |
|---|---|
| 一句话卖点、题材 | fanqie_project_create 的 premise、genre |
| 作者锁定的身份、规则、边界、结局 | locks |
| 关键人物与对手回应 | characters |
| 主线、终点、阶段计划、读者承诺；标“候选”的想法 | planned |
| 未结伏笔 | threads |
| 读者已知 | readerKnowledge |
| 文风与讲法 | style |
| 节奏档位 | pace |
| 定稿后的已发生 | happened（fanqie_foundation_append_happened 逐章追加） |

字段模板见 templates-plan。
