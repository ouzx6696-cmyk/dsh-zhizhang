# 规划类模板合集

什么时候用：要落一份根基、人物卡、规则卡、卷纲、幕纲、章纲、精简拆解或技法卡时，照下面的字段填。
用法：字段是容器，不是必填表。没有的写“无”或删掉那一行，不为填满而编；【】里的提示语不能留在成品里，fanqie_outline_check 会把它判为占位。各字段怎么写好见 plan-foundation、plan-structure、plan-outline、library。

## 1. 故事根基（写入 fanqie_foundation_set 或 fanqie_inspire_stage kind=foundation）

```markdown
premise（一句话卖点）：【表面处境】靠【独有办法】撬动【阻力】，近期拿到【什么】
pace：快爽／稳推／慢燃（作者确认前注明“默认，可改”）

planned：
- 主线：谁想做什么，根本阻力是什么
- 读者长期体验：
- 开篇第一口：
- 终点方向：（未定写未定）
- 本书不写：
- 阶段计划：（候选标“候选”）

locks：作者锁定的身份、规则、边界、结局走向；无写“无”

characters：（每个关键人物一段，格式见第 2 节，写摘要）

threads：伏笔名｜表面含义｜真实用途｜计划埋点｜计划回收｜状态（计划中／已埋／已回收／明确留白）
readerKnowledge：读者已知、而人物未知的事
style：人称与讲法、语言取舍、禁用写法
happened：（只在定稿后由 fanqie_foundation_append_happened 逐章追加）
```

## 2. 人物卡

```markdown
### 姓名（别名：）｜定位：主角／对手／重要配角｜状态：候选／已定
- 欲望：
- 当下处境与期限：
- 认知：知道……；不知道……；误以为……
- 方法与资源：
- 顾虑与不肯付的代价：（有才写）
- 辨识抓手（按需）：日常面具／底线与逆鳞／当下所求／标志性动作或器物
- 对手专用：已知处境（看见、知道、要保）→ 可行回应（先手、退路）
- 语言指纹（可选）：口癖、句长、不会说的话
- 弧光锚点：开篇状态 → 结局状态；关键转折（未定写未定）
```

自检：给他本轮处境，能推出有依据的下一步吗？

## 3. 规则卡（能力、制度、物品通用）

```markdown
### 规则名｜类型：客观规则／制度／个人条件｜状态
- 能做：（具体可验证）
- 不能做：
- 谁能用、生效条件、上限：
- 代价与消耗：（有才写）
- 例外与压制：谁能绕过、为什么
- 人物以为的版本：（与客观规则不同时写）
- 会因此改变行动的人：
```

需要防资源跳变时，加一张流向表：章｜进或出｜数量或状态｜交代。需要倒计时时，加：事项｜起点｜期限｜兑现章｜状态。

## 4. 卷纲（fanqie_inspire_stage kind=volume_plan，多卷才建）

```markdown
### 卷名（id、chapters 范围）
- 本卷把主线推进到：
- 本卷核心问题与阅读体验：
- 主要路径与关键变化：
  1. 路径 → 变化
  2. 路径 → 变化
- 卷末结果：兑现了什么承诺，留下什么
- 下一阶段入口及前置：
- 本卷涉及的锁定与未决：
- 档位（本卷换档才写）：
```

核对：没有这卷主线走得完吗？删掉它体验受损吗？

## 5. 幕纲（fanqie_inspire_stage kind=act_plan）

```markdown
### 幕名（id、volumeId、chapters 范围）｜单位：幕／事件群／关系段／探索段
- 输入处境：人物、关系、资源、压力（接上一段的输出）
- 本段问题：能不能……？
- 推进路径：行动 → 回应 → 条件变化 → 选择及依据 → 后果
- 与上一单元相比变了什么：问题性质／主动权／关系／能力用法
- 本段回报及在场享有：
- 章节因果链：
  | 章 | 关键经历与转向依据 | 结果及承接 |
  |---|---|---|
- 输出状态：
- 必须遵守的锁定与已定稿事实：
- 未定项：（不能拿来撑已完成章纲的关键因果）
```

## 6. 章纲（fanqie_outline_set）

```markdown
chapter：c001　title：
pov：人称与限知、贴谁；此刻身体状态、手边筹码、注意力偏见
targetWords：2200
locks：本章相关的锁定与旧账（伤势、物品去向、约定、金额、时间）；无写“无额外锁定”
knowledge：各人物当场知道／不知道什么及来源；读者已见与角色所知分开
synopsis：一两句：谁为了什么做了什么，抵达什么结果
conflict：承接的期待；卖点改变局面的那一拍；对手主动的一招；读者拿到的变化
beats：按发生顺序：切入 → 行动 → 回应 → 转向依据 → 选择或发现 → 结果；主要篇幅给哪场，压缩哪段及压缩时不能删的依据
ending：落在具体人、事、声、器上的结果或余韵；钩子类型或完整收束
```

## 7. 精简拆解（默认拆书交付，配 fanqie_reference_analyze）

```markdown
# 《书名》某段：一句话说清好看在哪

范围：读了……；未读……。版本：……

## 这段怎么组织的
三到五句：从哪起压、怎样加码、在哪兑现、兑现后留了什么。关键处附章号或行号。

## 技法 1：一句话技法名
- 原文怎么做：具体动作与位置；逐字短引放引号里并附位置
- 为什么起效：分析判断
- 带到你的书里：① ② ③
- 必须重造：欲望、能力边界、对手筹码或代价
- 什么时候失效：

## 技法 2（有则写，不凑数）

## 迁移包
目标题材与阅读痛点；可迁移的体验；三步做法；必须重造；主动舍弃的原著事件链或降智桥段；失效边界。
```

自检：每条技法能指到原文位置吗？引号里全部逐字命中（fanqie_quote_check）吗？三步做法离开原著人物道具还能执行吗？

## 9. 变更提案（改设定或改规划时）

```markdown
- 原依据：哪一幕、哪一章、哪条作者要求
- 改什么，与现状差在哪：
- 哪些不动：
- 影响范围：受影响的幕章、人物、规则、伏笔，各需同步什么
- 与作者锁定或已定稿正文的冲突：（有就等作者裁决）
- 未采纳部分：停在候选
```
