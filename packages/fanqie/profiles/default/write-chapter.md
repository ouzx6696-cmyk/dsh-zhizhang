# 写章流程：从章纲到交付

写第一章、续写、按章纲写某章、连写多章时用。产出：采纳为草稿的一章正文，附交付说明。默认路线已在常驻总则里，本页只补每一步怎么做好。

## 一、动笔前：备齐材料

1. `fanqie_outline_check`（本章）：8 字段齐全、无占位。缺的是措辞级细节就照写；缺关键因果、证据、选择或撑起主要篇幅的经历，回规划补（见 plan-outline），不让写手临时发明。
2. `fanqie_chapter_brief`（默认 lean）：拿到写法、幕、上一章正文、毒点与本书讲法。
3. 核这五样，缺哪样定点补哪样：
   - 本章章纲（含视角、锁定事实、人物知识边界）；
   - 上一章**全文**，从真实结尾接续（首章无；连写时给所依赖的候选前稿全文，并标明是候选）；
   - 相关幕纲或单元依据；
   - 根基里与本章有关的锁定、已发生、未结伏笔（`fanqie_foundation_get`）；
   - 本书文风与节奏档位。讲法未定时按番茄默认起步并在交付中注明“可改”。
4. 按需再读：节奏拿不准读 rhythm；有场面问题读 scene；句面读 prose。不读整份编辑方法。

省无关内容，不省前章全文、关键证据和知识来源。

## 二、想清四个落点再写

1. **主要篇幅给哪场亲历**：读者最等的那段（破局、交割、揭开局部答案、两人说开）。从人物当下的动作、器物或处境进入；快爽档约前 300 字让读者看到处境。
2. **视角人物此刻**：身体状态、手边的东西、最想要和最怕失去什么。所求可以是钱，也可以是安全、面子、关系、真相；别让每个人都在算账。
3. **对手的已知与主动一招**：他当场看得见什么、要保什么、按自身利益会怎样设卡、抢先、加码、反咬或换规则。能力或手艺写成有阻力的具体动作。
4. **章末落在哪**：结果、在场享有，或钩子（写清类型）。事办完了就完整收束。多数章停在具体动作、器物或新接口上，不以口号收尾。

各档都成立：回报在场被使用、享受或承受；压缩过场时保留让对方改主意的事实、筹码或证物；证据证明力有限时，写成人物据此追问、止步或换办法，不写成作者免责说明。

## 三、写候选

- 一口气写完整章，再回头改。生成中的正常自我纠错不等于逐句打分。
- 写手展开对白、措辞、微动作和现场节奏；**不改**关键因果、代价和结局，不规划下一章，不凑场数，不硬塞章纲没有的转折。安静、单场、无转折、完整收束都不是停点。
- 篇幅照章纲 `目标篇幅`；与内容明显不匹配时回报，不注水，不把关键节点挪到下章。
- 写好后 `fanqie_candidate_stage`（`chapter`、`content`）。同章可多次暂存；要合并多稿走旁路 `fanqie_chapter_drafts` → `fanqie_candidate_unify_brief` → `fanqie_candidate_unify_stage`。

## 四、两道自检，然后采纳

- **局面改变测试**：找出卖点（能力、手艺、身份、信息差）亲自改变局面的那一拍，设想删掉它。结果不变，说明卖点只在旁观，重写这一拍。常见病灶：对方在主角介入前已自己做完决定。安静过渡章可以不亮卖点，但不连续两章缺席。
- **本章变化测试**：一句话说出读者读完多得到了什么：一条新信息、一次关系移动、一个行动后果，或一笔实际进展。说不出来就补一个具体变化，不补解释。

然后 `fanqie_candidate_accept`。采纳内置语感扫描，不必先跑 `fanqie_style_lint`；命中只是回看提示。采纳等于进入草稿，不等于定稿。

## 五、审读、核账、定稿

1. 审读：按常驻总则派编辑子代理或自审，方法见 edit，回报用 `fanqie_review_report`。自审不能声称是独立审查。
2. 改过正文后 `fanqie_ledger_check`（本章，默认连带上一章），核法见 continuity。
3. 定稿：`fanqie_chapter_save` `status=final` 会弹作者确认。审读通过不等于获准定稿；正文一改，旧回报失效，须重审。作者没点头就停在草稿，告诉作者审读结论即可。
4. 定稿后用 `fanqie_foundation_append_happened` 记一句本章后果，必要时 `fanqie_foundation_set` 更新 `threads`（未结伏笔）。

## 六、连写多章

- “按这些章纲写三章”已经指定范围，直接写，默认交三章草稿；定稿权另算。
- 有事实依赖的章节**串行**：每章走完写、审、交，再把实际落点、新增或失去的东西、人物新获知、未结事项传给下一章。
- 前稿改动后，只重核依赖它的后稿和未来章纲，不全书重读。
- 停点只限：授权撤回或范围不明、关键事实查不到、章纲与锁定或定稿冲突、外部改动造成版本冲突。一般文风意见不阻断；不为推进倒改前章或临时补下一幕。

## 七、交付说明

写清：完成了哪几章、各自状态（候选、草稿、待审、已定稿）、实际落点、未决问题及影响；平台或讲法按默认时注明“可改”；正文含模型生成内容时提醒作者发布前按平台当期功能声明 AI 参与（见 platform）。正文里不夹审读标签、模板栏或“人物此刻”之类规划字样。
