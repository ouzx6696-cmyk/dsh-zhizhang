# 卷与幕结构，幕转章纲

什么时候用：根基已有，要排全书、卷、幕（推进单元），把幕纲拆成章；或连读发现因果断裂、主角突然换目标、整段原地打转。
产出：卷纲、幕纲（含章节因果链）、一章一份章纲。章纲字段写法见 plan-outline；节奏刻度与长线节奏病见 rhythm。

## 工具路线

- 全书、卷、幕规划：fanqie_inspire_stage（kind=book_plan、volume_plan、act_plan；卷幕填 id、title、content、chapters，幕可填 volumeId）→ 作者确认 → fanqie_inspire_accept（apply=true）。
- 章纲：逐章 fanqie_outline_set（或 fanqie_inspire_stage kind=outline 走采纳）；整批写完跑 fanqie_outline_check。
- 恢复现场：fanqie_status、fanqie_foundation_get、fanqie_chapter_list、fanqie_outline_get。

## 1. 先定本轮范围

- 作者要哪层做哪层。只要章纲，就补够这一段的依据，不扩成全书；要整套，就覆盖全部范围，远端可粗，但说明粗到哪。
- 从最终产物倒推最小上游：章纲要本段关键经历、转向依据、人物知识；幕纲要人物处境与行动条件；卷纲要主线与阶段方向。只补真缺口。
- 大范围先排全范围的阶段走向，再按自然单元分批细化。每批落盘；批次结束不等于全范围完成。

## 2. 四层互锁：每层都要被下一层用上

设定、卷纲、幕纲、章纲是一组互相约束的关系：上层约束下层，下层反查上层是否成立。

| 层 | 落在哪 | 向下约束 | 下层用不上时的病 |
|---|---|---|---|
| 设定 | 根基 locks、planned | 能力怎么得、上限、代价 | 规则漏洞、设定自嗨 |
| 卷纲 | volume_plan | 本卷承诺、卷间入口 | 动机断层 |
| 幕纲 | act_plan | 章节因果链、压力走向 | 整幕无人推进 |
| 章纲 | fanqie_outline_set | 具体的人、物、阻拦、结果 | 空转章 |

互锁检查（规划交付前、批次末各做一遍，自下而上）：

1. 每条会改变行动的设定，指出它在哪一幕哪一章被用上；指不出就删，或排进幕纲。
2. 每个卷级转折，在幕纲里找到承接它的那一幕；找不到就是断层，按第 3 节天堑前置补。
3. 每一幕说得出谁在主动推进；整幕只有作者在交代背景、或主角被动等事来，改幕纲。
4. 每一章落到具体的人和阻拦。“外部压力增大”不算；“劫匪皮卡堵住出城路，拒绝让行”才算。落不到就回幕纲补事件。
5. 修的方向：缺规则补设定，缺动机补上卷末的前置，自嗨段从幕纲删。只改未来规划和设定，不倒改定稿正文。

## 3. 卷：多卷才建

卷界来自目标、关系、处境或体验的重要变化，不由字数均值或转折个数算出。卷纲写四件：本卷推进主线到哪一步；本卷核心问题与阅读体验；主要路径与关键变化（够推出幕即可）；卷末结果与下一阶段入口。

核对：没有这卷主线走得完吗？所有卷连起来是一条完整故事线吗？删掉一卷不影响主线和体验，就合并。

### 天堑前置：下卷目标由上卷结果引出

上卷做 A、下卷突然做 B，是长线最常见的断层。倒推修：

1. 先定下卷主角要做什么。
2. 回到上卷末问：什么条件让他非做不可，或真心想做？
3. 把这个条件写成上卷的结果，在上卷后段幕纲里排出它怎样形成。可以是被逼的门槛（路被封死、原地活不下去、解法只在别处），也可以是主动追求、关系或认知的变化；不要求每卷都设绝境。
4. 核：下卷第一幕的行动，能否只凭上卷末的处境、资源、关系、认知推出。推不出，就补前置或改下卷目标，不让人物凭空换目标。

例：卷一收在出城道路被酸雾彻底封死，而新装备的原料和工艺只在另一座城，卷二开路建厂就接得上；卷一若只收在“打赢了”，卷二开厂就是硬转。

## 4. 幕：一段因果推进

幕围绕一个问题推进，常伴随处境、信息或关系的重要变化。内容是事件群、关系段、探索段时，声明实际单位，不硬套危机。

推进链（每幕都要写得出）：人物想做什么 → 用什么办法 → 他人或环境怎么回应 → 条件怎样变化 → 人物继续、调整、交换、放弃或选择 → 得到什么结果。

- 阻力可以是他人目标、制度、资源、误解、环境或自身顾虑。办法可行就让它成，不必每幕都失败、都更难。
- 转向追到来源：选择来自人物，证据来自可接触的材料，办法来自规则与已有资源。不靠临时规则、巧合证据、降智对手。
- 关键证据和策略来源在幕纲里定下，不写“待正文发挥”。
- 相邻两幕至少变一样：问题性质、主动权、关系或能力用法。变化可以是更近、更亲、更清楚，不只是更大。安静段判据是读者对人物或关系的理解是否改变。

常用组织形状（套不上就按内容组织）：目标推进（本段的处境、资源、认知变化成为下段输入，忌只靠加敌人升级）；单元游历（人的变化引出下一单元，忌无积累）；关系累积（信任、误解、立场变化引出下次互动，忌一句“关系加深”）；双线多视角（一条线揭示的东西改变另一条线的意义）；期限或空间约束（约束造成的处境变化成为下段条件）。

### 自增殖危机链：让变强本身制造下一个问题

适合目标推进型的成长、经营、生存类，是一种驱动，不是必选。

1. 写下本幕主角得到的提升（能力、装备、地盘、名声）。
2. 问它带来什么新负担：消耗、维护、暴露、被索要、超出现有上限。
3. 让这个负担成为下一幕的目标；三到五环后，链尾逼出一次卷级突破。

链例（废土改车）：改装提速 → 自重油耗翻倍跑不远 → 抢耐用部件 → 新部件散热管暴露 → 加防护 → 满负荷磨损加速、没配件 → 闯废墟抢修件 → 抢到的东西超出现有能力 → 逼出卷级技术突破。

判据：每一环的负担来自上一环的收益，而不是作者另派敌人。幕末问“主角处境为何比幕初更受挤压”；关系、生活、认知类幕答不上不算病，按输入输出是否实质不同判。

## 5. 开篇三章（快爽档常用排法）

第 1 章切入人物当下处境并亮出独有办法；第 2 章对手按已知合理反制，人物换办法；第 3 章完成一轮完整交锋，留篇幅让人物在场享有结果，再引出新问题。稳推、慢燃可以用一章立氛围与问题，只要读者看得懂。示例见 examples-plan。

## 6. 幕转章纲

1. 读本段路径：哪些经历值得读者亲历，哪些常规手续可略（判法见 scene 第七节）。章数按“目标总字数 ÷ 单章预算”粗估，再按经历容量调。
2. 分配任务：给每章一个关键经历和结果，写明与前后怎样连；不能只有“铺垫、过渡、高潮”标签。
3. 定章界：可落在事情办完、一次认识形成、关系变化或真实未结处，不强制截在危机高峰前。经历太少就并章或回上游补过程；太密就调章界，不删关键因果凑字数。
4. 展开节点与落点：按 plan-outline 的字段写；并行视角注明时间、信息和汇合关系。

### 互换判据：这章的人和事能不能和别章互换

章纲写完，每章做两次替换：

- 换位：把本章挪到前一章或后一章的位置，还成立吗？
- 换人：把本章的对手、配角换成书里另一个同类角色，还成立吗？

任一成立，这章就是模板兜底，缺本章专属的东西。补到同时满足：起点是上一章的具体结果；冲突来自这个人此刻的利害（他这一章才知道、才要保、才会失去的东西）；至少一件只属于本段的物件、信息或地点；结果改变了下一章的条件。补不出就并章或回幕纲补事件，不留给写手临场发明。

## 7. 连读与逆向校准

规划交付前、批次末、跨会话接续前，按翻页顺序连读本批涉及的章。单章都合格、连读垮掉，是长线最常见也最难救的病。

因果与设定：
- 每章由上章结果自然开始吗？主角突然换目标，按第 3 节倒查。
- 规则被绕过：还在规划阶段，回设定补限制；规则已被定稿正文使用或作者锁定，不补限制救纲，列出冲突请作者定。
- 正文连续偏离幕纲，重排剩余幕章，不硬写完旧计划。
- 日期、天数、金额、数量前后一致吗（fanqie_ledger_check 抽对）？人物有没有用到他当时不可能知道的信息？

人物：
- 欲望、知识、代价跨章一致吗？成长后以定稿正文的新选择为准，不写回旧状态。
- 配角是不是只在主角需要消息时出现？给他一件自己的事。
- 关系隔几章真的变了吗，还是停在原地？

推进（刻度见 rhythm）：
- 开篇尽早让读者看到人物处境，而不是先背世界观？
- 推进主线的章指得出卖点改变局面的那一拍？对手按已知反应、主动出过招？
- 每章一句话说得出读者多得到了什么？阶段胜利后留了享有篇幅？
- 相邻两章或两单元在重演同一骨架吗？同一冲突模式连用、逐章刻意升级，按 rhythm 第六节处理。

发现问题定位到源头修：缺动机修人物，证据断修前置，路径断修幕纲；同步改受影响的后续章纲，不在末尾加解释硬圆。

## 8. 修订与正文回传

- 改设定或改规划先讲清：原依据是什么、改什么、哪些不动、影响哪些幕章人物伏笔、是否碰到作者锁定或定稿正文。碰到就列影响等作者裁决，无关部分继续做。
- 定稿正文回传的新事实，只用来修受影响的未来章纲，用 fanqie_foundation_append_happened 记已发生；不倒改正文救旧纲。
- 未采纳的改动停在候选，不与现行规划并列生效。
