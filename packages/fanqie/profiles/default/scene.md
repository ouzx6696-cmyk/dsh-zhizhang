# 场景与情节手法

章纲已经具体，但动作看不清、对白只在搬信息、多人场面乱、信息放得不对时查。它解决“怎样把已定的剧情写成经历”，不能替代缺失的剧情：章纲本身太薄，回规划补。

## 一、先问这一段让读者经历什么

关键转向可按五格检查：**目标、条件、行动、回应、结果**。不是每场填满五格。结果可以是成功、安静相处、认知转变、关系移动或完整收束，不要求每场以失败或对峙收尾。

- 场景按经历、视角、时间组织，不和章纲节点一一对应，不按字数平分。重要的谈话和选择写足，过渡一笔带过。
- 上一场的结果冲击人物时，可用续场：**反应**（情绪先于判断）→ **困境**（没有完美选项）→ **决定**（引出下一场目标）。长线里常压成几句心理加一个动作；连续升级的章整段省掉。
- 起承转合只是参考。章纲没有转折就照写，不自己编。

**跳步判据**：“交涉后同意”“努力后成功”“经过一番”包住了本该亲历的过程，就还原：谁先开口，谁亮底，对方怎样回应，回应怎样改变下一步。办法确实可行就让它顺利，不为有戏硬造失败。常规流程照样可以概括。

## 二、动作：位置和办法接得上

- 先定：人物要到哪、护住什么，障碍在哪，双方彼此看得见、够得着什么。
- 只写改变局面的动作，并接住它带来的距离、遮挡、疲劳、伤势、资源变化。上一个动作的结果影响下一个。
- 速度来自时间压力和选择余地，不来自统一切短句。
- 伤势和体力不瞬间清零；硬时间窗口里塞的话和动作要来得及（例：三次呼吸内不能再插一串台词）。
- 对手熟悉规则时，不能亲手递出主角的解法。主角要靠普通手段逼出破绽、争到机会（例见 examples-write）。

## 三、对白：想得到什么，怎样开口

写有诉求的台词前问三句：他想让对方做什么？为什么不直说（面子、怕暴露、没把握、没到时候）？对方听懂了什么、愿意回什么？

- 关系够近时直说也成立；寒暄、陪伴、一起观察都可以，不把所有谈话改成交易，不让人人打哑谜。
- 双方都知道的背景不借嘴重念；只说有分歧的那一点。
- 声音来自经历、习惯、关系，不按职业发统一口吻，不只靠口头禅。
- 动作只在参与谈话或处境时出现，不按每一两句插一个。
- 让人物尝试错误的说法、被对方拒绝转向，比内心旁白事后总结更有戏（“钱是我付的，退起来也——”“我说钱了吗？”）。

## 四、视角与转场

- 沿用本书已定的叙述方式。限知视角里，人物的判断和猜测不能冒充别人的内心；“他明白了她的心”改成可见行为（停手、交回联系方式）。
- 切换视角要让读者知道观察位置变了，且新视角带来新经历，不是复述同一事件。
- 换场后尽快让读者认出时间、地点、跟着谁、上一场什么仍在起作用。回家、开门、睡觉等路程省掉；中间若发生改变承诺的争执，不能用一句“次日”抹掉。
- 情绪随时间和新经历变化：不换地点就忘了刚发生的事，也不几天后还维持峰值。

## 五、多人场面

- 每个在场者有**独立诉求**，不全场只绕主角转。旁听者开口必须改变下一步，不按人头加微动作或表情。
- 同意要可见：谁提议、谁问条件、谁确认，比“众人同意”可信。若本章重心不在交涉，可以概述，不是每场谈话都扩成议事。
- 读者理解靠正文：规划里清楚的规则（计分方式、机关、谁守哪里），正文要在人物看、拉、走的动作里交代，不让熟知规则的人物互相上课。
- 不添题面没有的期限或危机来制造紧迫；紧迫从人物看到的变化里来（对手在恢复体力）。

## 六、信息释放

- **读者知道多少，按本书选**：读者知道底牌而对手不知（爽感直给）；或读者少知、误判（悬疑、关系）。按章纲人物知识边界执行，不自动泄露未揭示真相。
- **公开方案也有悬念**：执行前让读者知道计划，悬念转到能否履约、追不追得上、对方怎样误判。不用“他另有妙计”遮住人物正在想的东西。
- **局部答案真结清**：一个问题答完就答完，更大的未知保留合理边界。证据证明力多大写多大：“登记晚一天”不等于“证明当天离开”。
- **发现类场景**写清：人物要回答什么问题、接触到什么材料、怎样理解、哪些仍待核实。人物说法不等于事实。
- **设定在需要时出现**：规则帮助读者理解眼前的判断和后果时交代清楚，不让读者猜规则；不用临时新规则救场。

## 七、前台与后台

只问：读者亲历这段，会不会改变理解或感受？会就是前台，写过程；只是告诉读者别处已办完，就是后台，带过。账目、手续、逐笔数字只写到读者理解眼前事所需；但谈价、核账、专业操作本身是冲突对象时，保留关键过程。
