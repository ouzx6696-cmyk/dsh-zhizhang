# 写作类模板

需要给本书立文风、整理当前状态、写硬边界入口或卷末总结时用。每个模板写明存进哪个工具字段。只填本书真有的项，空栏删掉；已有有效内容直接沿用，不按模板重建。章纲、根基、卷纲、幕纲模板见 templates-plan。

## 一、写作风格约定

存入：`fanqie_foundation_set` 的 `style`。讲法未定时可按番茄默认起步（短段、一屏两三段、关键结果单独成段、台词短而带目的），注明“技能默认，可改”。

```text
【核心取舍】本书怎样讲：叙述视角与距离（如第三人称限知，贴主角）；语域（市井、冷峻、热烈……）。
【观察偏见】2–3 条：主角第一眼先看什么／嘴上怎么说／心里真在意什么。（例见 prose 第四节）
【句子与段落】句长倾向、何时单句成段；有手机阅读要求才写。允许长段和独立心理就写明。
【对白】主要人物说话的可辨差别（来自经历和关系，不按职业）；对白标签习惯。
【心理与描写】直接心理怎样处理；哪些细节值得展开。
【不想要的写法】作者明确不要的（如：不写主角圣母谦让）。普通偏好不升为硬约束。
【编辑额外取舍】作者希望编辑特别保留或特别留意的（如：保留主角嘴碎的自辩）。没有写“无”。
【样段】本书已定稿的代表段落位置及示范哪一点；没有就空着，不伪造。
```

## 二、当前状态

存入：根基各字段（`fanqie_foundation_set`），批次或单元末更新受影响部分。不写逐章流水，不预填未来。

```text
happened（已发生，每章一句，定稿后用 fanqie_foundation_append_happened 追加）：
  C004：林绒以工单对照答清补登记，父亲是否登船仍未知；接下顾棠四点的木盒委托。

threads（活跃未结：已发生且仍影响后续的约定、伏笔、未决问题）：
  - 约定：【时间、地点、对象】出处：C0xx
  - 伏笔：【埋设内容】出处：C0xx；预计回收：【未定可写未定】

readerKnowledge（读者已知、角色未知的关键信息）：
  - 【信息】读者于 C0xx 得知；主角未知／对手未知

characters（人物卡中随正文更新的部分）：
  - 【人物】当前所求；已知／未知／误以为；伤势与体力；关键物品在手

旧账（本书真有才记，可写进 threads 或人物卡）：
  - 账目：谁付了多少、余额归谁，出处
  - 器物：关键道具当前在谁手里
```

## 三、本书硬边界

存入：根基 `locks`。编辑据此判“本书硬约束”。完整规则只留一处，这里写条目或指向根基对应段落，不抄第二份。

```text
1. 命名与身份：易混的正式称呼、别称及成立条件。
2. 规则与能力边界：能做什么、条件、上限、消耗与例外（本书没有消耗就不写）。
3. 作者锁定：不可改的设定、关键结果、结局走向。未揭示仍有效，人物只能用有来源的已知。
4. 作废项：已失效的安排及范围。候选被否不等于早先定稿作废。
5. 数字与表达约定：作者确立的口径（如货币单位、年龄、时间线）。没有写“无”。
```

改作者锁定或已定稿事实，先请作者决定。

## 四、卷末（单元末）总结

用在卷末或跨会话交接前，先连读本卷章节（检查项见 rhythm 第六节）。交付给作者；需要留档时，把压缩版写入 `happened` 卷末一条，并同步 `threads`。

```text
【本卷核心变化】主角从什么处境走到什么处境；关系、资源、知识的实际变化（只写正文支持的）。
【兑现的承诺】本卷兑现了哪些期待，在哪章。
【保留的未结】仍未解决的问题及后续触发条件，对应 threads 条目。
【计划与正文的偏离】哪些原计划被正文改变或失效；需要回规划重排的范围。
【下卷入口】下卷开头的处境与前置条件是否已在本卷正文立住。
```
