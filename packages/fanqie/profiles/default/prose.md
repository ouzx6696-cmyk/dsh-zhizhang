# 句面与人味

写前定声线、写后按症状回看句子时用。产出：去掉有症状的套话、保住人物声音的正文。原则：**按症状改，不按词表改**；`fanqie_style_lint` 与采纳扫描的命中只是“值得回看的位置”。

## 一、写前：三条习惯

1. **先写人物眼前的事**：他此刻想办成什么、怕失去什么、手边有什么。叙述者的眼光和人物处境决定什么值得看见，不平均介绍房间。
2. **具体不等于堆料**：不多报尺寸品牌，不给每句心理配一个身体动作。优先写看得见、听得到、碰得到的：物件状态、身体反应、空间关系、声音。
3. **关键结果单独落地**：账到账、战力亮出、被压制的那一刻，用最短的句子独立成段，不和解释挤在一起。高潮单感叹号，不叠用。

番茄默认取向：段落偏短，一屏两三段；手机上超过约 160 字的段会被体检标出。这是默认，不是配额：关系、心理、铺陈的句子可以长，本书已定讲法优先。

## 二、病型与改法

| 病型 | 例 | 改法 |
|---|---|---|
| 五官套话 | “眼中闪过一丝寒芒”“嘴角勾起一抹冷笑” | 换成和手头器物、职业习惯、身体处境绑在一起的动作 |
| 情绪直判 | “他感到一阵愤怒”“心中涌起一股不甘” | 写刺到他的细节和他立刻去做的事；人物真在权衡时可直接写心理 |
| 辩证翻案 | 叙述用“不是 A，而是 B”替人物下结论 | 写他看见什么、做了什么、没做什么，让读者自己看出 B |
| 过程跳步 | “经过一番交涉/观察”“敏锐地注意到” | 还原一个具体回合；卖点所在的过程必须亲历 |
| 路人认证 | “众人倒吸一口凉气”“大家都震惊了” | 写具体某人的具体反应及其后果（伙计不敢接话，视线往总库门上瞟） |
| 重复解释 | 同一意思说两三遍没有新层次 | 删并；先核是不是母题回声、口癖或递进 |
| 自我限定 | 叙述反复“还不能确定”“并不意味着”“只能说明” | 让人物据此去试、去问、去冒险；真实的证据限制写成止步或换办法 |
| 作者免责 | “这条记录并不能百分百证明……证据链还存在缺口” | 改成人物的追问和对方的回答（“有没有哪一栏能看出是补记？”） |
| 段尾感悟/章末口号 | “这一刻他明白了……”“反击才刚刚开始” | 停在动作、残局、器物或未完的事上 |
| 台词搬背景 | 双方都知道的事借嘴宣读 | 只说有分歧的那一点 |
| 播报式结算 | “她成功获得了控制权，大家都很高兴” | 把胜利写进身体感知和实际使用（见 rhythm 第四节） |

正例（同一情节）：

- 套话版：“看着管事轻蔑的眼神，姜照野心中涌起一股不甘。经过一番心理斗争，她坚定地要回了押金。”
- 处境版：“她把掌心朝上，摊在桌边。掌纹里有洗不净的青灰，昨天她还钻在凌霞峰底下，替一群将来要御剑飞天的人接他们食堂的风道。原来今日谈的仍是灶火。‘把我的押金还我。’她说。”

处境版没有一个情绪词：掌纹的青灰交代了五年临工，“原来今日谈的仍是灶火”交代了失望，动作交代了决定。更多对照见 examples-write。

## 三、误杀防护：这些不改

- 人物口癖、市井狡辩长句、喜剧自辩（它让读者看到人物怎样包装事情，删短会改掉喜剧来源）。
- 不可两全时的自私、拧巴、不体面。
- 大胜后的热烈欢庆与群体反应。
- 讲清规则、交割的必要说明句；有作用的直接心理（“他想留下，又知道自己答应过天亮前回去。”不必改成握拳咬牙）。
- 台词里的谨慎、套话、情绪词：那是人物性格。
- 引用的消息、书信，刻意的排比。

上述句式出现在这些位置，没有症状就不动。长句不一定拆，短句不一定补长。

## 四、声线锚定：用观察偏见代替形容词

在本书文风里（`fanqie_foundation_set` 的 `style`，模板见 templates-write）写 2–3 条“观察偏见”：第一眼先看什么、嘴上怎么说、心里真在意什么。比“幽默、明快”有用得多。

- 市井掌柜：凡事先算成本与折耗；嘴上一律往阔气里叫（折叠桌叫柜台），心里每一文钱的去向门儿清。
- 狠人夺权：不跟看不起自己的人争口舌，只看对方手里有什么可抢的实利；咬住就不松口，拿到手要站高处让人看见。
- 拧巴情感：嘴上理由冠冕堂皇，心理活动诚实拆穿自己的自私；越理亏越盼对方先发火。
- 冷静查证：先看哪里和平时不一样，再想谁有机会动过；话只说到证据撑得住的地方。

## 五、题材声线速查

| 题材 | 声线与视距 | 笔墨给 | 易失手 |
|---|---|---|---|
| 仙侠、高武、能力夺权 | 热烈开阔或贴身紧绷 | 能力运转的接触感、对手见招拆招、夺得后的公开享有 | 技能名对轰播报；赢了突然谦让 |
| 都市、年代、鉴宝经营 | 市井烟火、行家眼光 | 看破门道的瞬间、压价话术、落袋点数 | 写成行业百科；账算错 |
| 悬疑、规则、民俗 | 冷静克制、限知贴身 | 反常痕迹、手艺交叉核验、局部真相落地 | 感叹号凑恐怖；线索边界写成免责 |
| 言情、婚姻世情 | 细腻、潜台词足 | 利益与承诺冲突时的试探、回避、摊牌，一个暴露边界的微动作 | “深深地看着她”代替交锋；单方道歉大团圆 |
| 复仇、重生、逆袭 | 冷冽果断、节奏明快 | 截胡先机、对手算盘落空、旧账当场讨回 | 长篇复习前世惨死；只赢口舌 |
| 历史、权谋、群像 | 沉稳老辣、多方并置 | 同一句话落进不同人耳朵触发不同算计 | 配角当应声虫；高潮插播史料 |
| 轻喜、脑洞 | 一本正经胡说八道 | 为保体面的精密找补、离谱道具在严格规则下的乌龙 | 全员互飙烂梗；为笑破坏逻辑 |
| 治愈、种田 | 温润松弛、细节精准 | 手艺修复的踏实、不越界的善意、季节积累 | 无病呻吟空景；章尾硬造绝症 |

本书已有讲法和定稿永远优先于本表。
