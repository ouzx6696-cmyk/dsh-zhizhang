# 章纲：8 个字段怎么写好

什么时候用：动笔前给某章写或改章纲。章怎么切见 plan-structure。
产出：一章一份章纲，8 字段齐全、无占位，写手不必再发明关键因果。

## 工具与机械门槛

- 写入：fanqie_outline_set（chapter 必填），字段对应：

| 字段 | 参数 |
|---|---|
| 剧情梗概 | synopsis |
| 核心冲突与看点 | conflict |
| 情节推进节点 | beats |
| 章末落点 | ending |
| 视角 | pov |
| 目标篇幅 | targetWords（正整数） |
| 锁定事实 | locks |
| 人物知识边界 | knowledge |

  可选定调：situationLens（视角人物处境与注意力偏见）、livedScene（哪场亲历、哪些概览）、stateLens（本章人物状态与写法取舍）。
- 检查：fanqie_outline_check（chapters=本章或区间，默认 readiness）。以下直接判不通过：任一文本字段为空；出现 TODO、TBD、待填写、待补、待正文发挥，或模板提示语留在【】里；目标篇幅未设或不是正整数。超出 1500–6000 字只警告；章序缺号警告。
- 通过检查只说明格式齐，不说明能写。动机、因果、可写性要你连读判断。

## 给足与留白

- 下限：写手不必再发明关键行动、他人回应、证据来源、选择依据和撑起主要篇幅的过程。
- 上限：不锁死对白、措辞、微动作、现场节奏。章纲不是正文。
- 可以直接写动机和情绪意图，但不能用情绪标签代替事件（“关系升温”“交涉成功”不是经历）。

## 8 个字段

### 1. 剧情梗概（synopsis）

写什么：一两句，本章主要经历、人物当下意图、实际抵达的结果。
判据：读完知道“谁为了什么做了什么，最后到了哪”。
- 反例：“主角陷入危机，展现实力，打脸反派。”（标签串）
- 正例：“沈砚被逼签认赔字据，他摸出假炉底足的旧伤，指出炉子在总库放过半年，护住押银，并敲响封库核账的铜梆。”

### 2. 核心冲突与看点（conflict）

写什么：本章承接哪种阅读期待；卖点亲自改变局面的那一拍；主要对手按自身利益主动出的一招；读者本章拿到的具体回报、信息或关系变化。
判据：去掉卖点那一拍，结果会不同；慢档也写得出一个看得见的变化。没有敌对冲突的章，写清看点是什么（共同注意、核对过程、关系试探）。

### 3. 情节推进节点（beats）

写什么：按实际发生顺序，谁接触什么或做了什么 → 得到什么回应 → 什么改变了下一步 → 选择或发现 → 结果。再标篇幅分配：哪场是主要篇幅（写透阻力与来回），哪些常规流程压缩带过；压缩处保留让对方改主意的事实、筹码或证物。
判据：
- 他人回应符合其已知与利害，不降智。
- 发现类场景写清接触了什么材料、证据能支持到哪里；人物说法不当真相。
- 专业操作、谈价、核账是场景核心时给关键步骤，常规手续可略。
- 节点数按实际需要，不凑四拍、不硬加失败或反转。

颗粒度对照：
- 太粗：“大家交涉后同意换时段。”写手得自己发明限制、说服依据和确认路径。
- 足够：“甲队琴师只在前段；乙队长核过本队安排后接受后段；甲队确认腾空时间；管理员据双方确认改原预约。”
- 太满：规定每句台词、每次停顿。限制写手，没有增加依据。

### 4. 章末落点（ending）

写什么：本章最终抵达的结果、在场享有的过程或余韵；需要钩子就写类型（危机、反转、收获期待、新决定）。
判据：落在具体的人、事、声、器上，不以口号或总结收尾。事情办完可以完整收束，不为悬念再造反悔、来信、车祸。fanqie_foundation_append_happened 记的已发生通常从这里来。

### 5. 视角（pov）

写什么：人称与限知范围、贴谁；视角人物此刻的身体状态、手边筹码，以及会影响他看见什么的偏见。
判据：写手据此知道哪些信息能写进叙述，哪些只能从别人的行动里漏出来。

### 6. 目标篇幅（targetWords）

写什么：正整数字数。作者未定时按 2000–2500 估，并在交付里说“默认，可改”。
判据：篇幅服务于主要经历，不为字数门槛注水；主要场面占大头（快爽档可参考七三开）。

### 7. 锁定事实（locks）

写什么：本章不能违背的作者锁定和旧账：伤势、物品在谁手里、约定、金额、时间。没有额外锁定就明写“无额外锁定”，不留空。
判据：只投影与本章相关的条目，不抄整份根基。写前对一遍上一章实际正文（fanqie_chapter_read）。

### 8. 人物知识边界（knowledge）

写什么：各主要人物当场知道什么、不知道什么、靠什么来源得知；读者已见与角色所知分开。
判据：正文里没有人用到他当时不可能知道的信息；关键获知要有来源（亲见、被告知、推断并标明）。

## 精选示例（快爽档，教学虚构）

《鉴宝：从典当行断头账开始》第 1 章《押银一分不让》

- 视角：第三人称限知，贴沈砚。市井冷隽、算账利落；左手拇指沾着刚擦铜炉的黑铁锈。
- 目标篇幅：2200
- 锁定事实：沈砚昨日才接手副柜，交接单只有编号没有器物详图；押银十两；本章不揭刘朝奉私吞真炉的全部内情。
- 人物知识边界：沈砚只知炉子挂在自己账上，凭手感判断它在总库放过半年；刘朝奉知道炉子是从总库掉包来的，但不知沈砚能摸出存放痕迹；两名柜员只看见当场的话和炉底。
- 剧情梗概：刘朝奉逼沈砚签认赔字据平账。沈砚不签，摸出炉底的樟木油压痕，当众问炉子究竟何时进门，护住押银，并敲响封库核账的铜梆。
- 核心冲突与看点：卖点那一拍是拇指刮底足辨出“旧伤盖新锉”，没有它沈砚只能认栽。对手主动一招：刘朝奉不咆哮，先装好人，“替你担二十两”，软刀子逼签。本章回报：押银保住，刘朝奉被迫改口拖延。
- 情节推进节点：前 300 字从算盘拨到尽头、红契和打开的印泥盒切入。刘朝奉软劝按手印。沈砚不碰印泥，托起铜炉刮底足，指腹摸到先窄后宽、带樟木油的旧伤，上面盖着新磨的砂痕。他把炉底翻给两名柜员看，指出这种油印只有在总库三号架压足半年才出得来，问炉子是昨天进门还是在总库睡了半年。刘朝奉眼神一缩，拦人去搬樟木架核对，改口“今日先挂账，明日再议”，想拖到毁迹。主要篇幅：逼签的软硬拉扯和辨伤交锋，约七成。压缩：早课与昨日收货一句带过，但必须保留“交接单只有编号无详图”这条转向依据。
- 章末落点：刘朝奉伸手要收回铜炉，沈砚先抽出柜台下的枣木槌，敲响只有封库核大账才准敲的黄铜梆子，梁上积灰震落。

做对了：卖点直接决定胜负；对手按“明年要接大朝奉、不能闹丑闻”的利害出招，先哄后拖，不降智；压缩处留了依据；章末落在动作和器物上，同时是主角主动挑事的钩子。
