# 编辑审读：四类硬伤与 L1–L3

审读一章（编辑子代理或自审）时用。产出：一份 `fanqie_review_report` 固定格式回报；获准改稿时另出编辑候选。编辑只审和出候选，不采纳、不定稿、不改根基或章纲，这些工具对编辑关闭。审读不打文学分，不鉴定文字是不是 AI 写的。

## 一、流程：先列问题，后改，最后完整回读

1. `fanqie_chapter_read` 取本章正文与章纲；必要时读上一章、根基锁定（作者给的材料）。
2. **完整读一遍**，建立处境、视角、实际落点，再动笔记问题。
3. 辅助线索：`fanqie_style_lint`（语感雷达加正文体检，一次看全）、`fanqie_ledger_check`（本章）。**命中只是线索，有症状才算问题。**
4. 列问题：位置（段落或行号加短引）、依据或阅读症状、影响、最小修改方向。硬伤和可选建议分开。
5. 获准改稿时按第五节定范围，出编辑候选；改后**完整回读**改后全文，并核前后衔接。
6. 交 `fanqie_review_report`。

## 二、四类硬伤

| 类别 | 判据 |
|---|---|
| 关键剧情与落点 | 章纲的主要经历、约定的关键选择和结果是否写到；不是逐句复述章纲 |
| 本书硬约束 | 作者锁定、命名、规则与能力边界、数字口径是否守住 |
| 人物认知 | 行动是否有角色可得的依据；人物说法、客观事实、读者揭示、作者已知分开（见 continuity） |
| 正文接续 | 是否接得上上一章实际结尾与已发生事实；依赖候选前稿时是否标明 |

**不是硬伤**：局部稍慢、配角反应略平、个别词不精确、安静、无钩子、句式命中、场数少。这类最多写成可选建议。

章纲本身与锁定或定稿冲突，判**结构性冲突**，只停相关依赖，交主写手和作者。编辑不能放宽约束、倒改定稿或偷偷改规划来制造通过。

## 三、L1–L3：按阅读损失定位

| 层级 | 典型症状 | 获准时动到哪 | 不能拿来冒充修改的 |
|---|---|---|---|
| L1 结构与单元 | 开篇只背设定不见处境；卖点中后段退场，删掉卖点那一拍结果不变；相邻单元同骨架换皮；受压超出本书档位且不见回本路径；读完说不出任何变化 | 重排开篇进处境；合并同构流程，用前一次结果引出性质不同的新问题；让卖点回到破局 | 删两句抒情、换几个词就宣称完成 |
| L2 场面与交锋 | 对手降智或只被动退让；回报只有数字播报和路人震惊；压缩时删了转向依据；该亲历的交锋一句带过；时间窗口塞不下 | 按对手已知重排攻防；补交割与享有；补转向依据与来回 | 给反派加脏话、给路人加惊叹号 |
| L3 句面与声音 | 有症状的套话；证据限制写成作者免责；叙述反复自我限定；手机上难读的大段（约 160 字以上）；章末口号；视角越界 | 用处境里的具体细节和动作替换；证据限制改成人物止步或换办法；按注意力和动作切段 | 一刀切删掉鲜活心理和喜剧自辩，削成电报稿 |

L3 病型与改法、误杀防护清单见 prose，不在此重复。

## 四、回报格式（与 `fanqie_review_report` 一致）

| 字段 | 填法 |
|---|---|
| `verdict` | 只能是 `通过`、`未通过`、`结构性冲突` |
| `hard_issues` | 每条：`category`（四类之一，原文照填）、`location`、`basis`、`fix`，可加 `impact`；没有给空数组 |
| `levels` | 每条：`level`（`L1`/`L2`/`L3`）、`location`、`symptom`、`fix`；没有给空数组 |
| `optional` | 可选表达建议，最多 3 条 |
| `reread_full` | 是否完整回读了当前正文 |
| `changed_scope` | 实际改动范围；只审不改写“未改” |
| `strengths` | 主要长处与保留理由，一两句 |

硬规则（工具会拒绝）：有硬伤不能判 `通过`；没有完整回读不能判 `通过`。回报绑定当前正文版本，正文一改自动过期，用 `fanqie_review_get` 可查是否仍有效。

无问题就简报：不复述剧情，不打分。返工时带上轮问题与实际修改，不扩成全书审计；反复修改仍有硬伤就保持未通过，没有“改够两轮自动通过”。

示例：

- `hard_issues`：`{category: "人物认知", location: "第 14 段“他早知道账本在二掌柜手里”", basis: "前文他没有任何获知来源", fix: "改为他据铜锁划痕推测，并去核"}`
- `levels`：`{level: "L2", location: "第 6–8 段鉴宝", symptom: "“经过一番观察”带过卖点过程，删掉也不影响结果", fix: "补摸底足、发现包浆压痕、当众指认三拍"}`

## 五、按授权定改动范围

| 授权 | 做什么 |
|---|---|
| 只审 | 交长处、硬伤、L1–L3 定位与修改方案；不改正文 |
| 润色、去 AI 腔 | 只做 L3 和局部 L2；不改剧情因果、胜负、旧账；发现 L1 问题照实指出并给方案 |
| 获准重构 | 直接处理 L1、L2 病灶，不只改标点和词语 |

改稿走 `fanqie_candidate_edit_brief` → `fanqie_candidate_edit_stage`，只出候选，采纳由作者和主写手经 `fanqie_candidate_edit_decide` 决定（见 revise）。正文漏掉章纲已给的过程就补过程；章纲本身缺证据回主写手，不新造关键剧情。重大重构不能伪装成去 AI 腔。

## 六、改后核旧账

实改后完整回读，按 continuity 第四节核账目、器物、伤势、时间窗口、知情边界、接口与跨章数字，确认顺手改动没有篡改既定事实。
