# 创作与质量方法

织章的质量方法服务于本书的实际阅读效果。作者目标、节奏档位和已经成立的讲法优先，工具负责提供材料和可核记录，不把词表或字段数量变成文学裁决。

## 规划与落稿

规划要交代关键经历、人物当场可接触的证据、认知边界和转向依据，让写手知道为什么能这样行动。对白、措辞与微动作仍留给正文创作。

本章可以兑现信息、关系、行动后果，也可以让安静体验成立。不强制每章添加反派、代价、反转、固定场数或钩子。快爽的经验数字不自动约束稳推和慢燃，平台规则需使用当期可核来源。

参考迁移的是机制与成立条件；本书需要重新建立人物所求、能力限制、筹码和事件链。合理回应取决于人物当场已知，不等于每场必须加入敌人。

## 审读与编辑

先完整读正文及必要依据，再定位问题，说明位置、证据、阅读影响和最小修改方向。主要核对：关键经历与落点、本书约束、人物认知来源、正文接续。

| 修改层级 | 关注点 |
| --- | --- |
| L1 结构与单元 | 事件是否成立，推进与结果是否有依据 |
| L2 场面与交锋 | 人物如何行动、回应，关系或信息如何实际变化 |
| L3 句面与声音 | 语言是否准确、自然，是否符合本书讲法 |

依据真实损失选择层级。只获准润色时不偷改路线；获准重构时处理因果和场面，不只替换词语。改后完整回读，并复核原有约束和接续。

直接心理、长句、市井口气、热烈反应、必要说明和完整收束都可能有效。机械命中提示回看，默认不硬拒；显式 strict 策略属于用户选择。

## 证据能证明到哪里

| 工程证据 | 可以证明 | 不能证明 |
| --- | --- | --- |
| 引文命中 | 指定材料中有这些字句 | 解释正确、技法有效、读者喜欢 |
| 阅读申报 | 调用方声明读到的范围和程度 | 真实阅读已被独立核验 |
| 扫描凭据 | 对指定版本执行过机械检测 | 内容审读通过或有文学价值 |
| 审读记录 | 指定主体对版本和依据作过结论声明 | 作者授权、市场效果或无遗漏 |
| 覆盖和完整度 | 已处理材料及字段范围 | 分析正确率 |

插件不自动投稿或修改 AI 标识，不把教学例稿当作市场证据。操作上的审读、采纳和定稿见[作品生命周期](COGNITION.md)，具体编辑约定见[作品编辑与修订](skills/web-novel-master-optimizer.md)。
