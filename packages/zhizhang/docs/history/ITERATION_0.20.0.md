# 0.20.0 迭代记录

日期：2026-10-28。当前为未发布开发构建，代码基于 0.19.0 提交 `3739785`。不将设计报告的计划当作全部已实现。

## 已实现

- 章节 lens 缓存提供内容 revision、完整读记录指纹和更新时间，真实快照触发正文及审读元数据失效。R1 修复并入本分支，未单独发布 0.19.1。
- 本地表达诊断：旧句式信号、相邻重复起句、段内短语重复及句长概况。规则只给可选方向，不判断 AI 来源。完整扫描核对已加载版本，拒绝超限正文。
- React 源位置阅读器：标题、普通段落、引用、分隔线、围栏代码、行内粗体／强调／代码，保留原始 UTF-16 定位。新正文路径不使用 dangerouslySetInnerHTML。
- 分类标注、列表与原文定位，Alt+上下方向键在标记间移动；原文与整段编辑对照，简单撤销／重做，作者可直接保留原表达。
- 编辑缓冲在工作台根状态，切换前确认放弃；正文外部变化不自动重绑。页面关闭只提供浏览器离开提示，不承诺宿主卸载时恢复临时内容。
- 安全暂存修订候选：同一可重入作品锁内核对源正文、目标版本、父候选与上下文；显式传入本次依据，不继承过期简报。段落范围与修改前文本逐字核对。
- 来源与请求去重随候选 JSON、lint、采纳和既有 journal 保留。重复保存返回原候选；保存不直接改现行正文，后续采纳仍走共同规则。
- 独立扫描、暂存和能力 HTTP 路由复用原访问检查；修订请求独立上限 1 MiB，正文上限 400 KiB；超限不继续累计缓冲。

## 全面清理与统一复核

本轮按“文本分析 → 版本捕获 → 阅读标注 → 段落编辑 → 候选暂存 → 既有采纳/恢复”整条链路收敛职责，保留四类测试入口，不引入模型队列或另一套写入协议。

- 分离纯文本诊断和文件服务；规范化源身份、修改字段及顺序，保存去重不受 JSON 属性顺序影响。公开源凭据不再携带内部上下文详情。
- 限量结果按原文顺序保留，同时准确统计全部命中；代码、引用、标题和配对对白排除。规则与重复统计区分来源；重复是回看线索，不是错误判定。
- 对白识别改为一次遍历，合并嵌套范围；大段行内格式改用逐项追加，避免参数展开导致调用栈溢出。
- 扫描与保存集中到工作台 hook，纯编辑函数统一撤销、重做和历史预算。迟到错误按对象隔离；取消刷新保留修改；有未保存修改时，生命周期操作先拒绝再写盘。
- 保存结果不确定时保留原请求并锁定修改，再次请求只核对同一操作。目录中存在不可读候选时，拒绝可能重复的新增请求。
- 删除旧 HTML 字符串渲染器；无标记文本跳过字素切分，正文组件按输入复用渲染；列表、标记定位和无障碍描述绑定所属阅读器，重叠命中保留所有关联问题。
- 章节 lens 缓存同时限制条目和约 8 MiB 文本占用；候选文件与元数据外部改动触发刷新；历史列表取最近 20 条。章节摘要读取实际文件的标题、状态和字数；CRLF 元数据兼容且不统一改写正文内部换行。
- HTTP 路由登记和健康清单复用同一清单；请求容量、超时和中断分别报告，异常读取移除监听并限时关闭剩余流，限流提供 Retry-After。
- README、测试说明、工具参考和文档导航统一指向当前迭代状态，历史设计与附件评估继续保留为依据。

临时浏览器复核使用真实 React 18、Chromium、实际本地接口，覆盖提交成功后丢失响应、同请求重试无重复候选、旧扫描错误隔离、取消刷新保留缓冲、键盘定位和四种宽度，未出现页面脚本错误。使用插件控件回退，未启动实际 DSH。

本机 Node 24 单次纯分析样本：345,600 字节重复叙述约 146 ms；360,000 字节密集命中约 438 ms；390,018 字节未闭合引号约 84 ms，均完整计数、最多保留 120 条。数据是特定 Linux 环境的一次样本，不代表目标桌面、持续负载或渲染性能承诺。
