# 织章（Zhizhang）

织章是装在作者电脑上的本地优先中文写作桌面工作台。规划、起稿、审读、修订、质检等机械劳动交给可暂停、可恢复、费用可控的流水线；采纳、定稿、交稿始终由作者决定。

## 项目状态

- **发布版本**：`1.3.0`；v1.4 尚未发布。
- **当前开发状态**：v1.4 的大纲、设定集、导入、上下文、记账与规划界面已合入 `integration/v1.4`；本地验证通过，尚未发版。
- **验证边界**：当前验证使用离线假模型；真实模型与 Windows 安装升级检查未作为本轮通过项。详见[项目状态](docs/STATUS.md)。

## 核心模式与默认能力

- **番茄长篇**：支持全书规划提案、大纲树（卷 / 幕 / 章纲）编辑与章节绑定、设定库与待确认变更、TXT/MD 资料导入、章节流水线（预检、节拍、多稿起稿、代码闸、初选与换位比较、连续性核对、审读、定向修订、交付候选）、章节记账、十二类一致性检查、拆书入库与全书汇编导出（`.txt` / `.docx`）。
- **今日头条图文**：支持资讯线与故事线两类内容，体裁覆盖长图文、短图文与微头条；登记多个本地来源，依次执行立项卡预检、标题矩阵（覆盖至少 3 个母体、每条 ≤34 字）、蓝图轮换、起稿、代码抽词与证据匹配（事实链）、审读修订、Python 质检（≥84 分且无硬闸）及交稿单生成。
- **写作台通用**：右栏流水线与写作助手分屏协同（助手仅具备只读与发起流水线权限，不可直接改写正文）、右栏快捷切换（`Ctrl+.` 收起/展开，`Ctrl+1/2/3` 切助手/流水线/本章）、历史运行只读详情、编辑草稿落盘与崩溃断点恢复、本地加密密钥存储。

## 作者是裁判

- 任何正文采纳、定稿、设定集增量落盘、个人规则写入与头条交稿确认，均须由作者明确操作或确认。
- 头条交稿单固定以“——AI 到此止步。是否采用、何时发布由你决定。”收尾，工具不替作者发布。

## 安装与数据位置

- **运行环境**：Windows 10/11 x64（安装版 NSIS 或便携版 ZIP）；开发构建需 Node.js ≥24.11.0 与 Python 3.13。
- **应用状态目录**：`~/.zhizhang/`（可通过环境变量 `ZHIZHANG_STATE_ROOT` 覆盖），保存加密后的模型密钥（`safeStorage`）、全局设置（`settings.json`）、会话、诊断日志与流水线运行记录（`runs/`，断点恢复依据）。
- **本地写作文件夹**：由作者在首次引导或设置中选定，结构如下：
  - `.zhizhang/`：跨进程租约锁（`lease.json`）、资源写锁与编辑草稿（`drafts/`）。
  - `长篇/`：番茄长篇作品目录，每部作品包含 `work.json`、`outline/`、`bible/`、`imports/`、`chapters/`、`candidates/`。
  - `头条/`：头条图文文章目录（`meta.json`、`sources/`、`drafts/`、`qa/`、`交稿单.md`）与台账数据。
  - `拆书库/`：拆书入库来源与参考卡片。
