# 参考、规划与写作的交接

三个阶段按最终产物分工，已有充分材料可直接进入所需阶段。

| 阶段 | 输入 | 输出与边界 |
| --- | --- | --- |
| 参考 | 指定材料、问题、来源与范围 | 可复核分析和迁移包；分析不等于入库 |
| 规划 | 作者目标、实际作品与可选参考 | 根基、全书/卷/幕或章纲；不自动写正文 |
| 写作 | 采用章纲、前章实际正文、相关状态与讲法 | 候选和工作稿；审读、定稿另行表达 |

工作区 `analyses/ref-*.json` 保存原文片段、来源哈希、报告、逐字引文与迁移包。`inspire_start(reference_ids=[...])` 可显式使用它们，不要求先入公共库。

正式参考库保留 craft / mind：前者帮助场面写法，后者辅助设计。它们是用途分类；没有 mind 不再阻止材料充分的规划，combo 的数量是建议。

迁移包包含 experience、steps、recreate、discard、failWhen，不凑固定数量。规划把机制变成本书的具体依据，再由简报投影给写手，不把原著事件链直接交写手套用。

章纲复用现有 Outline：视角、篇幅、锁定、知识边界，以及 synopsis、conflict、beats、ending；作者完整章纲可放 synopsis，不重建另一份可分别编辑的权威稿。卷、幕按需要创建。

正文结果只校准受影响未来规划，不自动回灌公共知识库。审读与写手是先后职责，可由同一 Agent 执行，不保证独立审查。
