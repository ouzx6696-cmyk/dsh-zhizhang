## 阅读约定

正文中的简写如 `candidate_stage` 指完整工具名 `zhizhang_candidate_stage`。JSON 示例是工具调用参数，由 DSH Agent 执行，不是终端命令。示例中的作品名、ID 和 revision 应替换为本次工具实际返回的值。

当前操作说明以本目录的使用和维护文档为准。历史档案记录当时状态，可能包含旧命令、旧工具数量、未实施提案或已被替代的规则。版本记录区分 Git 可核实里程碑和仅由旧文档记载的过渡版本，不把提交日期冒充公开发布日期。
