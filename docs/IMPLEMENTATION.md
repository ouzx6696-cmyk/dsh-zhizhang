## 数据与状态保证

- 一个现行章节路径，原始字节历史位于 revisions；历史不参与普通汇编。历史先创建，后续失败可能留下未被采用的副本，它不代表提交成功。
- 新候选带目标基线；旧候选需提供明确的当前 expected_revision，或重新暂存。显式 append 保留合作锁内追加语义，不伪装成整章基线替换。
- ContextBasis 绑定本章、根基、规划及实际前稿版本。条件依赖保存在章与目录中，修订提示沿已记录引用传播；旧作品未知关联不被虚构。
- 旧 happened 作为作者材料保留。continuity 的 working 与 finalized 是有来源的接续索引和原文末尾摘录，不是自动故事事实数据库，不假称覆盖所有旧章。
- 审读记录是主体、结论、正文与依据版本的声明。改变正文或必要依据后旧结论不能用于重新定稿；依赖前章未定稿时可继续存草稿，不能将其冒充定稿依据。
- 已有 final 兼容保留，不补造审读。修订须严格 force，修改后降回草稿；作者只改标题时不无差别要求重审。
- 确认修订影响需要当前版本，既不改正文，也不让旧候选重新有效。待核对是提示，不自动把无关全书变成硬阻塞。
- 字面引文采用逐字核对，模糊归一化只用于诊断。阅读申报保留来源版本；重号不按数字静默合并，需实际位置明确范围。

## 结构、配置与作者界面

存储核心在 work-store，公开 store 是兼容外观，查询在 panel-query。共享原语独立于采纳协议；五类协议复用执行器，源暂存、来源守卫及删除保留专用步骤。旧记录仍由各自白名单解码。

架构护栏检查 100 个 TypeScript 源模块的可解析运行时依赖，未发现循环，且存储不反向依赖 Ports/面板。它不声称验证外部宿主的全部动态行为。

绑定工具携带实例配置，调用内使用 AsyncLocalStorage；相同会话 ID 在不同实例不串作品。最近根是发现入口，面板首次选定项目后沿显式项目继续请求。工具和 HTTP 对根配置采用同一优先级。

面板提供工作稿采纳、当前版本审读声明、定稿及修订确认；正文截断时禁用审读/定稿按钮并要求补读。Host/Origin 与配置令牌覆盖本机及 LAN；令牌只保留浏览器会话。坏候选明确可见，损坏相关视图显示不可读，不假称空库。

## 统一审查与验证

- Linux / Node 24.19.0：`npm run check` 通过，39 项测试全部通过。
- Linux / Node 22.23.4：相同命令通过，39 项全部通过。
- 四个测试文件保持不变，覆盖领域、短业务组合、存储故障/恢复/并发、面板访问与生命周期。增加客户端模块协议装载和正文转义验证，没有另建烟测或长篇端到端脚本。
- 静态审查补齐：简报仅注入相关接续索引、面板索引不携带全书摘录；正式引文逐字匹配；旧阅读来源不冒充新版已读；旧正文/旧章纲兑付记录不满足新候选严格检查；craft-only 推荐的工具回执与服务结果一致；审读拒绝结果不能定稿。
- 临时规模样本：500 章、300 候选，Node 24 冷快照 321ms、后续快照 330ms，JSON 约 131KB。这是当前 Linux 合成样本的观察，不是优化前后比较或性能承诺。
- 缓存增加近似文本字节上限；缓存不用于采纳或恢复完整性判断。未因单次样本引入复杂分页或新框架。
- Markdown 本地链接及 diff 空白检查通过。实际发行包含 228 个文件，独立解包后入口、按需启用与 52 个工具可加载，新增运行时模块齐全；源码与 tracked dist 一起交付。

## 全量梳理与去冗余复核

本次在同一套宏观契约下复查参考、规划、写作、采纳、审读定稿、修订与恢复，以及工具、HTTP、面板和交付说明；以下为复核后实际收敛项：

- 移除未使用的导入、重复工作流常量、空迁移基线及两份过渡检查脚本。`verbatimModuleSyntax`、`noUnusedLocals`、`noUnusedParameters` 交由编译器检查；禁止关闭类型检查并入现有架构扫描，不增加检查流程。
- 库与分析的底层原子写入、路径及时间戳直接复用存储原语；面板 HTML 与 JSON 复用同一接续索引和近期留痕投影。
- 候选列表与逐项读取共用元数据解码，格式合法但字段损坏、非法章节路径及正文缺失均显示不可读；坏记录不再靠默认路径假装正常。
- 新增前章会改变原首章的上下文依据；旧候选和旧审读均拒绝继续应用，原正文保持不变。已增加一个短业务回归用例，并扩充现有损坏资产用例，测试仍是四文件。
- Scheduler、ProductMap、工具 schema/描述、面板、编辑回执和工具文档统一：采纳内置扫描、编辑按真实授权、采纳不等于审读定稿、汇编不改变状态。去除自动追加 happened 的失效回执分支、空 threads 的例行催填和重复续写指令。

旧 journal 解码器、已公开工具名和 Store 外观承担真实兼容职责，继续保留。HTTP、库编排及客户端仍有较大文件；本次不把无独立职责的文件切片当作简化，也不声称已消除所有复杂度。

## 保留边界

真实 DSH 桌面/反向代理与 Windows 文件系统仍需相应环境验收，当前只有 Linux 与客户端模块协议级证据。CI 已配置 Node 22/24，尚未把未推送代码的云端 CI 当成已执行。

资源锁协调合作进程，文件替换不是 compare-and-swap；不宣称隔绝外部恶意竞态或保证断电持久性。路径写入拒绝链接祖先和链接资产，链接作品根需改用明确的真实目录配置。

完整文学质量、市场效果、人物知识语义、跨全书隐含因果仍由作者与实际审读判断。完整故事知识图谱、规划可视化编辑器、自动整书重写、平台投稿与通用外部技能运行时属于方案明确后置的能力。

当前提交/推送状态以 Git 为准；本文件不把本地完成视为 GitHub 已更新。
