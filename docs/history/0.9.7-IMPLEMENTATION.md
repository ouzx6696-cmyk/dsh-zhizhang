## 数据与工作指导

七天写作量由当前章节及 `revisions` 中的既有保存版本只读计算：按保存顺序累加正向字数差，删减不计入“增加”。七天之前的版本作为基数，避免把整篇旧稿重复算成今天新增；日期按客户端本地时区归档。没有新增统计数据库。全书查询才读取历史，章节局部查询不增加这笔开销；读取失败会显示未统计，不能伪造为零。没有结构化依据的人物／伏笔不生成数量或完成率。

后续维护沿这几个入口修改即可：

- 配色、字号和字体：`packages/ui/src/tokens.css`；不要在页面补主题覆盖。
- 通用控件与 Markdown：`packages/ui/src/`；旧写作台按钮通过现有 facade 接入，桌面方法页通过渲染插槽复用 Markdown，保持存量宿主单 React 的加载约定。
- 桌面交互：`apps/desktop/src/renderer/features/`；页面样式分别位于桌面、UI、workbench 的样式目录，入口 CSS 只负责导入。
- 仪表盘数据：`packages/fanqie/src/engine/dashboard-query.ts` 与 `panel-query.ts`；展示位于 `packages/workbench/src/client/fanqie/Dashboard.jsx`。
- 日常视觉调整先开开发预览页，再核对实际写作页。本轮只增加一项有业务意义的统计测试，继续复用现有 GUI，不建立额外测试平台。

## 提交前全量复核

按“桌面页面 → IPC 参数／范围 → 自有 PI 会话与角色 → 工具与存储 → 查询快照 → 页面更新”的链路核对，重点检查模型设置、项目／文章范围、候选与原稿、编辑离开、方法保存、任务停止、样式加载及 Windows 打包入口。保留 PI 原有会话隔离和授权机制，不增加适配内核或测试框架。

本轮复核修正：

- 文章按周分组改用本地日期，旧文章分组排在末尾。
- 手动改独立编辑连接时解除“沿用写手”状态，避免后续写手修改覆盖编辑配置；首次引导的独立编辑连接测试显示实际结果。
- 作者偏好读取失败时展示错误，不再用未读到的空内容覆盖原文件。
- 方法弹窗交由原生 dialog 处理 Escape，移除重复的全局关闭监听。
- 确认框移除“任意 Enter 都确认”的全局拦截，按当前按钮焦点执行；弹窗打开时，全局写作快捷键不再操作底层页面。既有停止场景补充核对 Enter 取消、Esc 取消，再明确点击继续停止，不新增测试场景。
