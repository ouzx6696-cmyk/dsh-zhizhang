# 0.9.4 实施与验收记录

日期：2026-11-02（香港时间）。基线：GitHub master 的 `364f084`，在 0.9.3-rc.1 优化及作者工作台基础上继续实施；没有重新套用已完成的第三方重构。

## 本轮修改

- 正文编辑固定开始时的正文、章节/候选、项目及版本，后台刷新不重置编辑器，也不将新版本号套在旧作者文本上。
- 共享源码编辑器接入已有离开决策：章节/文章/视图切换、关闭与保存中状态保护草稿；保存中 Escape 不再关闭编辑器；取消选择目录不预先丢弃草稿。
- 定稿正文保存需要明确确认，后端只接受实际传入的 force=true；普通保存不能隐式绕过定稿保护。
- 头条作者稿以已读版本和正文哈希作条件保存，比较在既有元数据串行临界区内完成。写入成功而台账同步失败时，如实报告正文已保存及台账警告，避免误导作者重复保存。
- 历史分页按可见消息计数，隐藏节点不占页额；保留总数、顺序和 PI entry 身份。
- 保存调用的适配器参数与返回结构明确类型；任务焦点逐字段校验。作品切换在后端接受后再提交前端目标，旧异步响应由请求代际丢弃。
- 仅前端构建使用的字体、图标、React/Markdown 依赖改为开发依赖；编译后的界面资源、字体及许可证保留。新增一个交付客户端启动检查，用真实 Windows 可执行文件核对版本与 preload。
- 本轮不改模型供应商、方法方案、质检阈值和存储格式，不引入新状态框架、后台进程或测试平台。

## 验证口径

复用已有用例：源码编辑场景增加离开拒绝和后台写入冲突；稿件版本场景增加旧依据拒绝；既有 HTTP 定稿场景增加修订授权检查；PI 会话场景增加隐藏节点分页检查。不为每个改动新建测试文件或扩充界面矩阵。

上一发行包 app.asar 中仅 @fontsource 与 lucide-react 源码合计约 187 MB；这不是整体安装包压缩收益。新产物体积和交付依赖需以实际构建文件比较，不预报百分比。

提交前结果：核心 Node 97/97、Python 标准库规则 215 项、桌面会话 9/9、GUI 6/6、桌面严格类型及构建通过，架构守卫通过（238 个源码文件，无内嵌提示词）。ESLint 无错误，保留既有 17 项 Hook 警告；不将其宣称为零告警。
