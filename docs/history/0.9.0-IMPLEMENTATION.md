## 本版实现

- Electron Main + Renderer，新增独立桌面入口，复用 React 写作台；桌面通过 IPC 调用同一操作上下文，不启动 HTTP 服务。
- Pi SDK 1.4.0 主会话、持久化及恢复、顺序工具、跟随消息、停止与编辑任务；沿用既有两种模式的工具、规则与方法方案。
- 桌面执行上下文显式提供会话与目录，长篇保留 withPluginConfig / withPortConfig 包装。
- 作者确认使用现有门禁；页面采用、采纳、定稿结果传回对应会话。取消和停止不表示撤销已经完成的保存。
- 显式同步项目与会话目标；新建首本书延续原对话，查看历史无需准备模型。项目登记与自定义作品目录在页面和工具间统一。
- 作者确认使用可随任务取消的原生对话框；发送、编辑失败与保存后通知分别返回实际结果。
- 模型设置、原有业务可选配置、用户方法方案目录、旧数据根登记、链接文本读取与已有热榜。
- 公共运行资产准备、随包 Windows CPython，保留 DSH 插件构建。

## 试用

解压 `WriterAgent-0.9.0-win-x64.zip`，运行 `WriterAgent.exe`。先选择创作数据目录，再在“模型设置”填写 OpenAI 兼容连接。长篇选择包含 works 的数据根，或新建空目录；头条选择文章目录。

打开“对话”发送创作要求；“恢复会话”读取对应历史。“方法目录”可切换到已有用户方案根目录。无需安装 DSH、Node 或系统 Python。

开发与打包命令、可选 writer.json 配置及数据位置见 DESKTOP.md。源码与构建产物均为本次实现的预览版本，不附带正式 Release 或运行验证声明。
