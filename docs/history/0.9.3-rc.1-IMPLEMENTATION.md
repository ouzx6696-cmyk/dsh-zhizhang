# 0.9.3-rc.1 候选构建说明

本候选版汇总内置 PI 写作流程加固与本轮效率重构，不是已完成全部验收的稳定版本。

主要变化：作者确认与版本约束、头条台账幂等与并发保护、角色能力收敛、历史身份与缓存、有限恢复入口；子任务取消交接及规划保存回执；显式目标选择和段落保存；共享进程内队列、移除部分测试专用出口、精简重复验证和构建。

实现与验证细节见 [0.9.3 实施记录](0.9.3-IMPLEMENTATION.md)及[效率重构记录](NEXT-ITERATION-IMPLEMENTATION.md)。发行包同时附带这些记录，避免离线阅读只有无法打开的链接。

已取得的本地证据：Python 215 个检查点、Node 94 项、桌面核心 7 项、Linux GUI 3 项，以及既有 DSH 集成和两条 headless 流程通过。提交前检查与远端构建以本候选提交的实际日志为准。

已知限制：桌面 JSX 已纳入独立 JS 检查，TS/TSX 保持 strict 检查；并不宣称所有动态业务数据已经全量严格类型化。真实模型 E 集、作者评分及 Windows 实机安装/更新尚未完成。构建成功不等于这些验收通过。

构建目标：Windows x64 NSIS 安装器、免安装 ZIP、兼容包和源码 ZIP，附 SHA-256 与实际签名状态；使用候选版本标识；GitHub provider 的清单文件名为 latest.yml，版本及实际 Release 属性决定候选状态。仅生成和核验构建产物，不自动发布 GitHub Release，不更新稳定版本下载。
