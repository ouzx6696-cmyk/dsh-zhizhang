## 阶段 2：设计系统

- 新增 `packages/ui`：设计变量、字体变量、间距 4/8/12/16/24/32、圆角 6/10/14、两级阴影、语义色和状态映射。
- DSH 从 `--dsw-*` 取色与字体；桌面把同一组别名映射到自己的亮暗调色板。
- 状态标签统一为草稿 / 待审 / 已审 / 定稿；头条为待写 / 待验收 / 已验收 / 待交稿，颜色固定。
- 基础组件：按钮、状态标签、卡片、标签页、提示栈。
- 组件与样式不再写死字体名或颜色；`styles.css` 与 `desktop.css` 的 `!important` 从 18 处降为 0。

## 阶段 3：页面

- 顶栏：三个导出按钮合并为「导出」下拉（复制、TXT、Word）。
- 左栏：只列章节；候选改为数字角标，点角标进入候选，去掉重复的「候选与回报」分组。
- 正文：状态、四步进度（当前高亮）、版本/保存时间与作者决定在标题行；表达诊断移入「本章」；稿纸随内容增高，移除中栏嵌套滚动。
- Agent 栏：任务标题两行、停止按钮改为文字；有结果卡时不再重复动作条；不再显示工具原始输出、内部 ID、`kind=`/`key=`；候选显示字数与时间。
- 方法方案：从 390px 右栏移到全屏三栏页；右栏只保留当前方案与打开入口，未保存草稿在关闭后保留。
- 设置：左侧分区导航；模型三个角色改为标签页；上下文窗口、最大输出和思考设置收进「高级」。
- 今日头条：同一外壳；标题行显示 S1–S7 进度、质检分与采用/打回。

## 阶段 4：测试与文档

- 界面测试新增：运行时字体检查（界面/正文/等宽三组变量）、文案扫描（`cand-`、`drafted`、`kind=`、`key=`、`ledger`）、头条流程、截图快照对比。
- 新增状态映射单元测试；Node 从 94 项增至 96 项。

- 版本号统一由守卫核对：根 `package.json`、桌面包、bundle 包、`core/version.ts`、CHANGELOG 首条。
- 迭代报告归档到 `docs/history/`，使用说明移到 `docs/guides/`；docs 根目录保留 6 份文档，全部本地 Markdown 链接可解析。

## 已知遗留

- 真实模型文学质量（E 集）、Windows 实机安装/更新与签名仍未验收；本轮结果不能替代发版验收。
