只使用本地假模型、Python/Node 业务回归、PI 运行时、完整 GUI 旅程和 Windows 原生构建检查。已删除外部 API 验收脚本、人工评分/盲评工具及相关工作流，不再把它们作为发布条件。详见[自动化验收](ACCEPTANCE.md)。

本地 `test:all` 已通过：Node 211 项通过、1 项 Windows 专属跳过，PI 62 项、GUI 完整旅程 1 项通过，Python 与静态检查通过。

每次推送后检查对应提交的 CI；失败须修复后重跑。测试包使用预发布版本，正式版与测试包分别管理。

## 当前改动

- 模型工具面按连续性和多稿开关隐藏不可用操作；内部业务接口仍保留明确的关闭错误，防止绕过模型层直接调用。
- PI 请求使用系统 HTTP(S) 代理并尊重 NO_PROXY；依赖显式声明，使用本地代理与假模型回归验证。
- 软件验收不需要外部 API 凭据，不读取验收 Key。
