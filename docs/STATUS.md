# 当前版本

0.7.0 提供一个写作入口、今日头条和番茄长篇两种模式，以及共用的 DSH 写作台。头条模式管理文章与交稿，长篇模式管理作品、章节、候选、参考与审读；两种模式都通过 DSH 会话完成模型调用。

## 验证方式

`npm test` 检查架构、Python 规则、业务工具和长篇引擎；`npm run pack` 生成安装包。DSH 组件及模拟模型的宿主检查见 [DSH 接口](DSH.md)。版本发布信息见 [0.7.0 说明](releases/0.7.0.md)。

真实模型的写作表现和目标桌面环境中的操作，仍需结合使用的模型、配置与作品自行验收。

## 使用边界

- 一个会话对应一种写作模式；切换模式时新建会话。
- 写作台按钮向最近使用该数据目录的主会话发送消息；同一数据目录有多个主会话时，以最近使用的会话为目标。
- 采纳和定稿由作者决定。无审批通道的宿主不能代替作者完成需要确认的操作。
- 本地表达扫描提供供回看的规则命中，不判断文本是否由 AI 写成。
