# 当前状态

最近正式版为 [0.9.9](https://github.com/ouzx6696-cmyk/dsh-zhizhang/releases/tag/v0.9.9)，测试版为 [1.0.0-preview.1](https://github.com/ouzx6696-cmyk/dsh-zhizhang/releases/tag/v1.0.0-preview.1)。本次源码版本为 `1.1.0-preview.3`（追读工程预览版），新增能力与范围见 CHANGELOG。下面的 1.0.1 验证记录属于历史基线，本次发布的实际验证结果以对应提交和 CI 为准。逐项变化见 [CHANGELOG](../CHANGELOG.md)。

## 已具备的能力

- 写作流水线：默认启用调度，可在设置中切回自由写作。番茄有规划、章节（多稿、交换位置比较、硬伤审读、定向修订）与定稿记账链；头条有卡片、标题、起稿、事实链与真实 Python 质检链。每个阶段记录输出、重试、耗时、用量与可用费用，可暂停、恢复、从失败处重试；交付结果等待作者采用。
- 上下文：阶段模型不带工具与聊天历史，按预算组装本阶段材料；方法阶段卡复用方法原文并校验源哈希、节编号覆盖和字数，缓存不含作品数据。
- 连续性与个人规则：分类看板、冲突确认、定稿自动记账（排队不抢占）、十章长线巡检与节奏曲线；个人规则显示候选与前后例子，作者确认后才生效。
- 数据保护：编辑离开确认、按作品与槽位保存的草稿及旧稿冲突检测、遗留锁恢复与作品锁接管、可恢复指针保护、读取期间替换文件的缓存保护、交稿单与质检结果绑定稿件版本和哈希。
- 运行时：Electron 45.2.3、Node 24.11、随包 Python 3.13（开发需 3.10+）；生产窗口启用 CSP 与沙箱，打包启用 Fuses（关闭 NODE_OPTIONS 与命令行 inspect、只从 app.asar 加载，保留备份脚本所需的 RunAsNode）。
- 界面：大窗口默认“自适应铺开”，左右栏与稿纸行宽随窗口变宽、字号不变；可在“设置 › 外观 › 大窗口布局”改为等比放大或关闭。

业务规则保持不变：标题 ≤34 字、质检 ≥84 分过线、编辑两轮打回、固定末句与状态词；头条评分规则版本 4.0.0；本次只统一默认 edit 方法对“锁定剧情与未锁定章纲偏离”的审读口径。

## 实现边界

模型读者比较属于写作辅助，不是发布评分门槛；同模型评审明确提示参考性质。来源检查保证引用落在已提供的原文中，不声称自动证明每个语义判断。方法编号检查不证明语义压缩无损。输入预算与断点保护已实现；通用第三方服务没有统一余额和价格接口，未知费用如实显示未知。

段落级多稿合并、第二厂商评审、空闲时段调度及平台数据自动导入不在本版范围；手动台账录入保留。没有做真实模型性能对照，不公布 token 节省或成稿质量提升百分比；CHANGELOG 中的测量均为本地数据。
