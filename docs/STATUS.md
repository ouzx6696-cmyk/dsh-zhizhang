# 当前状态

最近正式版为 [0.9.9](https://github.com/ouzx6696-cmyk/dsh-zhizhang/releases/tag/v0.9.9)。源码版本保留 `1.0.0-preview.1`；目前处于 1.0.1 稳定性补丁开发阶段，已具备阶段式写作、上下文预算、方法阶段卡、章节与文章流水线、连续性及个人规则界面，不创建发行版或标签。

## 本轮实现

- 默认启用流水线调度，设置中可切回自由写作。模型阶段没有工具与历史，完整作者章纲优先，交付结果等待作者采用。
- 所有阶段记录输出、重试、耗时、用量与可用费用；取消与预算暂停保留已完成阶段。任务历史可查看，作者改动阻止旧稿覆盖，交付中断恢复不重复保存。
- 方法原文保持不动，生成卡片复用同一来源并校验源哈希、节编号覆盖和字数。章节差异化多稿、交换位置比较与硬伤审读分开；文章调用现有真实 Python 质检，不降低门槛。
- 连续性分类看板、冲突确认、定稿自动记账、十章长线巡检和节奏曲线；旧内容备份迁移。个人规则显示候选、修改前后例子、确认采用、已生效规则与十章复核进度。
- 设置开关可见且保存才生效；整理抽卡、交接、学习模块职责及弹窗样式归属，启用稿纸容器布局。

## 验证与推送

软件验收只用本地假模型、Python/Node 业务回归、PI 运行时和完整 GUI 旅程。本轮没有调用真实模型 API；真实模型经济档验收仍待预算授权，不以假模型结果替代。新增两条完整流水线场景，覆盖生产调度、规划采用、候选交付、结构错误重试、取消恢复、作者版本保护和文章实际质检；GUI 扩入设置取消与流水线界面。

本轮最终检查通过：Python 224 项质检、14 项长篇桥接、2 项编码/兼容性回归；Node 350 项（349 通过、1 项 Windows 专属跳过）；PI 与流水线 116 项；完整 GUI 旅程 1 项。类型、lint、格式、导出、资产和架构检查通过，any 基线为 1、非空断言和吞错均为 0。article.ts、service.ts 的文件规模有两条非阻断提示，纯拆分重构留待 1.0.2。

本次推送前审查另外修复文件读取期间的替换竞态与 JSONL 嵌套缓存污染，补充生产缓存路径回归。读缓存只用于轮询，采纳与恢复继续使用未缓存原始字节校验。

推送后核对对应提交的 CI；Windows 平台专属检查以该提交的原生 CI 结果为准，不据 Linux 本地结果宣称 Windows 已通过。未创建发行版。

## 1.0.1 优化状态

- 数据保护：编辑离开确认、稳定草稿键与旧稿冲突检测、遗留锁恢复及作品锁接管、可恢复指针保护和自动记账排队。
- 调度与缓存：结构化停止原因、流式停滞检查、重试计费用量、暂停后停止派发；阶段卡隔离作品数据，上下文线性计数，进度事件合并且拒绝旧快照覆盖。
- 头条流程：驱动和标题预检对齐规则源、终稿事实链、损坏历史可见跳过、失败采用回滚、字符集与实体解码。业务阈值及规则版本 4.0.0 保持不变。
- 长书规模：校验后才生成定稿快照，接续索引按需取章尾，候选解析缓存保留逐文件失效和作者修改保护。快照不自动清理。
- 本地测量：章编排事件从 37 条/310252 字节降至 4 条/37456 字节；上下文计数的 300 个混合预算案例与旧实现等价。具体测量见 CHANGELOG，不代表真实模型费用或质量提升。

尚未完成的发布条件：T126 的 Electron 42 升级及类型对齐需明确授权；T134 规则调整需单独授权；真实模型验收需预算批准；Windows 真机安装、升级、卸载、备份恢复及关窗操作仍须执行。当前没有创建 1.0.1 标签或发行包。

## 实现边界

模型读者比较属于写作辅助，不是发布评分门槛；同模型评审明确提示参考性质。来源检查保证引用落在已提供的原文中，不声称自动证明每个语义判断。方法编号检查不证明语义压缩无损。输入预算与断点保护已实现；通用第三方服务没有统一余额和价格接口，未知费用如实显示未知。

段落级多稿合并、第二厂商评审、空闲时段调度及平台数据自动导入不列入本轮流水线交付；原有手动台账数据录入保留。没有执行真实模型性能对照，不公布 token 节省或成稿质量提升百分比。
