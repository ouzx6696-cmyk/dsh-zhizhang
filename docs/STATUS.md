# 当前状态

源码版本：0.9.9-rc.1（RC1 候选，未发布）。更新日期：2026-11-06（香港时间）。最近正式版仍为 [v0.9.8](https://github.com/ouzx6696-cmyk/dsh-zhizhang/releases/tag/v0.9.8)，其标签与附件保持不变。

RC1 以 0.9.9 为基线，吸收可独立验证的改动完成前后端性能、组件结构与样式体系梳理：`atomicWrite` 复用父目录安全校验结果避免重复祖先链 `lstat`；`readJsonlCached` 缓存解析后的 JSONL 行对象，调用方按只读契约使用；长篇面板快照、拆书库、灵感候选与会话、章节版本统计、项目与作品扫描、头条文章列举、方法方案加载和桌面项目列表全面改为受控并发 I/O，路由匹配改用 `Set` 查找。前端 `Markdown` 与 `AgentMessageList` 接入 `React.memo`，`AgentPanel` 缓存候选编号与快捷动作，`SourceEditor` 字数统计消除临时数组分配，顶栏项目切换菜单补齐点击外部与 `Escape` 关闭。超长组件与样式表按职责拆分，此前缺失的拆分文件按 0.9.9 云端实现重建并全量核对；`any` 基线从 128 下调至 99，架构守卫 0 失败、余 3 条超行提示。

0.9.9 已接入自带 Key 的 Exa 轻量搜索及预算，保留旧 Tavily 配置；新增连接测试和搜索费用诊断。Agent 面板显示当前上下文、最近请求、当前任务（含委派）和主会话累计用量，并显示实际读取的方法方案／ID／哈希。

自动压缩默认开启，按 80% 目标及输出预留计算阈值，可设置有效预算和近期保留量。新增互斥的手动压缩、保留重点与取消，沿用 PI 的压缩条目和原始历史。修复作者素材 URL 阻断、原版方法短 ID、文章投递前置检查、输出截断状态和任务结束同步；应用根容器跟随窗口尺寸。

本轮已验证：Python 218 项、Node 131 项（Windows 本地 129 过，`T3-12` 平台断言与 UTC 跨零点目录命名两项为基线既有失败）、PI 运行时 27 项、Electron GUI 完整旅程 1 条（9 个步骤）；类型检查（packages 与桌面端均 0 错误）、桌面构建、lint、严格守卫和导出审计通过。测试使用模拟服务，未调用真实模型或 Exa 付费 API。

待验收：真实模型的事实、字数、局部修改范围与请求效率；真实 Exa lite 可用性、中文资料效果及费用；Windows 原生最大化／全屏、显示缩放、安装和跨版本自动更新。Linux 的原生窗口 setBounds 已验证；Windows 专属窗口分支尚未运行。没有证书时构建仍未签名。

素材、字数和修改范围的交接已强化，尚不能以程序证明模型满足所有语义要求；本版没有新增语义评分器，也没有修改方法原文或降低质检门槛。0.9.8 的源码净减目标未达成，历史结论不因本轮功能开发改写。

使用见[桌面说明](guides/DESKTOP.md)，实现见[架构](ARCHITECTURE.md)，变更见[CHANGELOG](../CHANGELOG.md)，真实模型验收见[验收说明](ACCEPTANCE.md)，RC1 评估过程与遗留项见[RC1 报告](RC1-REPORT.md)。

本轮整合：流式输出按帧提交，重复状态不通知订阅者；上下文统计按会话叶节点复用，避免工具回执反复扫描历史；方法列表与壳层共享明确的活动方案字段；内核预览按需裁剪 Unicode，移除内部类型兜底。设置写入成功后再更新内存。

测试入口已收敛：守卫规则合并扫描，桌面场景改为分步骤完整旅程，测试构建批量执行。Node 回归本机约从 12.6 秒降至 6 秒，非跨环境性能保证。桌面只打包 WOFF2，移除 392 份旧 WOFF，字体资源减少约 13.55 MiB。any 基线从 128 下调至 99，未注明原因的吞错仍为 0，架构守卫余 3 条超行提示（`ProfileParts.jsx`、`shell.css`、`layout.css`，属提示而非失败）。
