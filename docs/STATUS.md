# 当前状态

源码版本：0.9.9-rc.1（RC1 候选，未发布）。更新日期：2026-11-06（香港时间）。最近正式版仍为 [v0.9.8](https://github.com/ouzx6696-cmyk/dsh-zhizhang/releases/tag/v0.9.8)，其标签与附件保持不变。

RC1 以 0.9.9 为基线，吸收可独立验证的改动完成前后端性能、组件结构与样式体系梳理：`atomicWrite` 复用父目录安全校验结果避免重复祖先链 `lstat`；`readJsonlCached` 缓存解析后的 JSONL 行对象，调用方按只读契约使用；长篇面板快照、拆书库、灵感候选与会话、章节版本统计、项目与作品扫描、头条文章列举、方法方案加载和桌面项目列表全面改为受控并发 I/O，路由匹配改用 `Set` 查找。前端 `Markdown` 与 `AgentMessageList` 接入 `React.memo`，`AgentPanel` 缓存候选编号与快捷动作，`SourceEditor` 字数统计消除临时数组分配，顶栏项目切换菜单补齐点击外部与 `Escape` 关闭。超长组件与样式表按职责拆分，此前缺失的拆分文件按 0.9.9 云端实现重建并全量核对；优化轮修复 5 项真实缺陷（含 UTC 目录命名、台账并发锁、面板竞态），吞错/边界/竞态按仓库规则收口，死代码净减约 400 行，8 类重复实现收敛到单一来源，非空断言清零、`any` 从 100 降到 1；`any` 基线从 128 下调至 1，架构守卫 0 失败。

随后一轮规则收口：章节 front matter 损坏改报 `bad_chapter`，审校类工具不再把坏稿报成「章节不存在」；拆书报告保留不可读卡片的真实错误；空库返回 `no_work` 领域码供仪表盘给起步指引。删除 no-op catch、死 filter、死参数别名、`errors: "text"` 死分支、恒真分支与重复校验；`PREF.mode`、`polling` 死状态和过时「轮询」注释按实际刷新行为清理。`str()`、对象守卫、本地日期各只保留一处实现，7 处手写 `ENOENT` 判断改走 `isMissingFileError`；错误判定辅助移入浏览器可用的 `core/src/errors.ts`，渲染包不再被 `node:fs` 拖入。全仓接入 Prettier（方法资产与文档除外），`format:check` 进入 `verify`；守卫新增「浏览器可用模块不得引用 fsx」与「格式化后 catch 内注释仍算注明原因」两条规则。

0.9.9 已接入自带 Key 的 Exa 轻量搜索及预算，保留旧 Tavily 配置；新增连接测试和搜索费用诊断。Agent 面板显示当前上下文、最近请求、当前任务（含委派）和主会话累计用量，并显示实际读取的方法方案／ID／哈希。

自动压缩默认开启，按 80% 目标及输出预留计算阈值，可设置有效预算和近期保留量。新增互斥的手动压缩、保留重点与取消，沿用 PI 的压缩条目和原始历史。修复作者素材 URL 阻断、原版方法短 ID、文章投递前置检查、输出截断状态和任务结束同步；应用根容器跟随窗口尺寸。

本轮已验证：Python 218 项、Node 135 项（Windows 本地全绿）、PI 运行时 27 项、Electron GUI 完整旅程 1 条（9 个步骤）；类型检查（packages 与桌面端均 0 错误）、桌面构建、lint、严格守卫、Prettier 格式检查和导出审计通过。`verify` 依次执行类型检查、守卫、格式检查、导出审计、Python 与 Node 测试；守卫新增非空断言计数与 any 全量口径（去注释 `\bany\b`）。测试使用模拟服务，未调用真实模型或 Exa 付费 API。

待验收：真实模型的事实、字数、局部修改范围与请求效率；真实 Exa lite 可用性、中文资料效果及费用；Windows 原生最大化／全屏、显示缩放、安装和跨版本自动更新。Linux 的原生窗口 setBounds 已验证；Windows 专属窗口分支尚未运行。没有证书时构建仍未签名。

素材、字数和修改范围的交接已强化，尚不能以程序证明模型满足所有语义要求；本版没有新增语义评分器，也没有修改方法原文或降低质检门槛。0.9.8 的源码净减目标未达成，历史结论不因本轮功能开发改写。
