## 需要你在桌面版上确认（⚑）
1. 按 INSTALL.md 装 dsh-writer；会话里只看到 `writer_enable`。
2. Windows 上 `py -3` 能被插件找到（找不到就在配置里填 `python`）。
3. 侧栏「写作台」能打开；顶部切换两种模式；今日头条模式能看到文章并"采用"；番茄长篇模式右栏有「写作 Agent」。
4. 在对话里用过一次后，写作台按钮能在对话里出现【写作台】消息并开始干活（headless 没有 webServer 与会话控制服务，只能桌面验证）。
5. 用真模型写 3 篇头条（资讯线 2、故事线 1），开一本新书写到第 5 章，每章走一次编辑审读与定稿确认。

## 已知限制
- 写作台按数据目录记会话，同一目录开多个会话时投到最近用过写作工具的那个。
- 编辑子代理依赖宿主的 `subagent` 工具（桌面/headless 默认都有）；没有时主写手自己做审读。
- 编辑子代理沿用主会话模型；按角色配不同模型要等 writer profile。
- headless/SDK 等没有审批通道的模式下，"已交稿"与定稿一律拒绝（设计如此）。
- 品牌包与发布流程未做。
