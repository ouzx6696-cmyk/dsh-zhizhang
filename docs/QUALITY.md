# 创作与审读方法 · 0.18.0

方法按任务加载，作者目标、本书有效讲法和节奏档位优先。默认简报提供作者人物依据、有效讲法和读者揭示，人物获知仍由章纲与实际前文分别核对。快爽的经验数字不约束稳推或慢燃，平台政策不从章长或题材推断。

## 规划与落稿

规划给足关键经历、可接触证据、人物认知与转向依据；对白、措辞和微动作留给写手。本章实际读者体验应当成立，可体现信息、关系、行动后果或安静体验；不强制反派、代价、反转、固定场数和章末钩子。

参考卡迁移机制与条件，重造本书人物欲望、能力限制、对手筹码与事件链。人物的合理回应取决于当场已知，不等于作者必须给每场添加敌人。

## 审读与编辑

先完整读，再列位置、依据、影响及最小修改方向，按授权改后完整回读。四类核对是：关键经历与落点、本书约束、人物认知、正文接续。

L1 结构与单元、L2 场面与交锋、L3 句面与声音，按真实损失选择修改层级。只获准润色不偷改路线；获准重构就解决因果和场面，不只换词。

直接心理、人物长句、市井口气、热烈群体反应、必要说明和完整收束都可能有效。词表命中是回看提示，默认不作文学硬拒；显式 strict 策略属于用户选择。

## 工程证据

引文命中只证明指定材料中有这些字；正文已读与深读是范围声明。扫描只证明对某版执行了机械检查。审读声明绑定具体正文与依据，不能制造作者授权，不能证明文学或市场效果。

材料完备度是工程指标，不是“分析正确率”。例稿是教学材料，不是市场成功证据。工具不自动投稿或修改 AI 标识。
