# 作者面板 · 0.18.0

默认三栏阅读：章节、正文/候选对照、当前状态与操作。管线视图展示参考库、灵感和写作概况，产文仍由宿主 Agent 完成。

采纳调用共同 Accept 服务，明确确认后写入工作稿。没有提前扫描时会自动扫描；过期扫描凭据不能冒用。旧候选需明确当前目标基线，当前章已加载时面板可随确认传递其 revision。

正文加载完整后可声明已审读、按授权定稿、确认已核对修订影响。正文截断或加载中禁用这些按钮；截断须通过工具补读。审读只是实际用户声明，代码不证明是否真正读过。

状态工具、简报和快照共同显示修订提示。损坏候选以不可读条目保留；不把不可读、待恢复或过期显示成无数据。

HTTP 本机也核对可信 Host，显式 Origin 必须匹配。allowLanPanel 开启后仍须 Host 白名单；配置 panelToken 后本机/LAN 均核令牌。设置卡可输入令牌，只存本次浏览器 sessionStorage；不在 URL 中传令牌。

面板按需读取正文，快照默认不带 HTML。文字缓存有条目与近似字节上限，采纳和恢复使用实际字节。完整可视化规划编辑、真实 DSH 桌面与浏览器验收不在当前自动测试的证明范围。
