# 作者面板

织章在 DSH 侧栏提供「织章」工作台，用来阅读、对照和确认写回。分析、规划和产文仍由会话中的 Agent 完成；面板不调用模型，也不会在单次点击时静默写入。

## 两个视图

| 视图 | 用途 |
| --- | --- |
| 写作台 | 三栏：章节导航、正文阅读、本章状态与操作。默认视图 |
| 全书概况 | 总览、参考库、规划、写作、留痕五个分区，查看整部作品的进度 |

顶部依次是作品标题、项目/作品选择、视图切换、自动刷新开关和刷新按钮；下方标签显示章数、字数、定稿、草稿、待采纳和待核对修订数量，以及最近一次更新时间。

## 写作台

**章节导航**：每章显示状态点、状态、字数和处境摘要；有待采纳候选时显示数量，正文修订后待核对时显示「待核对」。超过 6 章时出现筛选框和「全部 / 有候选 / 需处理」过滤。上下方向键在章节与候选间移动，Home/End 跳到首尾。

**阅读区**：可在「现行正文 / 候选 / 并排对照」之间切换；并排对照左侧是现行正文，右侧是所选候选，面板变窄时自动改为上下排列。字号可用 − / + 调整并按浏览器记住。正文与候选按需读取，手动刷新会重新读取。0.20.0 已补齐实际版本投影，正文和审读元数据变化均触发重读。超过约 400KB 的正文会标明截断，审读与定稿按钮随之禁用。

**本章栏**：

- 章节进度：计划 → 工作稿 → 已审读 → 定稿，并说明当前审读声明是否绑定现行版本。
- 声明已审读：在对话框里选择「通过 / 有阻断问题」并可填写说明，声明绑定当前已加载版本。
- 定稿：只有当前版本有通过的审读声明时可用；服务端还会复核上下文与前章依赖。
- 确认修订影响：只在本章存在待核对修订时出现，只清除提示，不改正文。
- 待采纳候选：显示简报与扫描状态，选择候选后「采纳这份候选」。同章多稿且开启 multiDraft 时可生成统一整理简报。
- 编辑稿指引、故事状态和下一步提示折叠显示，按需展开。

## 写回都要确认

| 操作 | 实际效果 |
| --- | --- |
| 阅读、切换候选、并排对照 | 只读，不改变章节 |
| 采纳 | 对话框中勾选确认后，调用与工具相同的采纳服务，写入工作稿并执行扫描；可选「允许覆盖定稿」「跳过简报检查」 |
| 声明已审读 | 保存当前版本的审读结论与说明 |
| 定稿 | 复核当前通过的审读、上下文和前章依赖后定稿 |
| 确认修订影响 | 清除本章已核对提示 |
| 统一整理 | 只生成供 Agent 使用的简报，不写盘；整理结果仍需暂存和采纳 |

写请求超时也可能已在服务端完成，面板会在失败后重新读取状态与正文，再核对是否仍需重试。确认弹窗绑定打开时的项目、作品及已读版本，切换作品或章节即关闭旧弹窗。旧候选缺基线时，面板随确认传递当前已加载章节的 revision；候选或目标后来变化时仍按共同规则拒绝。损坏候选显示为不可读；库或规划待恢复时显示对应状态，不冒充空数据。代码不能证明作者是否真正读过，按钮和声明不能代替实际阅读。

## 找到当前作品

先选择项目和作品，再选择章节。面板通过工具记录的最近根和项目索引发现数据，选定后不会随轮询静默切到其他根；项目、作品、视图、章节和字号按浏览器记住。找不到工具刚写的作品时，先核对[目录优先级](DATA.md#目录优先级)，不要重复创建。

自动刷新在页面可见时约每 6 秒一次，页面隐藏时约 30 秒一次，连续失败时逐步放慢，打开确认对话框期间暂停。可以在顶部关闭自动刷新，改为手动刷新。

## 访问配置

面板接口验证可信 Host 和显式 Origin。默认只允许本机连接；`allowLanPanel=true` 后，非本机请求还须符合 `panelHosts` 或本机网卡地址名单。接口地址按 DSH 应用基址（`document.baseURI`）解析，与宿主自带功能一致。

配置 `panelToken` 后，本机与 LAN 均须提供令牌。在插件详情页的「织章」卡片输入，令牌只存于浏览器当前会话的 sessionStorage，以请求头发送，不放进 URL。

Host/Origin、令牌和限流是不同检查。遇到 403、429 或代理问题按[排错说明](TROUBLESHOOTING.md)处理。真实 DSH 桌面和反向代理的兼容性仍需在实际环境验证。

## 与宿主界面的一致性

控件优先使用宿主 `@deepseek-ai/dsh-client-ui-primitives` 中的 Button、SegmentedControl、Tag、StateDot、Checkbox 和 Modal；宿主未提供控件时使用插件内实现；渲染错误统一由页面错误边界报告。样式只使用 DSH 主题的 `--dsw-*` 语义变量，明暗主题由宿主决定，布局随面板宽度（容器查询）而不是窗口宽度变化。样式表带 `data-plugin="dsh-zhizhang"` 标记，停用插件时由宿主回收。

## 0.20.0 表达诊断

阅读区提供本地「扫描表达」。现行正文与已加载候选可分别扫描，叙述普通段落中的命中按类别标注，排除标题、引用、代码与配对对白；重复与节奏统计单独说明，点击列表可定位原文；标注聚焦后 Alt+上下方向键移动。规则命中仅作可选建议，不判断作者来源。

选择整段编辑，左右对照原文与修改，支持简单撤销／重做。保存生成修订候选，成功后沿用既有采纳。切换前询问未保存修改；外部变稿或依据变化时保存拒绝，缓冲仍保留。网络结果不确定时保留同一请求标识及完整修改，暂时锁定编辑，用「核对并重试保存」对账已完成操作，避免重复暂存。旧扫描响应只更新原对象；放弃刷新时不会清空编辑。页面彻底关闭、插件卸载的未保存缓冲不能保证恢复。

深度扫描尚未开放，无模型调用或隐式会话消息。当前浏览器演示和实际 DSH 验收状态见 [开发状态](STATUS.md)。
