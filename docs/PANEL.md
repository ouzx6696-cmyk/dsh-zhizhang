# 作者面板

织章在 DSH 侧栏提供阅读工作台。默认三栏分别承载章节、正文/候选阅读，以及当前状态和操作；管线视图用于查看参考库、规划与写作概况。分析、规划和产文仍由会话中的 Agent 完成。

## 找到当前作品

先选择项目和作品，再选择章节。面板通过工具记录的最近根和项目索引发现数据，选定项目后不会随下一次轮询静默切到其他根。找不到工具刚写的作品时，先核对[目录优先级](DATA.md#目录优先级)，不要重复创建。

章节正文和候选按需加载，快照主要提供摘要与状态，默认不携带 HTML。超长正文会标明截断，不能将截断结果当成完整审读材料。

## 阅读和操作

| 操作 | 实际效果 |
| --- | --- |
| 阅读正文、选择候选 | 查看当前资产，不改变章节 |
| 对照并采纳候选 | 明确确认后调用共同采纳服务，写入工作稿并执行扫描 |
| 声明审读 | 保存当前已读版本的主体、结论及依据声明 |
| 定稿 | 核当前通过的审读、上下文和前章依赖，按授权定稿 |
| 确认修订影响 | 清除本章已核对提示，不改正文或复活旧依据 |
| 请求统一整理 | 获取供 Agent 使用的简报；整理结果仍需暂存和采纳 |

正文加载中或已截断时，审读/定稿按钮禁用；需要通过工具补读完整材料。代码不能证明作者是否真正读过，按钮和声明不能代替实际阅读。

旧候选缺基线时，面板可随确认传递当前已加载章节的 revision。若候选或目标后来变化，仍按共同规则拒绝。损坏候选会显示不可读；库或规划待恢复时显示相应状态，不冒充空数据。

## 访问配置

面板 API 验证可信 Host 和显式 Origin。默认只允许本机连接；`allowLanPanel=true` 后，非本机请求还须符合 `panelHosts` 或本机网卡地址名单。

配置 `panelToken` 后，本机与 LAN 均须提供令牌。在织章设置卡输入后，仅存浏览器当前 sessionStorage；请求使用请求头，不将令牌放入 URL。

Host/Origin、令牌和限流是不同检查。遇到 403、429 或代理问题按[排错说明](TROUBLESHOOTING.md)处理。真实 DSH 桌面和反向代理的兼容性仍需在实际环境验证。
