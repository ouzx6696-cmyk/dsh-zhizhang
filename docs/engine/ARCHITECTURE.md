# 番茄长篇引擎

全仓依赖与桌面调用链见[架构](../ARCHITECTURE.md)。本页说明 `packages/fanqie/src/engine/` 的持久化边界。

| 模块 | 职责 |
| --- | --- |
| `tools/` | 模型参数解析、业务编排和回执 |
| `runtime-config.ts`、`ports/config.ts` | 调用作用域配置与目录绑定 |
| `domain/` | 内容身份、证据、规划、工作流与文本统计 |
| `services/` | 工具与写作台共用的采纳、上下文及诊断操作 |
| `storage/` | 章节、候选、留痕、合作锁与恢复执行器 |
| `ports/` | 参考库、拆书、规划、方法、编辑和质量策略 |
| `panel-query.ts`、`panel-enrich.ts` | 只读作者视图投影 |
| `../workbench/api.ts` | 写作台命令与作者操作 |

工具和路由调用共同业务服务，写入在作品锁内核对实际资产和来源基线。章节直接保存与候选采纳共用准备逻辑，只维护一份现行正文；先保留原字节历史，再提交现行变更。

`storage/journal.ts` 统一八类多文件意图。各 Spec 声明固定目标、来源和守卫；恢复确认绑定 `{id, fingerprint}`。新章节日志使用 `version: 1` 加 `kind`，仍可解码旧版 1–5。冲突时保留意图与原文件，不扩展为任意路径恢复。具体前提见[业务契约](PORTS.md)与[磁盘格式](DATA.md)。

诊断服务捕获源身份和依据，Python 扫描统一文风规则，TS 组合统计并校验 UTF-16 位置。浏览器仅解析源位置和渲染文本节点。修订复用作品锁与 stage journal，保存后旧证据是否有效由版本判断。

保存请求不能因客户端取消而假定回滚；结果不确定时保留请求及修改，通过同一请求核对。撤销/重做限制步数与字节，不跨作品共享。合作锁不阻止外部编辑，多文件原子性由意图和恢复协议补足。
