# 作品编辑与修订

这是长篇引擎的编辑方法说明。运行时由 `fanqie_method_get ids=edit` 加载同一内容（`packages/fanqie/src/engine/domain/creative-guidance.ts` 的 EDITING_GUIDANCE），数据规则见[数据与恢复](../DATA.md)。

## 开始修改前

完整阅读当前章、必要前文和已采用规划。先明确作者本次授权的目标与范围，再列问题位置、依据、阅读影响和最小修改方向。

核对四件事：关键经历和落点是否成立，本书硬约束是否守住，人物获知是否有来源，正文是否接得上实际前稿。截断材料须补读，未知处保留为未知。

## 选择修改层级

- L1：结构和单元，解决事件及结果成立的问题。
- L2：场面与回应，解决行动、交锋和实际变化的问题。
- L3：句面与声音，解决语言和本书讲法的问题。

只获准润色就不改关键路线，获准重构就处理真实结构病灶。没有问题的内容保留，不按模式强制改字数，不用禁句表删除有用心理、长句、口癖和完整收束。

## 交付与核对

编辑正文先保存为候选，按实际授权决定是否应用。A/B/C 是兼容的采用范围交互，已有明确授权不重复索取固定确认词。采纳内置扫描，已有过期扫描凭据须重扫；扫描、内容审读、作者定稿分别表达。

定稿正文修订须核原稿基线，明确 force 并保留历史；应用后降回草稿。改完完整回读，核原约束及明确依赖的后稿，只保留一个现行正文。不自动重写其他定稿，也不自动回灌公共参考库。
