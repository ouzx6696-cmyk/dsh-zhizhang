# 参考分析与正式拆解

局部问题优先使用 reference_analyze。原文、问题与范围明确后交少量具体做法、逐字短引、必须重造内容和失效边界；不要求建库或先填全部维度。

完整拆书继续支持 import → plan → 分批正文 → facts → structure → card_stage → card_accept → report → combo。Full 须实际确认，用户要求全量时不静默缩成抽样。

目录扫描、正文交付、阅读申报、深读与未读分开。可核事实、人物自述、分析解释与待验证分开；引文命中不证明分析正确或读者效果。

重号按位置区分，事实可提供 sourceStart；有重复章号时不生成会静默合并的数字阅读计划，保留原文并提示按位置明确范围。局部分析不受此限制。心理/评价词仅提示核对，不能误拒原文中明确说过的话。

正式入库仍需已导入的原文与明确入库操作；局部成果不会自动晋级成公共知识。迁移参考可通过 inspire_start(reference_ids) 使用工作区报告，无需先入库。源版本变化后相关证据需重核，未读不当成不存在。
