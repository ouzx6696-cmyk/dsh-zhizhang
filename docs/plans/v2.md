## 2. 已完成演进里程碑

1. **M1（v1.3 收敛）**：清理旧模式与实验开关，统一品牌与 `@zhizhang/*` 包结构，建立 `guard.mjs` 静态守卫。
2. **M2（v2.0 双宿主与核心升级）**：升级 `zhizhang/2.0` 磁盘格式，抽离共享组合根与 Web 本地预览服务器，完成 `toJsonSchema`、`StageRunner` 并发串行化、设定集原子提交与全书规划提案隔离。
3. **M3（v2.1 全链路加固）**：修复 Python UTF-8 分块乱码与锁 `EPERM` 缺陷，实现番茄设定集索引化巡检、严格上下文预算与章节评分并行，完成头条 `.tmp` 隔离与原生卡片校验，加固 Web 预览安全与会话并发。
4. **M4（v2.2 灵感源对齐、柔和纸面 C2 与全仓洁净）**：完整对照五大灵感源梳理前后端架构，落地柔和纸面 C2 三栏工作台、D3 创作内核仪表盘、交互式技法编辑器与 PI 内核深度整合；清理全部死样式与颜色语义泄漏，将全部超 400 行文件拆解归零，`as` 基线收紧至 116，修复 Electron 打包构建并重构 8 份核心文档。

## 3. 下一阶段路线图（v2.3+）

- **Windows 桌面发行闭环**：在 `windows-latest` 上完成 Electron Playwright 全旅程 E2E、`electron-builder` NSIS/ZIP 签名打包与随包 Python 冒烟测试。
- **真实模型质量基准**：获批预算后执行 RM01/RM02 与番茄/头条多档位 A/B 质量对比，校准默认 `stage-map.json` 预算配额。
- **长程创作洞察**：探索番茄卷级伏笔时间轴与人物关系图谱、头条历史回流指标趋势与多方案并排对比。
