## 2. 已完成演进里程碑

1. **M1（v1.3 收敛）**：清理旧模式与实验开关，统一品牌与 `@zhizhang/*` 包结构，建立 `guard.mjs` 静态守卫。
2. **M2（v2.0 双宿主与核心升级）**：升级 `zhizhang/2.0` 磁盘格式，抽离共享组合根与 Web 本地预览服务器，完成 `toJsonSchema`、`StageRunner` 并发串行化、设定集原子提交与全书规划提案隔离。
3. **M3（v2.1 全链路优化与文档体系重构）**：修复 Python UTF-8 分块乱码与锁 `EPERM` 缺陷，实现番茄设定集索引化巡检、严格上下文预算与章节评分并行，完成头条 `.tmp` 隔离与原生卡片校验，全面加固 Web 预览安全、会话并发、运行记录容错与 8 份核心文档。

## 3. 下一阶段路线图（v2.2+）

- **桌面发行闭环**：在 Windows 环境完成 `electron-builder` 打包签名校验、随包 Python 冒烟测试与 Electron Playwright 全旅程 E2E。
- **真实模型质量基准**：获批预算后执行 RM01/RM02 与番茄/头条多档位 A/B 写作质量对比，校准默认 `stage-map.json` 预算配额。
- **增量写作体验**：探索番茄卷级伏笔时间轴可视化、头条历史回流指标趋势图表与多方案快速切换对比。
