## 2. 里程碑与完成度

1. **M1 大清理与品牌统一**：移除自由写手模式、兼容分支、冗余实验开关与 23 份过期文档，全仓统一为 `@zhizhang/*` 与 `zhizhang/1.3`。**（已完成）**
2. **M2 核心地基（`@zhizhang/core`）**：落地 `AppError` 码表、零依赖 `schema`、单一 `defineTool`、`StageRunner` + `TRANSITIONS`、`ModelGateway`、`LockService`、`Intent` 与 `stage-map.ts`。**（已完成）**
3. **M3 写作内核与流水线**：落地 `bible/` 存储与 `asOf(N)`、分层上下文组装器、纯文本起稿、引文逐条容错、段落 diff 学习与头条 `s5-editing` 修订。**（核心已完成；L5/L6、状态冲突巡检、日期/机构抽取等 P1 项在推进中）**
4. **M4 前端、守卫与测试重建**：落地 `--zz-*` 三层令牌、`WorkbenchCommandMap`、`shared/ipc.ts`、`guard.mjs` 静态守卫、`ci.yml` 与行为测试。**（已完成）**
5. **M5 打包与真机/付费评测**：Windows 安装包签名冒烟、`check-desktop-package.mjs`、W1–W20 真机检查与 RM01/RM02 付费复验。**（待宿主环境与预算批准）**
