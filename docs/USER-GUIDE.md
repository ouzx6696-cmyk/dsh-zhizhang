# 织章使用指南（v2.1）

## 1. 两种运行方式

- **Electron 桌面端（主形态）**：本地安装包运行，支持系统原生的文件夹/导出保存对话框、系统密钥库加密存储（`safeStorage`）与离线备份进程。
- **Web 本地预览（`http://localhost:3000`）**：开发或容器预览形态，复用同一套后端引擎与工作区目录，自动在本地初始化示例长篇与头条作品；API Key 在系统密钥库不可用时仅存于当前进程内存，不落明文到磁盘。

## 2. 首次引导与设置

1. 首次打开织章可按三步引导完成配置：**选择写作文件夹** → **连接写手模型** → **创建第一部作品或文章**（也可点击“稍后再说”先浏览工作区）。
2. 在顶栏点击**设置**可随时调整：
   - **模型**：添加多条模型连接（支持 OpenAI 兼容、Anthropic 兼容与本地免密钥服务），为写手、编辑、规划、评审、抽取、助手分别绑定连接与模型，并点击“测试连接”验证连通性（15 秒超时保护）。
   - **写作引擎**：配置单阶段输入预算、单任务总 token 上限、单任务金额上限、全局/单任务并发数，以及助手自动整理上下文阈值与长期写作偏好。
   - **外观**：切换主题（跟随系统 / 晨光 / 夜灯）、稿纸字体（思源宋体 / 系统黑体）、段落样式（首行缩进 / 段间留白）、字号（14–26 px）与行长（30–44 字），支持实时预览。
   - **写作文件夹**：更换目录、查看存储健康（残留锁 / 未完成写入 / 中断任务）与启动离线备份。
   - **关于**：查看版本、导出已去敏的诊断包或恢复默认设置（不影响作品文件）。

## 3. 番茄长篇日常写作

1. **新建长篇与全书规划**：在顶栏选择“新建长篇”，填写书名、一句话梗概与档位（经济 / 标准 / 精品）。在右栏发起“全书规划”流水线生成立项卡、世界观、分卷结构与前序章纲；规划提案保存在独立目录，确认采纳后才原子写入正式规划与设定集。
2. **新建与编辑章节**：在左栏章节列表中新建或切换章节，中栏以沉浸稿纸展示正文；点击编辑进入轻量源码编辑器，未保存修改自动原子暂存至 `.zhizhang/drafts/`，切换作品或意外关闭不会丢稿。
3. **章节流水线与对照采纳**：点击“发起章节流水线”，右栏实时展示各阶段进度、已消耗 token 与费用；可随时**暂停**（保留断点稍后恢复）或**停止**（终止任务）。完成后打开中栏**正式稿与候选稿左右对照**，确认满意后点击“采纳候选稿”。
4. **设定集与定稿**：点击“查看设定集”可按章号浏览人物/状态/伏笔/知情视图、一键巡检连续性，并在待确认队列逐条决定“按新事实更新”或“保留旧事实”。章节审读通过后点击“定稿”锁定终稿。
5. **全书导出**：在顶栏导出菜单选择导出 TXT 或 Word（`.docx`），可仅导出已定稿章节。

## 4. 今日头条图文日常写作

1. **新建文章与登记来源**：在顶栏选择“新建头条”，设定体裁（长图文 / 短图文 / 微头条等）与主驱动；在文章目录登记本地文字来源。
2. **编辑草稿与状态流转**：中栏查看或编辑文章标题与草稿正文；可切换到“台账”视图总览所有头条文章的体裁、质检分与状态，并按流程推进状态（`初稿待改` → `待验收` → `已验收` / `验收退回`）。
3. **文章流水线与质检**：在右栏发起“文章流水线”，自动完成立项卡校验、标题矩阵、蓝图、起稿、事实链核对、审读修订与 Python 质检（≥84 分且零硬闸）。
4. **验收与生成交稿单**：文章通过验收后点击“生成交稿单”，系统以原子写入生成 `delivery.md` 并固定附带“——AI 到此止步。是否采用、何时发布由你决定。”。

## 5. 右栏协同与快捷键

- **分屏与切换**：右栏支持“流水线”、“助手”或“助手 · 流水线”上下分屏，支持拖动或键盘方向键调整宽度。
- **写作助手权限**：助手可并发读取章节、设定集、候选稿、台账与方法原文，并为你发起流水线或打开对照视图，但**无权直接改写正文或设定集**。
- **常用快捷键**：
  - `Ctrl + .` / `F11`：进入或退出专注模式
  - `Ctrl + K`：打开命令面板（快速切章、切换视图或执行常用动作）
  - `Ctrl + S`：在编辑器中保存当前稿件
  - `Enter` / `Shift + Enter`：在助手输入框发送或换行

## 6. 备份、断点恢复与写锁排查

- **离线备份**：在“设置 › 写作文件夹”中指定写作文件夹**外部**的目标目录，独立进程完整复制作品目录并校验；进行中可安全取消。
- **断点恢复**：程序异常退出重启后，未完成的流水线会自动标记为“已暂停（中断）”，可在右栏选择恢复继续，或直接放弃。
- **写锁与只读提示**：若另一个织章实例正在打开同一写作文件夹，当前窗口会自动以只读模式打开避免覆盖；确认另一处已关闭后，可点击顶栏“接管”恢复可写，或在“设置 › 写作文件夹 › 存储健康”中清理残留锁并补写未完成意图。
