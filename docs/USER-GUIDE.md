# 织章使用指南

## 1. 运行方式

- **Electron 桌面端**：本地安装包运行，完全离线加载思源宋体与系统字体（零外链请求），支持原生系统目录/导出对话框、系统密钥库加密存储（`safeStorage`）与独立进程离线备份。
- **Web 本地预览（`http://localhost:3000`）**：复用同一套后端组合根与本地写作文件夹，首次启动自动初始化示例长篇与头条作品；无系统密钥库时 API Key 仅驻留内存，不落明文到磁盘。

## 2. 柔和纸面三栏工作台

织章采用无顶栏、无打断式浮层的三栏布局，聚焦三件事：**稿子长什么样、哪里变了、现在该我拍板吗**。

- **左栏（240px，平铺于暖灰纸底）**：
  - 顶部为中性色「织章」品牌、晨纸/暗纸主题切换与设置入口；
  - 「番茄长篇 / 今日头条」模式分段控件与全局检索入口（`Ctrl+K` 命令面板）；
  - 当前作品/文章切换卡片（含新建长篇、导入旧书接管、新建头条与导出入口）及字数进度；
  - 章节/文章列表（等宽编号、标题与状态；存在待裁决候选稿时显示赭橙小圆点，当前项以纸色浮起）；
  - 资料区直达「项目工作台」「设定集中心（显示待确认数）」「技法仓库」与「章节看板 / 发稿台账」；
  - 底部提供快捷流水线入口、静默保存时间戳与模型连接状态指示。
- **中栏（稿纸主角区）**：
  - 顶部轻量 `CenterBar` 展示作品/章节面包屑、单稿/对照视图切换、专注模式（`Ctrl+.`）与右栏开关；
  - Studio 顶部内嵌可折叠的 **D3 创作内核仪表盘** 与 **连载存稿缓冲栏**（展示连续可发定稿章数、存稿总字数、按日更折算可撑天数与琥珀色断档缺口提醒）；
  - 稿纸以 17px 衬线体、2.0 行距浮起于暖灰背景之上；存在待裁决候选稿时顶部显示左侧 3px 赭橙竖条的**决策卡**，下方并排展示「当前稿 / 候选稿」。
- **右栏（344px，双静谧浮卡）**：
  - 宽屏默认上下同屏展示**流水线卡**（进度条、预算消耗、当前步骤卡、提醒卡与可折叠历史步骤）与**只读助手卡**；
  - 顶部标签可随时切换「本章 / 设定集」参考卡或折叠右栏。

## 3. 首次引导与设置

1. 首次启动按三步完成配置：**选择写作文件夹** → **连接写手模型** → **进入或新建第一部作品**（也可先浏览示例工作区）。
2. 点击左栏顶部**设置**按钮可随时配置：
   - **模型**：管理 OpenAI 兼容 / Anthropic 兼容 / 本地免密钥连接，查看 PI 内置模型目录与思考档位能力，为写手、编辑、规划、评审、抽取、助手分别绑定模型并测试连接（15 秒超时保护）。
   - **写作引擎**：配置单阶段输入预算、单任务 token 上限、单任务金额上限、全局/单任务并发数、助手上下文自动整理阈值与长期写作偏好。
   - **外观**：切换主题（跟随系统 / 晨纸 / 暗纸）、稿纸字体（思源宋体 / 系统黑体）、段落样式（首行缩进 / 段间留白）、字号（14–26 px）与行长（30–44 字），实时预览。
   - **写作文件夹**：更换目录、检查存储健康（残留锁 / 未完成意图 / 中断任务）与启动离线备份。
   - **关于**：查看版本、导出已去敏诊断包或恢复默认设置（不影响作品文件）。

## 4. 番茄长篇创作流程

1. **拆书与技法仓库**：进入**技法仓库**登记拆书来源并发起拆书流水线；选中任意技法卡即可在交互式编辑器中修订核心机制、三步做法、重造条件、失效边界与防抄袭红线，右侧实时预览 Markdown 结构，并一键绑定到当前作品。
2. **新建长篇与全书规划**：在作品切换菜单选择「新建长篇」，填写书名、梗概与档位（经济 / 标准 / 精品）。在右栏选择「全书规划」生成立项卡、故事根基、卷纲与前序章纲；规划提案隔离存放在 `plan/proposals/`，经作者确认后才原子晋升。
3. **旧书大稿零模型接管**：在「新建作品」弹窗切换至「导入旧书接管」，填入单份 `.txt` 或分章目录路径：
   - 点击「预览切章」提前核对编码（UTF-8 / GB18030）、章节数、字数及首尾标题；
   - 导入状态默认设为 `drafted`（初稿待审），亦可按需选为 `final`；全程零模型调用，原稿按原字节无损归档至 `sources/legacy-import/` 并生成 `import-manifest.json`。
4. **章节写作、半章续写与专项精修**：在右栏统一流程启动器中选择：
   - **写本章**：支持勾选「黄金章」加路起稿、勾选「基于已写前缀继续写」锁定上半章正文无缝续写，或在下拉框中选择前章未定稿候选稿继续衍生分支；
   - **精修本章**：支持完整审改（`revise`）、专项去 AI 腔（`deai`）与轻润色（`polish`），产物全部落入候选稿待对照裁决，专项精修不会冒充完整审读；
   - **本章记账 / 连续性体检**：提取设定增量与跨章冲突，进入设定集待确认队列。
5. **决策卡、逐处采纳与过时分支提醒**：在对照视图中：
   - 顶部**决策卡**汇总改动处数、新增字数（绿）、删除字数（红）与提醒数（琥珀），提供「丢弃 < 部分采纳 < 采纳候选稿（赭橙主按钮）」三级裁决；
   - 并排双稿纸行内高亮红删/绿增并带段落编号，支持逐处勾选「采纳此处 / 保留原文」后局部合并，并支持采纳后撤回；
   - 若上游采纳导致下游衍生分支或同章其他候选失配，系统以琥珀色提醒需复核分支，绝不静默删改草稿。
6. **设定集中心、时间线回查与定稿导出**：在**设定集中心**按章号切片查阅设定、运行连续性巡检、在「时间线回查」按实体名或别名串联全书轨迹并一键跳章、按三分类沉淀提示逐条拍板；章节审读通过后点击「定稿」，并可在作品菜单导出 `.txt` 或 `.docx`。

## 5. 今日头条图文流程

1. **切换模式与新建文章**：在左栏顶部切至「今日头条」，于切换菜单新建文章、选定赛道与体裁，并登记本地文字来源或抓取公开网页正文。
2. **草稿编辑、验收锁与台账总览**：中栏阅读或编辑标题与正文，左栏进入**台账视图**总览全部文章体裁、质检得分与状态。若在「已验收」后修改草稿，状态自动回退为「初稿待改」需重新验收；点击「交稿」进入「已交稿」终态后草稿自动锁定只读。
3. **文章流水线与交稿单**：右栏发起「文章流水线」，自动执行立项卡校验、标题矩阵（≤ 34 字）、蓝图轮换、起稿、原文逐字证据核对、审读修订与 Python 质检（≥ 84 分且零硬闸）；验收确认后生成带固定末句的 `delivery.md` 并同步 `ledger.csv`。

## 6. 只读写作助手与快捷键

- **只读助手边界**：右栏助手卡顶部标注「只读 · 只查阅，不改正文」；助手可并发调用只读工具查阅章节、设定集、实体时间线、候选稿、技法卡与台账，并在回复中附带**原文引用卡**（支持一键定位原文或发起流水线），绝不直接改写正文或设定集。
- **常用快捷键**：
  - `Ctrl + K`：打开全局命令面板（切章、切视图、触发常用动作）
  - `Ctrl + .` / `F11`：进入或退出专注模式
  - `Ctrl + S`：在源码编辑器中保存当前稿件
  - `Enter` / `Shift + Enter`：助手输入框发送或换行

## 7. 备份、断点恢复与写锁排查

- **离线备份**：在「设置 › 写作文件夹」指定写作文件夹**外部**的目标目录，由独立进程完整复制并校验，进行中可随时取消。
- **断点恢复**：异常退出重启后，未完成流水线自动标为「已暂停（中断）」，可在右栏恢复或放弃。
- **写锁与只读保护**：另一实例正占用同一写作文件夹时，当前窗口自动进入只读模式防止覆盖；确认另一处已关闭后，可点击状态条「接管」或在「设置 › 写作文件夹 › 存储健康」清理残留锁并在沙箱保护下回放未完成意图。
