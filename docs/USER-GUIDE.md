# 织章使用指南

- 适用范围：当前工作区包含 v1.4 功能实现；发布版本仍为 `v1.3.0`，v1.4 尚未发布。

## 1. 首次引导与工作区设置

1. 首次启动按全窗口三步引导完成配置：**连接模型**（填写 API 地址与密钥并测试连接）→ **选定本地写作文件夹** → **新建第一部作品**。
2. 未配置写作文件夹时点「稍后再说」，引导会在下次启动时重新出现；配置完成后不再重复打扰。
3. 写作文件夹内自动建立 `.zhizhang/`、`长篇/`、`头条/` 与 `拆书库/`；密钥由系统 `safeStorage` 加密保存在 `~/.zhizhang/`，正文与设定始终留在本地。

## 2. 番茄长篇日常流程

1. **建书与规划**：通过“新建作品”填写书名、梗概、题材、方法方案与档位（经济 / 标准 / 精品）。可发起全书规划流水线，产出立项卡、根基、卷结构与章纲；确认并提交后写入书级规划和 `outline/` 大纲。
2. **编辑大纲**：顶栏进入“大纲·设定”，在“大纲”页新增、编辑、拆分、合并或移动卷 / 幕 / 章纲。章纲可绑定正文；创建正文前选中章纲。移动已写正文前会显示位置变化，确认后才提交。
3. **写章与对照采纳**：在章节栏点“写这一章”启动章节流水线；右栏实时展示阶段进度。候选稿生成后，在中栏打开左右对照视图比较不同候选并采纳。
4. **审读、定稿与记账**：审读正文后触发定稿；自动记账设置为“自动生成待确认记账”时，实体、状态、伏笔、出场与交接增量进入待确认队列。作者可查看证据、编辑决定并提交；每 10 章可运行一次全书检查。
5. **导入资料**：在“大纲·设定 › 导入”选择 TXT 或 Markdown 文件，确认编码预览、调整卷 / 幕 / 章映射后启动抽取。检查来源引文与提案，作者提交后才会写入设定集；失败块可单独重试，已提交批次可从历史撤销。
6. **全书导出**：通过顶栏“导出”菜单将单章或整部作品（可仅含定稿）汇编导出为 `.txt` 或 `.docx`。

“大纲·设定”还提供设定库、待确认、检查和历史页。设定库可按实体、关系或章节位置查看资料；检查页汇总十二类连续性发现；历史页查看并撤销可逆变更。

## 3. 今日头条图文流程

1. **登记来源与立项**：新建文章时选择内容线（资讯线 / 故事线）与体裁（长图文 / 短图文 / 微头条）及主驱动，粘贴原文或绑定本地文件作为来源（工具不会自动抓取网络）。
2. **流水线与质检**：依次完成立项卡预检、标题矩阵（≥5 个、≤34 字、覆盖 ≥3 个母体）、蓝图轮换、起稿、事实链证据核对、`s5-editing` 审读修订与 Python 质检（≥84 分且无硬闸）。
3. **验收与交稿**：在写作台查看事实链标记与质检详情，确认采用后状态转为“已交稿”并生成交稿单（末句固定为“——AI 到此止步。是否采用、何时发布由你决定。”）。发布后可导入平台回流数据查看分档统计。
4. 两轮精修后仍未过 84 分的文章保持“初稿待改”，运行以“待作者处理”结束，回执写明分数与未过项，不会误转为待验收。

## 4. 写作台、助手与快捷键

- **右栏分屏**：右栏可同时停靠流水线面板与写作助手，随时暂停、恢复或单阶段重试；需要作者拍板的任务会在顶部状态胶囊与“等你决定”卡片置顶提示。
- **助手权限边界**：助手仅能读取上下文与发起流水线/命令，不会直接修改正文。
- **草稿与标题**：编辑中的正文与助手输入经 IPC 保存到写作文件夹 `.zhizhang/drafts/`（同一 key 串行、最后一次生效），不再写入 `localStorage`；切换作品、关闭重开后可恢复。编辑态标题在独立输入框修改，保存时与正文首行 front matter 同步。
- **历史运行**：右栏“历史”可点开上一条运行，查看阶段时间线、上下文分区、交付回执与运行级错误；已交付候选稿提供“打开对照”入口。
- **快捷键**：`Ctrl+,` 打开设置；`Ctrl+.` 收起/展开右栏；`Ctrl+1/2/3` 切换右栏的助手、流水线与本章标签（`Cmd` 同效）。对话框打开时不响应。
- **导出**：顶栏“导出”菜单可按格式导出当前作品；番茄支持单章与整部汇编。

## 5. 设置、离线备份与锁故障排查

- **设置页**：模型角色卡（写手、编辑、规划、评审、抽取、助手）、引擎档位与 token/金额上限、写作文件夹、外观（主题、字体、字号、行长实时预览）、快捷键、资源与备份、关于。
- **离线备份**：在设置“资源与备份”中可将写作文件夹打包备份并做哈希校验（由独立进程执行，退出时可安全取消）。
- **中断恢复与写锁排查**：
  - 意外关机或崩溃重启后，未完成任务会标记为“可恢复”，点击恢复即可从断点阶段继续。
  - 若提示“写锁被占用”（`.zhizhang/lease.json` 或 `.zhizhang-lock/`），系统不会按超时自动强清锁；请先确认没有另一个织章实例正在运行，再按界面提示手动确认清理遗留锁。
- **版本与更新**：设置“关于”显示当前版本与诊断信息；自动更新在 v1.3 系列默认关闭（W16 已知问题），升级请使用安装包覆盖安装。
