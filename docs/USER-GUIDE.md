# 织章使用指南

## 1. 首次引导与工作区设置

1. 首次启动按全窗口三步引导完成配置：**连接模型**（填写 API 地址与密钥并测试连接）→ **选定本地写作文件夹** → **新建第一部作品**。
2. 写作文件夹内会自动建立 `.zhizhang/`、`长篇/`、`头条/` 与 `拆书库/` 目录；密钥由系统 `safeStorage` 加密保存在 `~/.zhizhang/`，正文与设定始终留在本地。

## 2. 番茄长篇日常流程

1. **建书与规划**：通过“新建作品”表单填写书名、梗概、题材、方法方案与档位（经济 / 标准 / 精品）。提交后可自动发起全书规划流水线，产出立项卡、根基、卷结构与章纲，确认采用后写入 `plan/` 与设定集（`bible/`）。
2. **写章与对照采纳**：在章节栏点击“写这一章”启动章节流水线。右栏流水线面板会实时展示阶段进度；生成候选稿后，在中栏打开左右对照视图对比不同候选并点击采纳。
3. **审读、定稿与记账**：作者审读正文后触发定稿；系统自动运行记账流水线抽取实体、状态与伏笔增量，进入“全书 › 连续性”的待确认队列，由作者逐条接受、修改或拒绝。每 10 章可运行一次全书体检。
4. **全书导出**：通过命令面板或导出菜单将单章或整部作品（可仅含定稿）汇编导出为 `.txt` 或 `.docx`。

## 3. 今日头条图文流程

1. **登记来源与立项**：新建文章时选择体裁（资讯 / 故事线 / 微头条 / 长图文）与主驱动，粘贴原文或绑定本地文件作为来源（工具不会自动抓取网络）。
2. **流水线与质检**：依次完成立项卡预检、标题矩阵（≥5 个、≤34 字、覆盖 ≥3 个母体）、蓝图轮换、起稿、事实链证据核对、`s5-editing` 审读修订与 Python 质检（≥84 分且无硬闸）。
3. **验收与交稿**：在写作台查看事实链标记与质检详情，确认采用后状态转为“已交稿”并生成交稿单（末句固定为“——AI 到此止步。是否采用、何时发布由你决定。”）。发布后可导入平台回流数据查看分档统计。

## 4. 写作台、助手与快捷键

- **右栏分屏**：右栏可同时停靠流水线面板与写作助手，随时暂停、恢复或单阶段重试；需要作者拍板的任务会在顶部状态胶囊与“等你决定”卡片置顶提示。
- **助手权限边界**：助手仅能读取上下文与发起流水线/命令，不会直接修改你的正文。
- **专注模式与命令面板**：按 `Ctrl+.` 或 `F11` 切换专注模式；按 `Ctrl+K` 打开命令面板，快速跳章、发起流水线或搜索设置项。

## 5. 设置、离线备份与锁故障排查

- **设置页**：包含模型角色卡（写手、编辑、规划、评审、抽取、助手）、引擎档位与 token/金额上限、写作文件夹、外观（主题、字体、字号、行长实时预览）、快捷键、资源与备份、关于。
- **离线备份**：在设置“资源与备份”中可随时将写作文件夹打包备份并做哈希校验（由独立进程执行，退出时可安全取消）。
- **中断恢复与写锁排查**：
  - 意外关机或崩溃重启后，未完成任务会标记为“可恢复”，点击恢复即可从断点阶段继续。
  - 若提示“写锁被占用”（`.zhizhang/lease.json` 或 `.zhizhang-lock/`），系统不会按超时自动强清锁；请先确认没有另一个织章实例正在运行，再按界面提示手动确认清理遗留锁。
