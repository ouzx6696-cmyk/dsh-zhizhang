# 织章使用指南（v2.3）

## 1. 两种运行方式

- **Electron 桌面端（主形态）**：本地安装包运行，完全离线加载思源宋体与系统字体（零外链请求），支持系统原生文件夹与导出对话框、系统密钥库加密存储（`safeStorage`）与独立进程离线备份。
- **Web 本地预览（`http://localhost:3000`）**：开发或容器预览形态，复用同一套后端组合根与本地写作文件夹，首次启动自动初始化示例长篇与头条作品；密钥库不可用时 API Key 仅驻留内存，不落明文到磁盘。

## 2. 柔和纸面 C2 三栏工作台

织章去掉了冗余顶栏与打断式浮层，界面只回答三件事：**稿子长什么样、哪里变了、现在该我拍板吗**。

- **左栏（240px，平铺于暖灰纸底）**：
  - 顶部为中性色「织章」品牌、日夜主题切换（晨纸 `day` / 暗纸 `night`）与设置入口；
  - 「番茄长篇 / 今日头条」分段控件与全局检索入口（`Ctrl+K` 命令面板）；
  - 当前作品/文章切换卡片（含新建长篇 / 导入旧书接管 / 新建头条与导出入口）与字数进度；
  - 章节/文章列表（等宽编号、标题与状态；存在待裁决候选稿时显示赭橙小圆点，当前章节以纸色浮起高亮）；
  - 资料区直达「项目工作台」「设定集中心（显示待确认数）」「技法仓库」与「章节看板」；
  - 底部提供「新章节流水线」次按钮与静默的「已保存到本地 · 时间」及模型连接状态指示。
- **中栏（稿纸主角区）**：
  - 顶部轻量 `CenterBar` 展示作品/章节面包屑、单稿/对照视图切换、专注模式（`Ctrl+.`）与右栏开关；
  - Studio 顶部内嵌可折叠的 **D3 创作内核仪表盘** 与 **连载存稿缓冲栏**（展示连续可发定稿章数、存稿总字数、按日更折算可撑天数及琥珀色断档缺口提醒）；
  - 稿纸以 17px 衬线体、2.0 行距浮起于暖灰背景之上；有待裁决候选稿时顶部出现左侧 3px 赭橙竖条的**决策卡**，下方并排展示「当前稿 / 候选稿」两张稿纸。
- **右栏（344px，双静谧浮卡）**：
  - 宽屏默认上下同屏呈现**流水线卡**（7 段进度条、预算消耗、当前步骤卡、提醒卡与可折叠已完成步骤）与**只读助手卡**（占满剩余高度）；
  - 顶部标签可随时切换「本章 / 设定集」参考卡或折叠右栏。

## 3. 首次引导与设置

1. 首次启动按三步引导完成配置：**选择写作文件夹** → **连接写手模型** → **进入或新建第一部作品**（也可先浏览示例工作区）。
2. 点击左栏顶部**设置**图标可随时调整：
   - **模型**：管理多条 OpenAI 兼容 / Anthropic 兼容 / 本地免密钥连接，查看 PI 内置模型目录与思考档位能力，为写手、编辑、规划、评审、抽取、助手分别绑定模型并测试连接（15 秒超时保护）。
   - **写作引擎**：配置单阶段输入预算、单任务 token 上限、单任务金额上限、全局/单任务并发数、助手上下文自动整理阈值与长期写作偏好。
   - **外观**：切换主题（跟随系统 / 晨纸 / 暗纸）、稿纸字体（思源宋体 / 系统黑体）、段落样式（首行缩进 / 段间留白）、字号（14–26 px）与行长（30–44 字），实时预览。
   - **写作文件夹**：更换目录、检查存储健康（残留锁 / 未完成意图 / 中断任务）与启动离线备份。
   - **关于**：查看版本、导出已去敏诊断包或恢复默认设置（不影响作品文件）。

## 4. 番茄长篇、旧书接管、技法仓库与设定集

1. **拆书与技法仓库**：从左栏进入**技法仓库**，可浏览或新建拆书来源，发起拆书流水线提炼结构化技法卡；选中任意技法卡后可在**交互式技法编辑器**中编辑核心机制、三步做法、重造条件、失效边界与防抄袭红线，右侧实时预览 Markdown 逻辑结构，并一键绑定到当前作品。
2. **新建长篇与全书规划**：在左栏作品切换菜单选择「新建长篇」，填写书名、梗概与档位（经济 / 标准 / 精品）。在右栏发起「全书规划」生成立项卡、世界观、分卷结构与前序章纲；规划提案隔离存放在 `plan/proposals/`，经作者确认后才原子晋升至正式规划与设定集。
3. **旧书大稿零模型接管**：在「新建作品」弹窗切换至「导入旧书接管」，填入单份 `.txt` 稿件或章节目录路径：
   - 点击「预览切章」可提前查看识别出的编码（UTF-8 / GB18030）、章节数、字数及首尾章节标题；
   - 导入状态默认设为 `drafted`（初稿待审），亦可按需选为 `final`；导入全程不调用模型，原文件按原字节无损归档至 `sources/legacy-import/` 并生成 `import-manifest.json`。
4. **章节流水线、半章续写与专项精修**：在右栏 `WorkflowStartForm` 发起任务时支持：
   - **半章断点续写**：勾选「基于已写前缀继续写」，系统锁定当前已写正文前缀，仅续写后续内容；
   - **黄金章与分支承接**：可勾选「黄金章」加路起稿，或在下拉列表中选择前章未定稿候选稿继续衍生分支；
   - **专项去 AI 腔 / 轻润色**：在精修流水线选择 `deai` 或 `polish` 模式，无需手填问题清单即可单轮精修，产物仍落入候选稿（不直接改正文，也不会冒充完整审读）。
5. **决策卡、逐处采纳与过时分支提醒**：完成后在中栏打开**对照视图**：
   - 顶部**决策卡**显示改动处数、新增字数（绿）、删除字数（红）与提醒数（琥珀），提供「丢弃 < 部分采纳 < 采纳候选稿（赭橙主按钮）」三级裁决；
   - 并排双稿纸行内高亮红删/绿增，左边距标圆形编号，支持按段落逐处选择「✓ 采纳此处 / 保留原文」后点击「部分采纳」；采纳后支持一键撤回；
   - 若上游采纳导致下游衍生分支或同章其他候选失配，系统会自动弹出琥珀色提醒，提示哪些下游分支需要复核，绝不静默删改草稿。
6. **设定集中心、跨书时间线回查与定稿导出**：进入**设定集中心**可按章号切片查阅实体、状态、伏笔与知情表，运行连续性巡检，在「时间线回查」页签按实体名/别名串联全书轨迹并一键跳章，在待确认队列按三分类沉淀提示逐条拍板；章节审读通过后点击「定稿」，并可在作品菜单导出 `.txt` 或 `.docx`。

## 5. 今日头条图文写作

1. **切换模式与新建文章**：在左栏顶部切至「今日头条」，于切换菜单「新建头条」选定赛道与体裁，并登记本地文字来源。
2. **草稿编辑、验收绑定与台账总览**：中栏阅读或编辑标题与正文；通过左栏进入**台账视图**总览全部文章体裁、质检得分与状态。若在「已验收」后修改草稿，文章会自动回退为「初稿待改」需重新验收；点击「交稿」进入终态「已交稿」后草稿自动锁定为只读，避免误改已发稿件。
3. **文章流水线与交稿单**：右栏发起「文章流水线」，自动执行立项卡校验、标题矩阵（≤34 字）、蓝图轮换、起稿、原文逐字证据核对、审读修订与 Python 质检（≥84 分且零硬闸）；作者验收确认后生成带固定末句的 `delivery.md` 并同步台账 `ledger.csv`。

## 6. 只读写作助手与快捷键

- **只读助手边界**：右栏助手卡顶部明确标注「只读 · 只查阅，不改正文」；助手可并发调用只读工具查阅章节、设定集、实体时间线、候选稿、技法卡与台账，并在回复中附带**原文引用卡**（支持一键「定位到原文 →」或「发起连续性复查」），但绝不直接改写正文或设定集。
- **常用快捷键**：
  - `Ctrl + K`：打开全局命令面板（切章、切视图、触发常用动作）
  - `Ctrl + .` / `F11`：进入或退出专注模式
  - `Ctrl + S`：在源码编辑器中保存当前稿件
  - `Enter` / `Shift + Enter`：助手输入框发送或换行

## 7. 备份、断点恢复与写锁排查

- **离线备份**：在「设置 › 写作文件夹」指定写作文件夹**外部**的目标目录，由独立进程完整复制并校验，进行中可随时取消。
- **断点恢复**：异常退出重启后，未完成流水线自动标为「已暂停（中断）」，可在右栏恢复或放弃。
- **写锁与只读保护**：若另一实例正占用同一写作文件夹，当前窗口会自动进入只读模式防止覆盖；确认另一处已关闭后，可点击状态条「接管」或在「设置 › 写作文件夹 › 存储健康」清理残留锁并在沙箱保护下补写未完成意图。
