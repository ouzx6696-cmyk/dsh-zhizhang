# 番茄小说与工作台

`fanqie_enable` 在当前 DSH 会话启用小说方法、检查工具和内部织章工作台。编辑角色只能查询、审读和创建编辑候选；正文采纳、设定变更与定稿属于写手和作者。旧 `zhizhang_enable` 可通过 `compatibilityEntry: true` 开启。

作品、章节和候选沿用原 `.zhizhang/` 存储。`writer_run` 可绑定作品、章节与自定义 `working_dir`；新书使用任务预留 key 创建。写作包包含根基、当前章纲、前两章及关联规划，`zhizhang_chapter_brief` 可按需补充方法和上下文。

编辑回报存于作品 `writer-reviews/<章id>/`，绑定正文 SHA-256。新旧回报按记录时间查找，正文变化后旧回报失效；0.3.0 的外置回报不会自动迁移。

`fanqie.requireEditorPass: true` 要求独立编辑完整回读当前版本、零硬伤并给出通过回报；小说原有审读声明、章节依赖和作者确认仍有效。未开启严格模式时，作者可在原面板直接审阅。

小说右栏操作发送到已打开该作品的主会话；同一作品对应多个主会话时，到任务页手动选择。续章从面板中选中的章节向后定位。重启宿主后需重新在目标主会话打开作品。
