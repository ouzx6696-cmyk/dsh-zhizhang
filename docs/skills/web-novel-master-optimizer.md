# 网文创作与去AI味全景优化技能（织章对齐）

## 0. 核心定位

网络小说靠**沉浸、代入、滑屏节奏**和**紧凑利益/行动链**吃饭。

本技能是一套闭环：

**宏观定处境 → 词句定病灶 → 密度定优劣 → 实景定改写 → 扩充定血肉 → Diff 定采纳 →（可选）验收落正式章**

与织章默认写作链对齐时，编辑过稿落在 **stage → lint** 之后、**accept** 之前（或与其合并为一次用户确认，见下）。工程端口：`port.edit`（`zhizhang_candidate_edit_*`）；调度见 `Scheduler.writeLine()`。

### 五大立场

1. **通篇感知，处境驱动**：先定角色即时利益与本章落点，再改字；拒绝脱离上下文逐句抠字。
2. **词表定线索，策略定动作**：词库只负责发现；每个 AI 味词绑定 `delete` / `replace` / `rewrite`。
3. **以写代删，实景替换**：删冗余逻辑词，但用带阻力的动作、利益台词、五感细节顶上，不断因果。
4. **扩充有度，张力优先**：扩写服务冲突与主线，不是注水。
5. **不求零命中，只拦系统性**：偶发放行；按千字密度拦系统性 AI 腔；改动按句/段 Diff，由用户审阅。

### 与织章口径对齐（重要）

| 织章概念 | 本技能怎么说 |
|----------|--------------|
| `stage` | 编辑产出进候选区，**不**自动变正式章 |
| `lint` | 扫描/密度评分；硬闸可阻断，软提示不静默改稿 |
| `accept` | **仅**用户显式确认后写入正式章；禁止静默验收 |
| 打碎僵硬 | 目标是打碎「完美、齐刷、范文腔」；**不是**脏话配额、也不是每书硬塞出丑桥段 |
| 去AI味 | **≠** 磨成范文齐句；清空转/套话/心理标签/段尾升华，**保留**呼吸起伏与局部毛边；禁止为去味把句长熨平、主语砍光 |
| Agent 可见提示 | 优先正向「这一场要写成什么样」；硬闸清单可保留否定句 |

## 0.5 写手 →（可选）编辑 → 验收流水线（必读）

写手写完草稿后，**可以先过一遍编辑**；是否把编辑稿当成正式验收，**必须由用户显式选择**，不得默认、不得静默。

```text
写手草稿（stage 候选 / 初稿）
        │
        ▼
（可选）编辑过稿 —— 本技能四阶重塑 + 选定润色模式
        │
        ▼
用户抉择（三选一，须口头/控件确认一次）
        │
        ├─ A) 采纳编辑稿并一次确认验收
        │     → 一次确认 = 应用 Diff 全量（或已勾选条）+ accept 写入正式章
        │     → 回执写明：已编辑 + 已验收
        │
        ├─ B) 只采纳编辑稿为候选，仍须人工再验收
        │     → 编辑结果写回 stage/候选；正式章不变
        │     → 之后仍走 lint → 用户单独 accept
        │
        └─ C) 拒编辑
              → 保留写手草稿；或换润色模式重跑编辑；不 accept
```

### 抉择细则

- **若用户已决定过编辑、且明确要一次验收**（如「编辑后直接过 / 编辑完就验收 / 用编辑稿定稿」），走 **A**。编辑本身不是默认必经；写手稿可直接 lint→accept。
- **未表态**：不得当 A；编辑结果只进候选（等同 **B** 的安全默认），并提示用户选 A/B/C。
- **A 的确认语必须可核对**：例如「确认：采纳本章编辑稿并验收为正式章」。一次确认同时完成「应用编辑」与「accept」；**禁止**只应用编辑却偷偷 accept，也禁止只 accept 未展示 Diff。
- **B**：适合还想改设定/对照大纲再点验收的场景。
- **C**：可指定「退回草稿」或「换模式重跑」（如从标准去味改成节奏提速）。

### 与织章工具的映射（概念层）

| 步骤 | 织章侧落点 |
|------|------------|
| 写手成稿 | `zhizhang_candidate_stage` |
| 编辑过稿 | `zhizhang_candidate_edit_brief` → 改写 → `zhizhang_candidate_edit_stage`（`editOf`；不直写 `chapters/`） |
| 抉择 A | `zhizhang_candidate_edit_decide(choice=A, confirm_accept_after_edit=true)` 或 accept 双旗标；一次确认=编辑+accept |
| 抉择 B | `edit_decide(choice=B)`；稍后 `style_lint` → `candidate_accept` |
| 抉择 C | `edit_decide(choice=C)`；可换 mode 重跑 edit_brief |

## 第一部分：三道防线与四阶工作流

### 1.1 全局三道防线

```text
【写前预防】硬约束：禁用词表 + 视角/人设口吻 + 处境利益锚点
            + 7 维自然扩充法则 +（若有卡）打碎僵硬「本场应落纸」一行正向
     ↓
【提交校验】扫描器按句定位 + CJK 千字密度
            （≥60 Error 阻断 / 1–59 Warning）+ 可选句式诊断
     ↓
【事后重塑】四阶工作流 → 多模式改写 → 句子级 Diff 审阅
            → 用户按 0.5 节 A/B/C 抉择（A 才连带 accept）
```

### 1.2 事后重塑四阶工作流

#### 阶段一：通读全局与全景定位

动手改字前通读全文，完成三项定位：

- **视角与利益**：谁的视点？手里有什么、差什么、防谁、最想办成什么？
- **章节功能与落点**：铺垫 / 爆发 / 分赃 / 转场？结尾是钩子还是喘息？
- **病灶与干瘪区**：出戏感 / 说明书感 / 拔高感；以及跳步、需扩充的干瘪段。

#### 阶段二：词库与句法双层锚定

- **微观词库**：五大类高频 AI 词（见第二部分）。
- **宏观句式**：辩证空转、文青碎句、过程跳步、机械「他+动词+了+一下」、段尾升华。

#### 阶段三：实景化重塑与血肉扩充

- 冗余逻辑词 → `delete`
- 万能套话 → `replace`
- 抽象心理 / 空转 / 干瘪过程 → `rewrite` & `expand`（五感、动作分解、台词潜台词、利益博弈）

同时注意**打碎僵硬**（正向）：句子呼吸不齐刷、念头可半截、信息不急着讲漂亮、过程可留毛边——但**卖点节拍与压力链不散**，避免散文化。

> **去AI味 ≠ 磨成范文齐句。** 编完若短句齐刷（像匀速吐字），优先退回写手稿或换 `polish-rhythm`，不要再往短压。

#### 阶段四：手机端滑屏语感验收（编辑侧自检，≠ 用户 accept）

- 滑屏是否卡顿？假文艺断句、排比堆砌是否消掉？
- 配角是否有真实利益反应？是否守住当前润色模式边界？
- 结尾是否落在具体局面上？

> 本阶段的「验收」是编辑自检，**不是**织章 `accept`。用户正式验收见 **0.5 节**。

### 2.2 宏观层：六大句法顽疾与网文重塑律

#### 1. 辩证翻案句式

- **病理**：「不是 A，而是 B」「与其说…不如说…」「这不仅…更…」。
- **重塑**：斩断权衡，直接给决断后的单一动作或利益事实。
  - 原：「他眼中的冷漠不是因为无情，而是为了隐藏内心深处的痛苦与防备。」
  - 改：「他没去接对方递来的热茶，甚至连眼皮都没抬一下：『规矩就是规矩，天亮前拿不出灵石，人我带走。』」

#### 2. 散文碎句与形容词尾随

- **病理**：主谓省略 + 形容尾随 + 破折号堆叠，割裂气流。
- **重塑**：整合成动词主导的顺畅长短句。（打碎僵硬 ≠ 故意写成散文碎句。）
  - 原：「脚步声，近了。黑，浓稠如墨。他握紧了刀，心跳，砰，砰…」
  - 改：「巷口那串踩碎瓦砾的脚步声越来越近。夜色黑得辨不清五指，他反手将柴刀抽出半截，冰凉的刀背死死抵在掌心的老茧上。」

#### 3. 抽象情绪与生理标签

- **病理**：「心情复杂」「嘴角勾起残忍的弧度」。
- **重塑**：删情绪标签，换物理阻力、肌肉反应、利益权衡。
  - 原：「看着倒在地上的敌人，他嘴角勾起一抹冷笑，心中涌起一股大仇得报的快意。」
  - 改：「他一脚踹开尸体压着的储物袋，用鞋底在对方干净的袍角上蹭掉刀刃上的血污，长长舒了胸口憋着的那口浊气。」

#### 4. 段尾与章尾去升华

- **病理**：冲突结束拔高哲理鸡汤。
- **重塑**：结尾落在具体物品、动作残局、未完威胁或下一场算计。
  - 原：「他站在废墟之上，望着满天繁星。他明白，属于他的传奇才刚刚拉开序幕。」
  - 改：「外头巡夜的铜锣声由远及近。他吹灭桌上的油灯，把染血的黑袍团塞进灶膛，顺手将门闩轻轻合死。」

#### 5. 台词去说明书

- **病理**：借角色背设定，礼貌完整无烟火。
- **重塑**：台词带诉求（要钱、保命、立威、推责）；只说当下有利益分歧的部分。
  - 原：「李兄，这万毒窟凶险异常，里面盘踞着二阶妖兽赤炼蛇，我们必须小心行事。」
  - 改：「『解毒丹就剩最后两颗，你要走前头你拿一颗。』他停住脚步，冷冷瞥了一眼黑黢黢的洞口，『不然就老老实实在后头压阵。』」

#### 6. 机械句式与排比降维

- **病理**：「他+动词+了+一下」、三句以上排比、感叹号泛滥。
- **重塑**：长句拆短，事件句干脆；排比只留一项最有冲击力的细节；收敛感叹号。

### 2.3 全景四维诊断卡与误杀防护

#### 四维检查单

1. **动机与利益轴**：观察是否带主观利益偏见？险境中是否还在客观欣赏景物？
2. **句式与呼吸轴**：连续对仗排比、「不是 A 而是 B」、文青碎句？
3. **细节与过程轴**：核心冲突是否「经过一番激战」带过？（调七维扩充）
4. **结尾与钩子轴**：是否哲理总结？（砍鸡汤，落残局/异响/危机）

#### 误杀防护（严禁矫枉过正）

- **合理情绪爆发**：复仇、绝境反杀的痛快宣泄，符合心境则勿强行冷淡化。
- **市井口语与口癖**：「老子」「他娘的」「得加钱」等是人味，严禁规范化成书面语。（这是角色载体，不是「脏词配额」任务。）
- **数据流 / 系统面板**：核对数值、算收益属爽点，勿当说明书删。
- **快节奏必要概括**：无博弈价值的赶路、常规闭关，一笔带过，勿强行扩生活细节。
- **卖点节拍**：打碎僵硬时，口气可毛，**压力链与章内兑付不可散成散文**。
- **反齐刷短句**：删空转时不要把长短熨平、主语砍光；写手稿里有起伏的长句与半截念头，能留则留。

## 第三部分：七维血肉扩充武器库

执行 `rewrite` 或以写代删、或字数不足需自然扩充时调用：

### 1. 场景细节与动态交互

布局/光线/气味；物品质感；环境对人物的阻力与空间移动（踩板吱呀、衣角带烛、挤门擦碰）。

### 2. 人物内心（Show, Don't Tell）

利弊算计；1–2 段极短画面闪回触发决断；贪婪与谨慎的即时交锋——用身体和选择表现，不贴「心情复杂」。

### 3. 对话扩展与博弈

身份口吻差异；潜台词（摸底/施压/分赃）；打断、拒答、跑题再拉回。

### 4. 五感

视听触嗅味用具体形变与质感，不用「绝美/深邃」。

### 5. 次要情节线

小人物真实反应；顺手伏笔；关系因分赃/并肩产生的微妙变化——仍须服务主线张力。

### 6. 关键时刻放慢

出招/格挡连续帧；发现破绽的定格；对峙前的小动作与环境风吹草动。

### 7. 环境烘托

天气对视线与耐力的实质影响；行规、剥削、底层法则自然流露。

### 扩充三原则

- **自然融入**：挂靠视角人物的感知与行动。
- **保持张力**：扩充不卸冲突。
- **推进主线**：最终改变角色状态或推进核心剧情。

## 第四部分：多模态润色矩阵与边界纪律

**全局底线：所有模式一律禁止引入 AI 味词句。**

| 润色模式 | 适用 | 侧重 | 长度 | 绝对禁止 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 标准去AI味**<br>`polish-depolish` | 初稿常规去味 | 清空转/套话/心理标签/段尾升华；**保留呼吸与毛边**；禁止为去味熨平句长 | 原长 **±10%**；长短交错，不求句句变短 | 新增情节、篡改设定；齐刷短句匀速吐字 |
| **2. 分类专项**<br>`polish-depolish-{cat}` | 某类密度极高 | 每次只盯一类，优先命中最多的类 | 原长 **±10%** | 乱改无关段、变更剧情 |
| **3. 节奏提速**<br>`polish-rhythm` | 拖沓卡顿 | 删重复；事件句短句；连续 3 段无新信息合并 | 压缩 **20%–40%** | 删核心冲突节点、新增情节 |
| **4. 凝练缩写**<br>`polish-condense` | 超长、转场啰嗦 | 删枝节、合并同类对话场景 | 原长 **60%–70%** | 删主线、改设定、引入 AI 味词 |
| **5. 血肉扩写**<br>`polish-expand` | 干瘪、字数不足 | 调七维扩充 | 原长 **1.5–2 倍** | 无关支线、注水、引入 AI 味词 |
| **6. 文风统一/校对**<br>`polish-style` / `proofread` | 拼接或发布前 | 统一视角时态口吻；错别字病句标点 | 保持不变 | 大段重写、抹杀口癖 |
| **7. 重构式深度润色**<br>`polish-literary` | 高潮章、黄金三章 | 只守情节/人设/世界观；其余可重组扩写；**几乎每段可见重构** | 依张力伸缩 | 改主干事实、生死与核心设定 |

编辑跑完任一模式后，**必须回到 0.5 节让用户选 A/B/C**，不可自行当作已验收。编辑仍是**可选项**：写手 lint 后可直接 accept。

若编辑稿出现短句齐刷（`uniform_short_run`），回执会软提示：优先 **C 退回写手** 或换 `polish-rhythm`，不要再压短。

## 第五部分：扫描、评分与 Diff 审阅

### 5.1 扫描与密度评分（`scanner` 概念）

1. **长词优先匹配**：词库按长度降序，避免短词抢长词；不做「词中词」跳过，贴近真实密度。
2. **按句组织命中**：按 `。！？!?\n` 切句；命中带句上下文（可截断约 60 字）。
3. **CJK 千字密度**：
   - 分母只数 CJK（`\u4e00-\u9fff`）。
   - `perThousand = (命中数 / cjkChars) * 1000`；`score = min(100, round(perThousand * 10))`。
   - `score >= 60` → **error**（阻断提交，须处理）；`1–59` → **warning**；`0` → 通过。
4. **可扩展**：项目级追加 AI 味词；`forbiddenWords` 硬禁用独立校验。

### 5.2 句子级 Diff 与采纳闭环

1. **句子级粒度**：按句末标点与换行切 Token；句内改动整句标 `del + add`。
2. **性能**：任一侧 Token > 2000 时退化为整块 `del + add`。
3. **交互**：段落级建议卡片；逐条采纳/拒绝、预览、定位、撤销。**模型不直接覆写正式章。**

### 5.3 采纳与验收（与 0.5 节绑定）

| 用户说法 / 选择 | 系统行为 |
|-----------------|----------|
| **A「编辑后直接验收」** | **一次确认**同时：应用已采纳（或全量）编辑 Diff **+** `accept` 写入正式章。回执须同时写明「已应用编辑」与「已验收」。 |
| **B「先用编辑稿，我再验收」** | 只更新候选/stage；**不** accept。提示下一步单独验收。 |
| **C「不用这次编辑」** | 丢弃或归档本次 Diff；正式章与写手草稿关系不变；可换模式重跑。 |
| **未明确** | 按 B 的安全默认处理，并追问 A/B/C。 |

**禁止：**

- 编辑模型跑完后静默 `accept`
- 用户只说「看着行」但未选 A/B/C 时当作 A
- 只 accept 写手旧稿却声称「已按编辑稿验收」

## 第六部分：实操 Prompt 模板

> Agent 可见段落优先写「要写成什么样」；词表清剿等硬约束可用否定清单。

### 模板 1：全能去 AI 味与实景重塑

```text
【任务背景】
你是资深网文主编。把 AI 腔、油腻套路、文青碎句的初稿，重塑为沉浸、紧凑、有人味的正文。
改完后不要自称已定稿；定稿与验收由用户按 A/B/C 抉择。

【输入】
- 待改文本：{{章节文本}}
- 叙事视角与此刻处境/诉求：{{…}}
- 本章冲突与结尾预定状态：{{…}}
- 润色模式：{{标准去AI味±10% / 节奏提速-20~40% / 血肉扩写1.5~2倍 / 重构式深度润色}}
- （可选）本场应落纸：{{打碎僵硬的一行正向，如：半截念头可留、信息不急着讲漂亮；卖点节拍不散}}

【要写成什么样】
1. 处境驱动：视线与行为紧扣当下利益；景物只作为生路/破绽/财物信息出现。
2. 实景推进：关键处用带阻力的动作、博弈台词、五感细节；过程可读，不跳步通报。
3. 呼吸自然：长短句交错，可留半截念头与局部毛边；事件句可以干脆，但不要整段齐刷短句；结尾落在具体残局/物品/威胁，不升华。
4. 人还在场：口癖与合理宣泄可留；系统面板与必要概括可留；主语不必为「干净」而砍光。

【去AI味 ≠ 磨成范文齐句】
- 要去：空转连接、万能动作、心理标签、辩证翻案、段尾升华。
- 不要为去AI味：把长短熨平、主语省略成流水账、句句压到差不多短。
- 编完若短句齐刷，优先退回写手或换节奏提速，不要再往短压。

【硬约束·词句清剿】
- 删：不禁、不由得、然而、与此同时、总而言之、毋庸置疑、值得一提的是、旋即、顿时、罢了、啊！等冗余连接/语气。
- 伪过渡（下一秒/忽然之间/然而就在这时）改为具体突发动作。
- 万能动作（嘴角勾起一抹/眼中闪过一丝/缓缓/微微/深吸一口气）改为具体肢体或视线。
- 禁止辩证空转「不是A而是B」；禁止文青碎句堆砌；禁止心理标签（心中涌起/心头一紧/思绪万千）；禁止台词背设定；禁止段尾哲理金句。
- 禁止为去AI味而齐刷短句或把主语砍光成匀速吐字。
- 保留故事事实、境界、战果胜负与核心走向。
- 重构式深度润色：几乎每段有可见结构重组，禁止只换同义词。

【输出】
只输出重塑后的正文，无说明报告。
```

### 模板 2：AI 味深度诊断扫描

```text
对以下文本做词表之上的 AI 味诊断，检测：
1. 词库：高频连接词、万能动作、抽象心理（一丝/一抹/心中涌起等）。
2. 句式：他+动词+了+一下、不是A而是B、文青碎句、排比滥用、感叹号泛滥。
3. 叙事：Tell 代 Show、过程跳步、台词背设定、段尾升华。

按 JSON 输出（evidence 引原文，suggestion 给实景改写）：
{
  "score": 0-100,
  "issues": [
    {
      "severity": "high | medium | low",
      "category": "connector | action | psychology | adjective | tone | syntax_template | prose_fragment | ending_elevation",
      "evidence": "原文病句",
      "advice": "诊断说明",
      "suggestion": "符合 Show don't tell 与网文节奏的改写"
    }
  ]
}
```

### 模板 3：七维自然扩写

```text
将以下章节自然扩充至原长 1.5–2 倍，只输出正文。
要写成什么样：
1. 场景：布局、光线、气味、物品质感、空间移动与触碰。
2. 关键处放慢：出招受力、呼吸、对峙小动作。
3. 对话：潜台词、试探、口吻、停顿。
4. 五感与内心具象：利弊算计、肢体犹豫、或 1–2 段短闪回；不用心理标签。
硬边界：保持张力、推进主线；禁止注水与无关情节；禁止引入「不禁、仿佛、缓缓、微微、一丝、一抹、心中涌起、嘴角勾起、不是A而是B」等 AI 味词句。
卖点节拍与压力链不得因扩写而散掉。
```
