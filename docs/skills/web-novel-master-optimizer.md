# 作品编辑与修订

当前方法按技能套件 1.3.0 的交接思想整理；运行时单源为 `domain/creative-guidance.ts`，实际文件与版本规则见 [DATA.md](../DATA.md)。

先完整读章与必要依据，列位置、依据、影响及最小修改方向，再按实际授权修改并完整回读。四类内容核验是关键经历与落点、本书硬约束、人物认知来源、正文接续。

按 L1 结构/单元、L2 场面/交锋、L3 句面/声音定位问题。只获准润色不改关键路线，获准重构就处理真实结构病灶。不按模式强制改字数，不按禁句删除有用心理、长句、口癖和完整收束。

A/B/C 保留为选择编辑候选的兼容交互，不等于定稿。已有明确授权不重复索取固定确认词。候选采纳内置扫描；已有凭据过期须重扫。审读结论、当前版本与实际定稿授权分别核对。

已定稿修订须核原稿基线，保留不可覆盖的历史，审读候选后再应用；只存在一个现行正文。未来稿按明确依赖重核，不自动回滚或重写其他定稿，也不自动回灌参考库。
