# 写作台

DSH 侧栏「写作台」用来阅读、对照和确认写回；写作本身仍由会话里的 Agent 完成。写作台不调用模型，单次点击不会静默写入。顶部切换**番茄长篇 / 今日头条**，两种模式各自取数，切换后浏览器会记住。

## 番茄长篇模式

页头：作品标题、项目/作品选择、写作模式切换、视图切换（章节 / 全书概况）、自动刷新开关和刷新；下方标签显示章数、字数、定稿、草稿、待采纳、待核对修订和最近更新时间。

**章节视图**（三栏）
- 章节导航：状态点、状态、字数、处境摘要；有待采纳候选时显示数量，正文修订后待核对时标「待核对」。超过 6 章出现筛选框与「全部 / 有候选 / 需处理」。上下方向键移动，Home/End 跳首尾。
- 阅读区：现行正文 / 候选 / 并排对照；字号可调并记住。超过约 400KB 的正文标明截断，审读与定稿按钮随之禁用。本地「扫描表达」可标注叙述段落里的规则命中（可选建议，不判断来源），整段编辑后保存为修订候选。
- 本章栏：章节进度（计划 → 工作稿 → 已审读 → 定稿）；声明已审读、定稿、确认修订影响；待采纳候选与采纳；**写作 Agent**：最新编辑审读结论（四类硬伤与 L1–L3 计数、是否过期），以及「续写下一章 / 派编辑审读本章 / 按回报修改」。打开 requireEditorPass 时，没有当前正文的"通过"回报不能定稿。

**全书概况**：总览、参考库、规划、写作、留痕五个分区。

## 今日头条模式

页头：写作模式切换、刷新；下方标签显示文章总数、各状态篇数和最近更新时间。

- 文章栏：按状态分组（初稿待改 / 待验收 / 已验收 / 验收退回 / 已交稿），每篇有状态点、体裁、当前版本，右侧是最近质检分（过线绿、未过红）；超过 6 篇出现筛选框。
- 阅读区：当前稿 / 交稿单切换。
- 状态栏：文章进度条（立项 → 成稿 → 待验收 → 已验收 → 已交稿，待改标黄、退回标红）；内容线与体裁、打回轮数、立项卡主问题、主推与备选标题；质检（分数、硬闸、当前版本质检是否仍有效、全部质检记录）；版本列表（写手版 / 编辑版 / 作者版）；**采用**：已验收、已出交稿单且质检仍有效时可用，在对话框里确认后标记为"已交稿"（AI 不替你发布）；状态历史；**写作 Agent**：「继续推进 / 派编辑红笔 / 按质检修改 / 新写一篇」，可附 300 字以内的附言（新写一篇时附言当题材）。

## 操作反馈
- 每次操作的结果在右下角弹出提示：成功和信息类几秒后自动消失（底部细条倒计时，鼠标悬停暂停），出错的留到你关掉；带详情的提示可展开。
- 写作 Agent 按钮是动作卡片（图标、名称、一句说明），发送中图标转圈、说明变成"正在发到对话…"；不能用时卡片置灰，原因写在下方。
- 「采用」发送中转圈，成功后短暂显示对勾；「刷新」读取中转圈。
- 切换章节、文章或视图时内容淡入；对话框弹出有过渡；系统开启"减少动效"时动画全部关掉。

## 按钮怎么发到对话
- 发出的是一条以【写作台】开头的普通用户消息，Agent 正忙就排队（mode=queue），你在对话里能看到原文、能打断。
- 目标是最近在这个数据目录（长篇按引擎数据根，头条按头条数据目录）用过写作工具的主会话；编辑子代理不算。
- 没有会话控制服务（headless）或这个目录还没有会话用过写作工具时，按钮置灰并写明原因。

## 写回都要确认

| 操作 | 效果 |
|---|---|
| 阅读、切换、对照、扫描 | 只读 |
| 采纳候选（长篇） | 对话框确认后调用与工具相同的采纳服务，写入工作稿并扫描 |
| 声明已审读 / 定稿 / 确认修订影响（长篇） | 绑定打开时已加载的版本；定稿复核审读、上下文、前章依赖与 requireEditorPass |
| 采用（头条） | 复核"已验收 + 交稿单 + 质检仍有效"后改为已交稿，同步台账 |
| 写作 Agent 按钮 | 只发一条消息到对话，不改作品 |

写请求超时也可能已经完成，写作台会重新读取后再判断是否需要重试。

## 刷新与发现数据
自动刷新：页面可见时约每 6 秒一次，隐藏时放慢，连续失败逐步退避，打开确认对话框期间暂停。写作台通过工具记录的最近数据根与项目索引发现数据，选定后不会随轮询静默切换。

## 访问与接口
- 默认只接受本机；`workbench.allowLan=true` 后接受局域网，Host 须在 `workbench.hosts` 或本机网卡地址里；配了 `workbench.token` 时每个请求都要带（插件详情页「写作台」卡片输入，只存在当前浏览器会话）。带 Origin 的请求必须同源。每个客户端每分钟最多 120 个 GET、20 个 POST。
- 接口一览见 [TOOLS.md](TOOLS.md#写作台接口只接受本机或按-workbench-配置的局域网与令牌)。

## 与宿主界面的一致性
控件优先用宿主 `@deepseek-ai/dsh-client-ui-primitives`（Button、SegmentedControl、Tag、StateDot、Checkbox、Modal），没有时用插件内实现；样式只用 `--dsw-*` 主题变量，布局随面板宽度（容器查询）变化；样式表带插件标记，停用时由宿主回收。
