- 框架认知：ARCHITECTURE 改为先解释自有桌面调用链，明确任务、作者动作、授权、作品、读取和方法的责任；保留共享包及存量接入说明。

- 定点验证：只新增一个取消场景，包含准备等待及 SDK 接收窗口。此项使用可控会话协议验证取消交接，真实 SDK 正常链路由原桌面集成场景覆盖；不将模拟时序声称为真实模型故障复现。

- **渲染检查**：client、Workspace、Settings 均显式启用 `@ts-check`，Markdown 使用 TSX。独立 renderer 配置检查现有 JavaScript，桌面 TS/TSX 继续使用原 strict 配置，没有降低现有 TypeScript 检查强度。构建必须同时通过两者；架构守卫禁止新增未启用检查的桌面 JSX。JS 检查不是“全量 strict TS 迁移”，保留 JavaScript 的兼容语义，不新增全局 any 或忽略错误指令。
