# 写作台

在 DSH 侧栏打开「写作台」，顶部可切换番茄长篇和今日头条。写作台用于阅读、对照和处理作品；生成正文由 DSH 会话中的 Agent 完成。

## 番茄长篇

章节视图按章节、阅读区和本章操作分栏。可以选择作品与章节，查看现行正文和候选，并排对照后决定是否采纳；也可以声明审读、定稿或确认修订影响。全书概况集中展示作品、参考库、规划和写作状态。

阅读区的「扫描表达」会标记可回看的语言信号，修改后可保存为候选。它是规则辅助，不判断文本来源。最新编辑审读结果显示在本章栏；需要时可向会话发送续写、审读或修改请求。

## 今日头条

文章按状态分组，阅读区可切换当前稿和交稿单。状态栏展示标题、版本、质检与历史记录。满足采用条件后，作者可在写作台确认采用；也可以向会话发送新写、继续推进、编辑或修改请求。

## 写作台与会话

写作动作会发送一条以【写作台】开头的普通消息。目标是最近使用该数据目录的 DSH 主会话；Agent 正忙时消息会排队。附言最多 300 字。还没有会话使用该目录，或宿主没有会话控制服务时，按钮会显示不可用。

写作台操作完成后会显示结果。采纳与定稿使用当前打开的版本；切换作品或正文变化后，先刷新并核对再操作。

## 访问与数据

默认仅允许本机访问。局域网访问需在 `workbench` 中配置；详见[安装与配置](INSTALL.md)。两种模式的数据位置见[项目架构](ARCHITECTURE.md#工作方式)，接口见[工具参考](TOOLS.md#写作台接口)。
