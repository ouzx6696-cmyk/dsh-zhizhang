# dsh-writer 0.7.0

0.7.0 是基于 DSH 的写作插件，提供今日头条、番茄长篇和共用写作台。DSH 负责模型与会话；作品、稿件和写作方法由插件管理。

## 主要功能

- 一个 `writer_enable` 入口，按会话启用头条或长篇模式；可使用编辑子代理参与审读。
- 头条模式支持素材与立项、稿件版本、质检、交稿单和作者采用。
- 长篇模式支持作品设定、章纲、正文候选、审读定稿、拆书参考和规划，并内置 forge 写作方法。
- 写作台可切换两种模式，阅读和对照稿件，查看审读结果，并向 DSH 主会话发送写作请求。
- 梳理安装、配置、数据、工具和架构文档，移除过时的设计草案；发行包只包含运行所需文件。

## 安装

从本页下载 `dsh-writer-0.7.0.tgz`，完全退出 DSH 后执行：

```bash
dsh plugin --profile desktop add ./dsh-writer-0.7.0.tgz
```

需要 DSH `>=0.2.1-rc.4 <0.2.2` 和 Python 3.8 及以上。完整步骤与配置见[安装文档](https://github.com/ouzx6696-cmyk/dsh-zhizhang/blob/v0.7.0/docs/INSTALL.md)。

## 从 0.5.0 升级

0.7.0 的入口改为 `writer_enable`，不再提供 0.5.0 的 `writer_run` 等任务工具。长篇数据默认目录从 `.zhizhang/` 改为 `.writer/`，新版本不会自动迁移旧作品。请保留旧数据和配置，参照[升级说明](https://github.com/ouzx6696-cmyk/dsh-zhizhang/blob/v0.7.0/docs/INSTALL.md#从-050-升级)核对后再使用。
