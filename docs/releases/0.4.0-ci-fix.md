# 0.4.0 CI 修复

## 原因与修改

- Windows Python 使用 cp1252 输出中文，原规则测试触发 UnicodeEncodeError。CI 显式设置 PYTHONUTF8=1、PYTHONIOENCODING=utf-8；不修改原规则或测试。
- 根目录 test:zhizhang 命令从仓库根执行，原测试中的相对路径与子进程导入找错 dist。新增 scripts/test-zhizhang.mjs，在 packages/zhizhang 工作目录执行全部四个原测试文件；仍然是原 47 项断言。
- .gitattributes 固定文本源码为 LF，ZIP/tgz 保持二进制；避免 Windows checkout 改变原测试文件的 SHA-256。矩阵 fail-fast=false，让两平台都给出完整结果。

## 验证与交付

完整本地命令及输出见 0.4.0-ci-fix-tests.txt，原测试哈希保持不变。远端最终状态以本分支对应提交的 GitHub Actions 为准。

改动文件：.github/workflows/ci.yml、.gitattributes、package.json、scripts/test-zhizhang.mjs、CHANGELOG.md，以及本说明与日志；同时刷新 release-artifacts/writer-agent-v0.4.0 的源码 ZIP 与校验和。安装包运行代码没有改变。

接口变化：无业务接口、数据格式、配置契约或 DSH API 变化。本次仅修复测试启动与平台环境，不新增运行时依赖。Windows 桌面实点和真实模型试写仍待验收；没有新增上游改动建议。
